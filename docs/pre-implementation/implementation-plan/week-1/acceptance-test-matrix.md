# 验收用例框架与测试矩阵

## 1. 文档目标

本文用于 Sprint 0 第一周交付“验收用例框架与测试矩阵”，为后续详细用例、接口测试、SIT、专项测试和 UAT 提供统一口径。

依据文档：

- `implementation-plan/testing-release-risk-plan.md`
- `review-acceptance/implementation-testability/implementation-testability-review.md`
- `review-acceptance/product-coverage/product-coverage-review.md`
- `review-acceptance/ui-consistency/ui-consistency-review.md`
- `architecture/technical-architecture-design.md`

一期验收目标聚焦“看见状态、定位问题、触发通知、基础处理闭环、权限隔离、安全审计”。不纳入一期主验收：复杂组合规则、动态阈值、智能降噪、完整告警合并/静默/升级/排班日历、正式工单/事件/IM 集成、完整 APM 拓扑、自动修复、中间件/数据库专项一级导航。

## 3. 状态覆盖矩阵

| 状态类型 | 枚举 | 必测页面/模块 | 验收口径 |
| --- | --- | --- | --- |
| 健康状态 | 正常、预警、异常、严重、未知 | 首页、应用、服务器、告警、依赖对象 | 描述业务或监控对象运行健康，不与接入状态混用 |
| 接入状态 | 已接入、仅指标、仅日志、未接入、验证中、接入异常 | 应用详情、接入管理、数据源管理、告警规则 | 未接入不计入业务异常统计；接入异常计入接入风险 |
| 数据源状态 | 正常、异常、超时、鉴权失败、采集延迟 | 指标、日志、Trace、数据源管理、规则检测 | 数据源异常不生成“指标为 0”的误告警；页面展示最近成功采集时间 |
| Agent 状态 | 正常、无心跳、版本过低、配置异常、未安装 | 服务器详情、接入管理、首页接入风险 | Agent 异常影响服务器/日志/自采集指标接入状态，不直接判定业务应用异常 |
| 告警状态 | 已触发、已通知、通知失败、已确认、处理中、已恢复、已关闭 | 告警列表、告警详情、通知记录、处理时间线 | 状态流转、允许动作、处理记录、审计记录一致 |
| 规则状态 | 草稿、启用、停用、配置异常 | 告警规则列表、规则表单、接入状态提示 | 未接入指标、无近期采集、数据源异常时不可启用依赖规则 |
| 导出任务状态 | 待确认、排队中、处理中、成功、失败、已过期、已取消 | 日志导出、指标导出、告警导出、导出记录 | 异步任务可追踪；失败原因可见；过期不可下载 |
| 页面通用状态 | 加载、空、无匹配、无权限、查询失败、部分缺失 | 所有列表、详情、抽屉、弹窗 | 无权限不泄露对象名称、数量、日志内容、SQL、Topic、连接串 |

## 4. 角色权限矩阵

一期权限采用“角色 + 应用授权 + 业务线隔离 + 操作权限 + 环境约束 + 敏感字段权限”的组合模型。所有搜索、下拉、列表、统计、详情、导出、URL 直访必须执行后端过滤。

| 角色 | 首页/总览 | 应用/服务器 | 日志/指标 | 告警 | 通知/值班 | 接入管理 | 系统管理 | 敏感/导出 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 平台管理员 | 全量可见 | 全量维护 | 全量查询 | 全量规则和事件管理 | 全量配置 | 全量配置 | 用户、角色、授权、审计管理 | 可授予敏感权限；高风险操作审计 |
| 运维/SRE | 业务线或运维范围可见 | 可看授权范围及运维对象；可看共享中间件/数据库全局指标 | 可查授权范围和运维对象 | 可建规则、处理告警、查看通知失败 | 可维护渠道和值班组 | 可维护数据源、Agent、默认规则 | 可查看受限审计 | 生产导出、敏感明文需额外权限并审计 |
| 应用负责人 | 仅授权应用及衍生对象 | 授权应用、实例、关联服务器摘要、依赖摘要 | 授权应用日志/指标 | 授权应用告警查看和基础处理 | 可看关联通知记录和值班信息 | 可看本应用接入状态，通常不可改全局数据源 | 不可管理用户角色 | 默认脱敏；导出限授权应用并审计 |
| 值班人员 | 当前值班或授权范围待处理问题 | 值班范围关联应用和服务器摘要 | 可按告警上下文查证据 | 可确认、处理中、备注、关闭授权告警 | 可看通知记录和值班组 | 只读接入状态 | 无 | 默认脱敏；导出按授权控制 |
| 业务负责人 | 业务线摘要和重大告警只读 | 业务线授权应用摘要 | 指标和日志只读按授权过滤 | 业务线告警只读或备注视授权 | 只读通知结果 | 只读接入风险 | 无 | 通常不可导出生产日志，不可看明文 |
| 测试人员 | 测试环境授权范围 | 测试环境应用/服务器 | 测试环境日志/指标 | 测试环境告警验证 | 测试通知记录 | 测试数据源只读或受控操作 | 无 | 禁止访问生产日志和生产敏感字段 |
| 只读用户 | 授权范围只读 | 授权范围只读 | 授权范围只读 | 告警只读 | 通知记录只读 | 接入状态只读 | 无 | 不可导出或仅允许低风险脱敏导出 |
| 无授权用户 | 无数据或无权限页 | 不可见 | 不可见 | 不可见 | 不可见 | 不可见 | 无 | 不可导出，不可通过 URL 或搜索泄露对象 |

### 4.1 控件级权限验收口径

| 控件/路径 | 有权限表现 | 无权限表现 | 必测风险 |
| --- | --- | --- | --- |
| 菜单与 Tab | 可见可进入 | 隐藏或进入无权限页 | 菜单隐藏后 URL 直访仍需拒绝 |
| 列表与统计 | 仅返回授权数据和授权计数 | 空态或无权限，不返回未授权数量 | 统计卡、分页总数不可泄露 |
| 搜索与下拉 | 仅可检索授权对象 | 未授权对象不可匹配 | 输入精确名称也不能泄露存在性 |
| 详情页 URL 直访 | 展示授权详情 | 403 或无权限页，不带对象名称 | 旧链接、浏览器回退、复制链接 |
| 行内操作按钮 | 按操作权限显示或启用 | 隐藏或置灰并说明原因 | 前端置灰不能替代后端校验 |
| 敏感字段明文 | 授权后短时可见并审计 | 默认脱敏或拒绝 | 查看、复制、导出、审计一致 |
| 导出按钮 | 按范围、阈值、敏感级别受控 | 隐藏、置灰或提交后拒绝 | 任务创建、下载都要二次校验 |

## 5. 核心端到端验收用例框架

| 用例编号 | 场景 | 前置条件 | 步骤框架 | 期望结果 | 覆盖专项 |
| --- | --- | --- | --- | --- | --- |
| E2E-01 | 首页发现生产 P1 告警并进入排障 | ACE 生产应用触发 P1；当前用户有 ACE 权限 | 登录首页；查看待处理问题；进入告警详情；跳转日志和指标 | 可识别影响对象、负责人、持续时间；上下文带应用、环境、实例、时间窗口、告警 ID、Trace ID | 权限、告警、日志、指标 |
| E2E-02 | 应用负责人排查错误率升高 | 应用有日志、指标、Trace 数据 | 从应用详情查看健康；进入错误聚合；按 Trace ID 查日志；查看指标趋势 | 日志、指标、Trace 上下文一致；敏感字段脱敏；无数据源异常误提示 | 脱敏、接入状态、上下文 |
| E2E-03 | 值班人员处理告警闭环 | 告警处于已通知状态；用户具备处理权限 | 确认告警；标记处理中；添加备注；指标恢复后关闭 | 状态按已通知、已确认、处理中、已恢复、已关闭流转；处理记录和审计完整 | 告警状态机、审计 |
| E2E-04 | 运维配置 CPU 简单阈值规则 | 服务器指标源正常；通知对象有效 | 新建规则；选择对象和指标；配置阈值、持续时间、重复通知间隔；启用 | 规则字段完整；启用前校验通过；触发后 1 分钟内创建通知任务 | 规则、通知、审计 |
| E2E-05 | 日志导出受控完成 | 用户有授权应用日志导出权限 | 查询日志；发起导出；二次确认；查看任务；下载文件；查看审计 | 导出范围不越权；内容脱敏；任务状态可追踪；下载审计可查 | 导出、脱敏、审计 |
| E2E-06 | 测试人员访问生产日志被拒绝 | 测试人员无生产环境授权 | 访问生产日志列表、搜索生产应用、URL 直访日志详情、尝试导出 | 全部拒绝或无数据；不泄露应用名称、日志内容、数量、索引信息 | 越权、脱敏 |
| E2E-07 | 数据源异常不误判业务异常 | Prometheus 超时或日志源鉴权失败 | 查看首页、应用详情、指标趋势、告警规则 | 页面显示数据源异常和最近成功时间；不生成指标为 0 的误告警；无关模块可继续使用 | 接入状态、告警 |
| E2E-08 | Agent 无心跳识别和追踪 | 服务器 Agent 超过阈值未上报 | 查看服务器详情、接入管理、首页接入风险 | 展示无心跳、最近心跳、影响范围；不直接判定业务应用异常 | Agent、接入状态 |
| E2E-09 | Kafka 积压告警 | Kafka Topic/消费组与授权应用关联 | 触发积压；查看告警；进入关联应用日志和指标 | 可见 Topic/消费组摘要、影响应用、通知对象；共享集群全局指标仅 SRE 可见 | 中间件权限、告警 |
| E2E-10 | PostgreSQL 慢 SQL 告警 | PostgreSQL 慢 SQL 聚合接入 | 触发慢 SQL 告警；查看详情；尝试查看 SQL 明文 | 默认展示脱敏摘要；明文查看需授权和审计；无权限不泄露库表名 | 数据库权限、脱敏 |
| E2E-11 | 应用授权调整后衍生范围生效 | 管理员调整用户应用授权 | 授权 ACE；用户重新访问应用、日志、指标、告警、服务器摘要 | 授权应用及衍生日志、指标、告警、关联服务器范围正确；缓存及时失效 | 权限、审计 |
| E2E-12 | 邮件通知失败可追踪 | SMTP 配置异常或收件人邮箱无效 | 触发告警；查看通知记录；修复后重试 | 失败原因、重试次数、接收人解析链路可见；成功后状态更新 | 通知、审计 |

## 6. 异常态专项用例

| 编号 | 异常场景 | 触发方式 | 期望结果 |
| --- | --- | --- | --- |
| EX-01 | 列表查询失败 | 后端接口 5xx 或超时 | 展示查询失败状态；保留筛选条件；允许重试；不清空用户输入 |
| EX-02 | 详情部分缺失 | 日志源异常但指标源正常 | 详情页局部降级；指标仍可查看；日志区展示异常原因 |
| EX-03 | 表单保存失败 | 告警规则字段非法或并发更新 | 字段级错误、分组错误、底部错误摘要明确；不产生半成品启用规则 |
| EX-04 | 通知发送失败 | SMTP 超时、鉴权失败、收件人缺失 | 写通知记录；展示失败原因；进入通知失败状态或保持告警可处理 |
| EX-05 | 审计写入失败 | 审计服务异常 | 高风险操作阻断或进入补偿队列；用户可见失败原因；不得静默成功 |
| EX-06 | 数据源鉴权失败 | Prometheus/日志源 Token 失效 | 接入管理显示鉴权失败；规则检测记录失败原因；不误触发告警 |
| EX-07 | 导出任务失败 | 查询超时、文件写入失败、对象存储不可用 | 任务状态失败；失败原因可见；不可下载半文件；审计记录创建尝试 |
| EX-08 | 自动刷新冲突 | 首页或列表自动刷新时用户正在筛选/展开/编辑 | 不覆盖筛选、排序、展开行、抽屉、表单输入和选中行 |

## 7. 越权专项用例

| 编号 | 越权路径 | 核心断言 |
| --- | --- | --- |
| AUTH-01 | 未授权用户访问应用详情 URL | 返回无权限，不泄露应用名称、负责人、业务线 |
| AUTH-02 | 未授权对象出现在搜索/下拉 | 不返回、不提示存在、不进入最近访问 |
| AUTH-03 | 应用负责人访问共享 Kafka 全局指标 | 仅展示授权应用相关 Topic/消费组摘要，全局 Broker 指标拒绝 |
| AUTH-04 | 应用负责人访问 PostgreSQL SQL 明文 | 默认脱敏；无敏感权限时不可查看明文 |
| AUTH-05 | 测试人员访问生产日志 | 拒绝访问；不泄露生产日志数量和索引 |
| AUTH-06 | 只读用户处理告警 | 按钮隐藏或置灰；直接调用接口返回拒绝并审计 |
| AUTH-07 | 无导出权限创建导出任务 | 前端不可发起；接口拒绝；不创建可下载文件 |
| AUTH-08 | 修改请求参数扩大应用范围 | 后端按用户权限重新裁剪，不信任前端传入范围 |
| AUTH-09 | 浏览器回退查看已失效授权页面 | 页面重新校验权限，失效后进入无权限或刷新为空 |
| AUTH-10 | 下载他人导出文件 | 下载接口二次校验创建人、授权范围、有效期和脱敏策略 |

## 8. 脱敏专项用例

| 编号 | 场景 | 脱敏对象 | 核心断言 |
| --- | --- | --- | --- |
| MASK-01 | 日志查询结果 | 手机号、身份证、银行卡、邮箱、Token、Cookie、Authorization Header、地址、用户 ID、订单号 | 默认展示脱敏结果，原始值不进入前端响应 |
| MASK-02 | 日志上下文 | 上下文前后行敏感字段 | 上下文和列表使用同一脱敏策略 |
| MASK-03 | 复制日志 | 日志行、Trace ID、错误摘要 | 普通复制复制脱敏结果；明文复制需授权并审计 |
| MASK-04 | 导出日志 | 导出文件内容和文件名 | 导出内容脱敏；文件名不包含敏感对象名称或查询关键字 |
| MASK-05 | PostgreSQL 慢 SQL | SQL 文本、库表名、参数值、连接串 | 默认展示摘要和脱敏 SQL；明文查看需授权、理由和审计 |
| MASK-06 | 通知记录 | 接收人地址、失败详情中的敏感信息 | 邮箱、手机号、Token、SMTP 密钥脱敏展示 |
| MASK-07 | 审计记录 | before/after、请求参数、密钥字段 | 审计本身不成为敏感信息泄露渠道 |
| MASK-08 | 配置密钥 | SMTP 密码、Webhook Secret、Agent Token、数据源 Token | 保存后不可明文回显；更新需重新输入；查看或复制受控 |
| MASK-09 | 明文查看授权 | 临时敏感访问授权 | 有过期时间、审批或确认结果、查看理由、审计编号 |

## 9. 导出专项用例

| 编号 | 导出类型 | 权限与范围 | 阈值与任务 | 脱敏与审计 | 期望结果 |
| --- | --- | --- | --- | --- | --- |
| EXP-01 | 日志导出 | 仅授权应用、环境、时间范围 | 超行数或生产日志走异步任务和二次确认 | 默认脱敏；记录创建、完成、下载审计 | 文件可下载且不越权 |
| EXP-02 | 指标导出 | 仅授权对象和指标 | 限制时间范围、采样点数、文件大小 | 标签中敏感值脱敏；下载审计 | 趋势数据与页面查询一致 |
| EXP-03 | 告警导出 | 授权规则和事件 | 支持按时间、级别、状态筛选 | 处理备注、通知地址按策略脱敏 | 状态、处理记录、通知记录完整 |
| EXP-04 | 报表/摘要导出 | 仅授权业务线或应用 | 一期仅低风险摘要，不导出未授权明细 | 审计记录包含筛选条件摘要 | 不暴露二期报表能力 |
| EXP-05 | 超量导出 | 大时间范围或高行数 | 阻断、要求缩小范围或进入审批/二次确认 | 审计超量尝试 | 不产生不可控大文件 |
| EXP-06 | 过期文件下载 | 文件超过有效期 | 下载拒绝 | 记录拒绝下载审计 | 不返回历史文件 |
| EXP-07 | 导出任务重试 | 任务失败后重试 | 仅有权限用户可重试 | 新增或更新任务审计 | 失败原因和重试结果可追踪 |
| EXP-08 | 文件内容校验 | 下载后抽样检查 | 与查询条件一致 | 敏感字段全部脱敏 | 文件哈希和导出记录一致 |

## 10. 审计验收字段

所有高风险操作应至少具备以下审计字段，便于测试按记录核验：

| 字段 | 验收说明 |
| --- | --- |
| 审计编号 | 操作成功或进入补偿队列后可追踪 |
| 事件类型 | 如规则变更、告警处理、权限变更、导出、敏感查看、越权访问 |
| 对象类型和对象 ID | 应用、服务器、规则、告警、数据源、用户、角色、导出任务等 |
| 操作人和角色 | 记录用户 ID、角色、授权来源 |
| 操作时间和来源 IP | 支持问题追溯 |
| 来源页面或接口 | 区分 UI 操作、API 调用、定时任务 |
| 变更前后 | 配置类操作记录 before/after 摘要，敏感值脱敏 |
| 操作结果 | 成功、失败、拒绝、补偿中 |
| 失败原因 | 越权、校验失败、数据源异常、审计写入失败等 |
| 确认或审批结果 | 二次确认、敏感查看理由、导出确认结果 |

## 11. M0 后进入 Sprint 1 的测试准入

M0 后进入 Sprint 1 前，测试侧需确认以下准入项完成。未满足项必须记录责任人、关闭时间和风险豁免结论。

| 编号 | 准入项 | 通过标准 |
| --- | --- | --- |
| GATE-01 | 一期范围冻结 | P0/P1 范围、二期隐藏或预留能力边界明确，转派/静默/升级不进入一期主路径 |
| GATE-02 | 状态字典冻结 | 健康、接入、数据源、Agent、告警、规则、导出、页面通用状态枚举和优先级明确 |
| GATE-03 | 权限矩阵冻结 | 角色、页面、控件、字段、下拉、URL 直访、导出、敏感字段的可见/可操作规则明确 |
| GATE-04 | 告警状态机冻结 | 已触发、已通知、通知失败、已确认、处理中、已恢复、已关闭的动作、权限、失败回滚、审计明确 |
| GATE-05 | 导出统一规格冻结 | 导出类型、字段范围、阈值、二次确认、任务状态、有效期、失败重试、审计回显明确 |
| GATE-06 | 脱敏策略首批规则冻结 | 手机号、身份证、银行卡、邮箱、Token、Cookie、Authorization、地址、用户 ID、订单号、SQL、连接串覆盖 |
| GATE-07 | 审计字段冻结 | 审计事件字段、审计编号、失败原因、审计可见权限和补偿策略明确 |
| GATE-08 | 数据源聚合规则冻结 | Prometheus/Grafana、SkyWalking、日志源、Agent、Kafka、PostgreSQL 状态对首页、详情、规则、图表影响明确 |
| GATE-09 | 固定验收数据准备 | 至少 3 个应用、2 个环境、约 20 台服务器、2 个 Trace ID、2 个错误签名、2 个值班组、2 类数据源异常 |
| GATE-10 | 接口契约可测 | 核心列表、详情、规则、通知、导出、审计、权限拒绝接口具备状态码和错误码约定 |
| GATE-11 | UAT 主链路可拆分 | E2E-01 至 E2E-12 均能映射到页面、接口、测试数据和责任模块 |
| GATE-12 | 阻塞问题闭环计划 | 评审中的状态、权限、审计、导出、数据源、值班解析、授权衍生范围问题均有关闭计划 |

Sprint 1 测试启动最低门槛：

1. `GATE-01` 至 `GATE-08` 必须完成或有正式豁免。
2. 核心 E2E 用例框架必须完成评审，并能映射到研发模块。
3. 权限、脱敏、导出、告警、通知、接入状态六类专项不得缺失测试负责人。
4. P0/P1 接口需具备可联调用例数据和错误码约定。
5. 任何涉及权限过滤、敏感字段、生产日志、导出下载的未决问题不得无记录进入 Sprint 1。
