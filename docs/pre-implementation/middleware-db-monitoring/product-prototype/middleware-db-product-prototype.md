# 中间件与数据库监控产品原型补充说明

## 1. 文档定位

本文补充企业级统一监控平台中“中间件与数据库监控”的产品原型说明，承接现有：

- `product-prototype/README.md`
- `product-prototype/list-and-states/list-and-states-prototype.md`
- `product-prototype/core-troubleshooting/core-troubleshooting-prototype.md`
- `ui-design/foundation-rules/foundation-rules.md`
- `ui-design/list-pages/list-pages-high-fidelity.md`

范围仅覆盖中间件与数据库相关页面和既有页面增强：

- 中间件列表
- 数据库列表
- 中间件详情
- 数据库详情
- 指标查询增强
- 告警详情增强
- 应用详情依赖区增强

设计边界：

1. 一期不新增过多一级导航，中间件和数据库作为“监控对象”进入指标、告警、应用依赖和排障链路。
2. 可在“应用监控 / 依赖状态”“指标中心 / 指标查询”“告警中心 / 告警详情”中承载入口；若产品需要专项列表，可作为应用监控或指标中心下的二级页面。
3. 权限仍以应用授权为主，数据库和中间件通过依赖的授权应用、对象负责人或基础设施权限决定可见范围。
4. 未接入、采集异常和业务异常必须分开展示，避免把“没有数据”误判为“运行正常”。

## 2. 全局对象与状态规则

### 2.1 监控对象类型

| 类型 | 子类型 | 典型指标 |
| --- | --- | --- |
| 中间件 | Redis、MQ、Kafka、RabbitMQ、RocketMQ、Nginx、网关、任务调度、缓存、注册中心 | 连接数、QPS、错误率、队列积压、消费延迟、缓存命中率、实例健康 |
| 数据库 | MySQL、PostgreSQL、Oracle、SQL Server、MongoDB、Elasticsearch、TiDB、ClickHouse | 连接数、QPS、TPS、慢 SQL、锁等待、主从延迟、容量、IO、复制状态 |

### 2.2 健康状态

| 状态 | 规则 |
| --- | --- |
| 严重 | 存在 P0 未恢复告警、核心依赖不可用、数据库主库不可用、MQ 大面积消费中断 |
| 异常 | 存在 P1 未恢复告警、慢 SQL/锁等待/消费延迟/错误率超过异常阈值 |
| 预警 | 存在 P2/P3 未恢复告警、容量或连接数接近阈值、采集延迟但仍有可用数据 |
| 正常 | 关键指标可采集，无未恢复告警，最近采集时间在有效窗口内 |
| 未接入 | 尚未配置指标源、日志源或实例发现，不能进入业务健康判断 |
| 采集异常 | 曾接入但当前采集失败，列表和详情必须标注最近成功采集时间 |
| 未知 | 数据源无返回或对象归属不明确，无法判断健康状态 |

### 2.3 权限口径

| 场景 | 可见性规则 |
| --- | --- |
| 依赖授权应用 | 用户可查看授权应用直接依赖的中间件/数据库摘要、健康状态、关键指标和告警 |
| 共享中间件/数据库 | 若对象被多个应用共用，只展示用户有权应用的依赖关系和影响范围 |
| 基础设施权限 | 运维/SRE 可查看授权基础设施范围内的完整对象、实例和容量指标 |
| 只读用户 | 可查看授权范围内趋势、告警和脱敏对象信息，不可导出、配置规则或处理告警 |
| 无授权用户 | 不展示对象名称、实例、统计数、SQL 样例、队列名称等明细 |
| 敏感信息 | 数据库账号、连接串、SQL 参数、Token、业务主键默认脱敏，明文查看需权限和审计 |

### 3.5 关键指标

| 类型 | 列表优先指标 |
| --- | --- |
| Redis/缓存 | QPS、连接数、内存使用率、缓存命中率、Key 过期/淘汰、主从延迟 |
| Kafka/MQ | 队列积压、消费延迟、生产速率、消费速率、失败消息数、消费者在线数 |
| Nginx/网关 | 请求量、错误率、P95/P99、5xx 数、上游失败数、限流/熔断次数 |
| 任务调度 | 任务成功率、失败任务数、超时任务数、等待队列长度、最近执行时间 |
| 注册中心 | 实例数、异常实例数、注册/注销次数、心跳延迟 |

| 触发 | 目标 | 带入上下文 |
| --- | --- | --- |
| 点击名称 | 中间件详情 | `middlewareId`、`type`、`env`、`timeRange`、`backFilter` |
| 点击指标 | 指标查询 | `objectType=middleware`、对象、类型、环境、核心指标、最近 6 小时 |
| 点击告警 | 告警列表 | 对象类型=中间件、对象 ID、未恢复、最近 24 小时 |
| 点击关联应用 | 应用详情或应用列表 | 授权应用、依赖对象、环境、时间范围 |

### 3.7 权限与操作

| 操作 | 权限 | 表现 |
| --- | --- | --- |
| 查看列表 | 中间件查看或依赖应用查看 | 仅展示授权范围对象 |
| 查看详情 | 对象查看或关联应用查看 | 共享对象只展示授权应用相关依赖信息 |
| 批量查看指标 | 指标查看 | 跳转指标查询，未授权对象自动过滤 |
| 批量查看告警 | 告警查看 | 跳转告警列表，按授权过滤 |
| 导出 | `export:list` | 无权限置灰；生产和超量需二次确认并审计 |

### 3.8 状态文案

| 场景 | 文案 | 主操作 |
| --- | --- | --- |
| 空状态 | 未找到符合条件的中间件对象。请调整筛选条件，或确认你是否已获得关联应用权限。 | 重置筛选 |
| 加载状态 | 正在加载中间件监控数据... | 无 |
| 数据源异常 | 中间件指标源暂不可用，列表展示最近一次成功采集数据。 | 重试 |
| 未接入 | 该中间件尚未接入指标采集，状态可能不完整。 | 查看接入指引 |
| 无权限 | 当前账号暂无可查看的中间件对象。 | 申请权限 |

### 3.9 验收点

1. 能按名称、类型、环境、状态、关联应用、负责人、接入状态和当前告警筛选。
2. 表格能展示中间件类型差异化关键指标，且支持按状态、告警、关键指标和更新时间排序。
3. 用户只能看到授权应用关联或基础设施授权范围内的中间件对象。
4. 采集异常、未接入、未知状态必须与业务异常分开展示。
5. 行内跳转到详情、指标、告警、关联应用时必须携带对象、环境、时间范围和返回上下文。

### 9.3 筛选项

| 筛选器 | 控件 | 默认值 | 规则 |
| --- | --- | --- | --- |
| 依赖类型 | 多选下拉 | 全部 | 数据库、缓存、MQ、网关、Nginx、任务调度、第三方服务 |

| 环境 | 单选/多选 | 当前应用环境 | 默认继承应用详情环境 |
| 当前告警 | 单选 | 全部 | 全部、有未恢复、无未恢复 |
| 接入状态 | 高级筛选 | 全部 | 已接入、未接入、采集异常、验证中 |

### 9.4 表格字段

| 字段 | 说明 | 排序 |

### 9.6 跳转上下文

| 触发 | 目标 | 带入上下文 |
| --- | --- | --- |
| 依赖名称 | 中间件详情/数据库详情 | 依赖对象、当前应用、环境、时间范围 |
| 指标 | 指标查询 | `objectType`、依赖对象、应用、核心指标、时间范围 |
| 告警 | 告警列表 | 依赖对象、当前应用、未恢复、最近 24 小时 |

| 返回应用 | 应用详情 | 保留依赖 Tab、筛选、滚动位置 |

### 9.7 权限与状态

| 场景 | 表现 |
| --- | --- |
| 应用有权但依赖对象无全量权限 | 展示依赖摘要、健康状态、与本应用相关指标；隐藏其他应用和对象敏感信息 |
| 未接入依赖 | 展示“依赖未接入监控”，不计入业务异常，但计入接入风险 |
| 采集异常 | 展示数据质量标签和最近成功采集时间 |
| 第三方依赖 | 若无内部对象详情，仅展示探活指标和告警入口 |
| 无应用权限 | 不展示应用详情和依赖区 |

### 9.8 空、加载、异常、未接入

| 状态 | 文案 | 主操作 |
| --- | --- | --- |
| 无依赖 | 当前应用暂无已登记依赖。 | 添加或同步依赖 |
| 无匹配依赖 | 未找到符合条件的依赖对象。 | 重置筛选 |
| 加载状态 | 正在加载应用依赖状态... | 无 |
| 数据源异常 | 部分依赖数据源暂不可用，依赖状态可能不是最新。 | 重试 |
| 未接入状态 | 部分依赖尚未接入监控，请优先补齐核心依赖接入。 | 查看接入指引 |

### 9.9 验收点

1. 应用详情依赖区能展示数据库、缓存、MQ、网关、第三方服务等依赖类型。
2. 依赖表格能按类型、状态、环境、当前告警、接入状态筛选。
3. 每个依赖展示差异化关键指标、当前告警、负责人、接入状态和更新时间。
4. 点击依赖可进入中间件/数据库详情，点击指标和告警能带入应用与依赖上下文。
5. 有应用权限但无依赖全量权限时，只展示与当前应用相关的信息。

## 10. 通用验收清单

1. 中间件列表、数据库列表、中间件详情、数据库详情、指标查询增强、告警详情增强、应用详情依赖区均覆盖筛选项、表格字段、关键指标、状态、跳转上下文、权限和验收点。
2. 所有页面和模块均遵循现有状态字典：正常、预警、异常、严重、未知、未接入、采集异常、受限。
3. 未接入不展示误导性 0 值，不计入业务异常统计，但计入接入风险。
4. 采集异常必须展示异常来源、影响模块和最近成功采集时间。
5. 所有搜索、下拉、列表、统计、趋势、导出和 URL 直访均按应用授权、对象授权或基础设施授权过滤。
6. 共享中间件和数据库不得泄露未授权应用、库表、队列、Topic、SQL、连接信息和敏感参数。
7. 从告警、中间件/数据库详情、应用依赖区、指标查询之间跳转时，必须携带对象、环境、时间范围、来源页面和返回入口。
8. 导出生产数据、慢 SQL、对象清单、指标明细和告警处理记录时，必须按现有导出统一规则进行权限校验、二次确认、脱敏和审计。
9. 空、加载、异常、无权限和未接入状态必须保留筛选上下文，并提供重置、重试、申请权限或接入指引入口。
10. 常规指标查询响应时间不超过 3 秒；大范围查询提示降采样，超量导出进入后台任务。
