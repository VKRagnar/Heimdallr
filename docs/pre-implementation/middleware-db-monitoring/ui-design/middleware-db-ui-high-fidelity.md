# 中间件与数据库监控 UI 高保真设计说明

## 1. 文档定位

本文用于补齐企业级统一监控平台中“中间件与数据库监控”的 UI 高保真说明，承接现有 `ui-design` 规则体系，适用于后续设计稿绘制、前端页面搭建、交互评审和测试验收。

覆盖对象：

- 数据库：MySQL、PostgreSQL、Oracle、SQL Server、Redis、MongoDB、Elasticsearch 等。
- 中间件：Kafka、RabbitMQ、RocketMQ、Nacos、Zookeeper、Consul、网关、缓存、搜索、任务调度等。
- 关联能力：依赖拓扑、依赖摘要、指标趋势、告警入口、日志入口、慢 SQL、队列积压、消费者状态、数据源异常、权限受控。

统一设计约束：

1. 继承全局框架：顶部栏 56px、左侧导航 216px、内容区桌面 24px 内边距、模块间距 16px。
2. 采用专业、克制、高密度工作台布局，不做营销式大屏或装饰化拓扑。
3. 状态、告警级别、权限、导出、审计、数据源异常遵循 `ui-design/foundation-rules/foundation-rules.md`。
4. 颜色、字体、表格、筛选、图表、空态、无权限态遵循 `ui-design/visual-system/visual-system.md`。
5. 所有对象、指标、日志、慢 SQL、队列和拓扑均按应用授权与基础设施授权过滤；无权限时不泄露对象名称、数量、连接串、库表、Topic、Consumer Group 或慢 SQL 内容。

## 2. 信息架构与页面入口

### 2.1 导航位置

建议在左侧一级导航中新增或归入“中间件与数据库”，位于“服务器监控”之后、“日志中心”之前。若一期导航不新增一级入口，可在“应用监控 / 资源依赖”或“指标中心 / 对象类型”中提供同等入口。

页面集合：

| 页面 | 目标 | 主要用户 |
| --- | --- | --- |
| 中间件与数据库列表 | 统一查看数据库、中间件实例健康、接入、告警、关键指标 | 应用负责人、运维/SRE、值班人员 |
| 对象详情 | 定位单个数据库或中间件对象的健康、依赖、指标、日志和告警 | 运维/SRE、应用负责人 |
| 依赖拓扑 / 依赖摘要 | 判断应用与数据库、中间件之间的影响范围和故障传播方向 | 研发负责人、SRE |
| 指标图表 | 查看连接、延迟、错误、容量、吞吐、积压等指标趋势 | 运维/SRE、值班人员 |
| 慢 SQL / 队列积压入口 | 快速进入数据库慢 SQL、锁等待、队列积压、消费者滞后证据 | DBA、SRE、应用负责人 |

### 2.2 页面间上下文

跨页跳转必须保留以下上下文：

| 字段 | 说明 |
| --- | --- |
| `sourcePage` | 来源页：middlewareDbList、middlewareDbDetail、dependencyTopology、alertDetail、logQuery、metricTrend |
| `objectType` | database、cache、mq、registry、gateway、search、scheduler |
| `objectId` / `objectName` | 有权限时展示名称；无权限不回显 |
| `appId` / `appCode` | 关联应用 |
| `env` | 环境 |
| `instanceId` / `nodeId` | 实例、节点、Broker、Shard、Consumer 实例 |
| `metricCodes` | 指标编码集合 |
| `topic` / `queue` / `consumerGroup` | 消息队列上下文 |
| `database` / `schema` / `sqlFingerprint` | 数据库慢 SQL 上下文 |
| `alertId` | 告警 ID |
| `traceId` / `requestId` | 链路和请求标识 |
| `startTime` / `endTime` | 时间窗口 |
| `backFilter` | 返回来源筛选条件 |

来源提示条示例：

```text
来源：告警 ALM-20260426-012 / payment-db / 生产 / 连接数过高 / 10:00-10:30  [返回告警] [清除来源]
```

## 3. 全局页面布局

### 3.1 页面骨架

```text
顶部全局栏
左侧导航
内容区：
  页面标题区：面包屑 / 标题 / 对象状态 / 环境 / 更新于 / 页面操作
  筛选区或上下文条：对象、环境、类型、状态、负责人、时间范围、查询
  数据质量提示：指标源、日志源、链路源、Agent、采集延迟、最近成功时间
  主工作区：列表、详情双栏、拓扑、图表、表格证据
  底部信息：分页、查询耗时、采样粒度、导出任务入口
```

### 3.2 详情页布局

对象详情采用 `8 + 4` 结构：

- 左侧 8 列为证据区：核心指标、趋势图、慢 SQL / 队列积压、节点表、日志和告警。
- 右侧 4 列为摘要区：健康摘要、依赖摘要、负责人、接入状态、快捷入口、最近事件。

详情页标题区必须展示：

```text
对象名称 / 类型 / 环境 / 健康状态 / 接入状态 / 更新于 HH:mm:ss
```

### 3.3 按钮层级

| 区域 | 主按钮 | 次按钮 / 文本按钮 |
| --- | --- | --- |
| 筛选区 | 查询 | 重置、保存视图、刷新 |
| 列表页标题区 | 无固定主按钮 | 导出、查看拓扑、保存视图 |
| 详情页标题区 | 查看告警或查看日志，按对象风险决定 | 指标趋势、依赖拓扑、慢 SQL、队列积压 |
| 告警处理区 | 按告警生命周期展示唯一主动作 | 添加备注、转派、关闭、查看审计 |
| 图表区 | 查询 | 导出图片、收藏指标组合 |

## 4. 中间件与数据库列表页

### 4.1 页面目标

帮助用户在授权范围内快速判断哪些数据库或中间件对象异常、影响哪些应用、是否存在接入异常、下一步应进入告警、日志、指标、慢 SQL 还是队列积压。

### 4.2 首屏优先级

1. 授权对象总数、严重/异常对象数、采集异常数、未接入数。
2. 对象类型、环境、状态、负责人、关联应用核心筛选。
3. 风险优先排序的对象表格。
4. 详情、告警、指标、日志、慢 SQL / 队列积压入口。

### 4.3 布局

```text
中间件与数据库 / 对象列表                 授权对象 86 个 / 更新于 10:31:20
[刷新] [保存视图] [导出]

对象名称/IP  类型  环境  状态  关联应用  负责人  接入状态  时间范围  [查询] [重置]
高级：集群、区域、标签、版本、角色、端口、数据源状态、是否我负责、仅看生产

全部 86 | 严重 2 | 异常 8 | 预警 16 | 正常 52 | 采集异常 5 | 未接入 3
已选 4 项 [批量查看告警] [批量查看指标] [批量导出]

对象表格
分页 / 查询耗时 / 最近成功采集时间
```

### 4.4 筛选器

| 筛选器 | 控件 | 默认值 | 高保真要求 |
| --- | --- | --- | --- |
| 对象名称/IP | 搜索框 | 空 | 支持实例名、集群名、IP、端口、对象 ID |
| 类型 | 多选下拉 | 全部 | 数据库、缓存、消息队列、注册中心、网关、搜索、调度 |
| 环境 | 多选下拉 | 全部授权环境 | 生产标签轻微强调 |
| 健康状态 | 多选标签 | 全部 | 正常、预警、异常、严重、未知 |
| 关联应用 | 搜索多选 | 空 | 仅返回授权应用 |
| 负责人 | 搜索下拉 | 全部 | 支持“我负责”快捷项 |
| 接入状态 | 多选下拉 | 全部 | 指标已接入、日志已接入、仅指标、仅日志、未接入、采集异常 |
| 数据源状态 | 高级筛选 | 全部 | 正常、延迟、异常、停用、验证中、未知 |
| 集群/分组 | 高级筛选 | 全部 | 按集群、业务线、区域、机房过滤 |
| 时间范围 | 快捷时间 | 最近 1 小时 | 列表指标摘要按该窗口计算 |

### 4.5 表格列

| 列 | 展示 | 排序 | 备注 |
| --- | --- | --- | --- |
| 对象名称 | 主标题 + 对象 ID / 地址 | 支持 | 点击进入详情，不可隐藏 |
| 类型 | 数据库、中间件类型标签 | 支持 | 如 MySQL、Redis、Kafka |
| 环境 | 标签 | 支持 | 生产突出 |
| 集群/角色 | 集群名 + 主从/节点角色 | 支持 | 主库、从库、Broker、NameServer、Shard |
| 健康状态 | 状态标签 | 默认 | 按全局健康优先级聚合 |
| 数据质量 | 接入/采集状态标签 | 支持 | 业务异常与采集异常并存时必须分开展示 |
| 关联应用 | 授权应用前 2 个 + 更多 | 支持 | 未授权应用不展示名称 |
| 关键指标 | 类型相关摘要 | 支持 | 数据库连接数、Redis 内存、Kafka 积压等 |
| 当前告警 | 最高级别 + 数量 | 支持 | 点击跳告警列表 |
| 慢 SQL / 积压 | 数量或峰值 | 支持 | 数据库显示慢 SQL；MQ 显示积压 |
| 负责人 | 主负责人 | 支持 | 联系方式脱敏 |
| 更新时间 | 最近采集时间 | 支持 | 延迟时标注 |
| 操作 | 详情、告警、指标、日志、更多 | 不支持 | 固定右侧 |

### 4.6 行内操作

| 操作 | 出现条件 | 跳转上下文 |
| --- | --- | --- |
| 详情 | 有对象查看权限 | 对象 ID、类型、环境、时间范围、返回筛选 |
| 告警 | 有告警查看权限 | 对象 ID、未恢复优先、当前时间窗口 |
| 指标 | 指标已接入 | 对象 ID、类型默认指标组、最近 6 小时 |
| 日志 | 日志已接入 | 对象 ID、环境、最近 1 小时 |
| 慢 SQL | 数据库对象且有权限 | 数据库、实例、时间范围、排序为耗时 |
| 队列积压 | MQ 对象且有权限 | Topic/Queue、Consumer Group、时间范围 |
| 依赖拓扑 | 有依赖查看权限 | 对象与关联应用、上下游一跳 |

### 4.7 状态文案

| 场景 | 文案 | 主操作 |
| --- | --- | --- |
| 无匹配对象 | 未找到符合条件的中间件或数据库对象。请调整筛选条件后重试。 | 重置筛选 |
| 无授权对象 | 当前账号暂无可查看的中间件与数据库对象。 | 申请对象权限 |
| 未接入监控 | 该对象尚未接入指标或日志，健康状态可能不完整。 | 查看接入指引 |
| 采集异常 | 该对象监控采集异常，列表展示最近一次成功采集数据。 | 重试 |

## 5. 对象详情页

### 5.1 页面目标

在单个数据库或中间件对象维度，展示健康、接入、依赖、指标、告警、日志、慢 SQL 或队列积压，帮助用户判断异常来源和影响范围。

### 5.2 首屏优先级

1. 对象名称、类型、环境、健康状态、负责人、主要操作。
2. 接入状态：指标源、日志源、链路源、Agent 或 exporter。
3. 核心指标卡：根据对象类型展示关键指标。
4. 依赖摘要：上游应用、下游资源、受影响告警。
5. 告警、日志、慢 SQL / 队列积压快捷入口。

### 5.3 布局

```text
页面标题：对象详情 / payment-db              异常 生产 [查看告警] [指标趋势] [日志]
基本信息：类型 MySQL / 集群 pay-cluster / 主库 / 负责人 / 版本 / 地址脱敏
接入状态：Prometheus 正常 / 日志正常 / Exporter 延迟 / 链路未接入

左侧证据区：
  核心指标卡
  主趋势图
  Tab：概览 / 节点 / 依赖 / 告警 / 日志 / 慢 SQL 或队列积压 / 接入状态

右侧摘要区：
  健康摘要
  依赖摘要
  数据源状态
  最近事件
  快捷入口
```

### 5.4 核心指标卡

| 对象类型 | 指标卡 |
| --- | --- |
| 关系型数据库 | 连接使用率、QPS/TPS、慢 SQL 数、锁等待、主从延迟、CPU/内存 |
| Redis | 内存使用率、命中率、QPS、连接数、淘汰 Key、复制延迟 |
| Kafka/RocketMQ/RabbitMQ | Topic 数、生产速率、消费速率、积压量、消费者在线率、失败重试 |
| 注册中心/配置中心 | 实例数、健康实例、注册延迟、推送失败、节点可用性 |
| 网关 | QPS、错误率、P95/P99、上游失败、限流次数 |
| Elasticsearch | 集群健康、查询延迟、索引写入、Shard 异常、磁盘水位 |

指标卡高度 88px，异常数值使用状态色，仅高亮数值和标签，不整卡染色。点击卡片进入指标趋势并带入对应指标。

### 5.5 Tab 内容

| Tab | 内容 | 高保真要求 |
| --- | --- | --- |
| 概览 | 关键趋势、最近告警、依赖摘要、最近事件 | 默认展示，首屏可完成风险判断 |
| 节点 | 实例、Broker、Shard、Replica、主从节点 | 表格行高 40px，状态与角色固定列 |
| 依赖 | 上游应用、下游资源、调用关系、影响范围 | 与拓扑互通，支持一跳和二跳 |

## 6. 依赖拓扑与依赖摘要

### 6.1 页面目标

帮助用户判断“哪些应用依赖该数据库或中间件、当前异常影响哪些上游、故障是否由下游资源或中间件传播”，并提供到详情、告警、日志、指标的短路径。

### 6.2 拓扑布局

```text
标题：依赖拓扑 / payment-db / 生产          [返回详情] [切换摘要] [刷新]
筛选：对象类型  层级 一跳/二跳  状态  应用  时间范围  [查询]

左侧：拓扑画布
右侧：选中节点详情 / 依赖摘要 / 当前告警 / 快捷入口
底部：图例、数据来源、最近更新时间、隐藏无权限节点说明
```

### 6.3 视觉规则

| 元素 | 高保真要求 |
| --- | --- |
| 节点 | 应用、数据库、中间件、服务器使用不同线性图标 + 类型标签 |
| 状态 | 节点边框和状态标签表达健康，不用大面积填充 |
| 边 | 调用、读写、生产、消费、注册、配置拉取使用不同线型 |
| 风险 | P0/P1 节点可加左侧或顶部 3px 风险条 |
| 无权限节点 | 不展示真实名称；可显示“受限对象”占位且不计数 |
| 数据源异常 | 画布顶部提示，拓扑边标注“数据可能不完整” |

### 6.4 依赖摘要

详情页右侧和拓扑右侧均展示依赖摘要：

| 摘要项 | 展示 |
| --- | --- |
| 上游应用 | 授权应用数量、异常数量、最高告警级别 |
| 下游资源 | 数据库、中间件、外部服务数量和异常数量 |
| 当前影响 | 未恢复告警、错误率升高、队列积压、慢 SQL 峰值 |
| 风险路径 | `order-api -> Kafka topic.pay -> payment-worker -> payment-db` |
| 数据来源 | SkyWalking、Prometheus、日志解析、配置关系、手工维护 |
| 最近更新 | 最近采集时间；延迟时显示数据质量标签 |

### 6.5 交互

| 操作 | 表现 |
| --- | --- |
| 点击节点 | 右侧详情面板更新，展示状态、指标、告警、入口 |
| 点击边 | 展示依赖类型、流量、错误率、延迟、采集来源 |
| 双击节点 | 进入对象详情或应用详情 |
| 状态筛选 | 只高亮匹配节点，其余降透明，不改变权限过滤 |
| 层级切换 | 一跳默认；二跳需提示节点数量和加载耗时 |
| 返回详情 | 保留选中节点、时间范围和筛选 |

## 7. 指标图表

### 7.1 图表通用规则

指标图表遵循统一视觉规范：

- 图表必须展示单位、时间范围、采样粒度、数据源和最近采集时间。
- 缺失数据使用断线，不以 0 填充。
- 告警触发点使用 P0/P1/P2/P3 状态点，阈值线使用虚线。
- 数据源延迟时，在图表标题区显示“数据延迟”和最后数据点时间。

### 7.2 默认指标组

| 对象类型 | 默认图表 |
| --- | --- |
| 数据库 | 连接数/使用率、QPS/TPS、慢 SQL、锁等待、主从延迟、CPU/内存、磁盘 I/O |
| Redis | 内存使用、命中率、QPS、连接数、淘汰 Key、阻塞客户端、复制延迟 |
| Kafka/RocketMQ/RabbitMQ | 生产速率、消费速率、积压量、消费滞后、失败重试、Broker 负载 |
| 注册中心 | 注册实例数、健康实例数、心跳延迟、推送失败、节点可用性 |
| 网关 | QPS、错误率、P95/P99、上游 5xx、限流/熔断次数 |
| Elasticsearch | 查询延迟、索引写入、Shard 状态、JVM、磁盘水位、搜索错误 |

### 7.3 图表布局

```text
核心指标卡
主图：最关键风险指标，高 320-360px
双列辅助图：吞吐 / 延迟、容量 / 错误
事件列表：告警、发布、重启、配置变更、数据源异常
```

### 7.4 图表操作

| 操作 | 权限 | 表现 |
| --- | --- | --- |
| 查询 | 指标查看权限 | 刷新当前图表组 |
| 收藏指标组合 | 查看权限 | 保存个人视图 |
| 导出图片 | 图表导出权限 | 二次确认生产环境和敏感标签 |
| 导出数据 | 指标导出权限 | 超 10000 点进入后台任务 |
| 创建告警规则 | 规则配置权限 | 跳规则抽屉，带入对象和指标 |

## 8. 状态标签与风险表达

### 8.1 状态标签

| 场景 | 标签 | 语义 |
| --- | --- | --- |
| 健康 | 正常、预警、异常、严重、未知 | 对象最终健康状态 |
| 接入 | 指标已接入、日志已接入、仅指标、仅日志、未接入、采集异常、验证中 | 数据可用性 |
| 数据源 | 正常、延迟、异常、停用、验证中、未知 | Prometheus、日志源、Exporter、Agent |
| 数据库 | 主库、从库、只读、主从延迟、锁等待、慢 SQL | 角色和风险 |
| 消息队列 | 生产正常、消费延迟、积压、消费者离线、重试异常 | MQ 风险 |
| 权限 | 只读、脱敏、无权限、临时授权 | 访问控制 |

### 8.2 聚合优先级

对象主状态按全局健康状态优先级聚合。若业务健康异常与数据采集异常并存，主状态展示业务最高风险，旁边展示数据质量标签，例如：

```text
异常 / 指标采集异常 / 日志正常
```

未接入不计入业务异常统计，但计入接入风险；采集异常计入接入风险并阻止误判为正常。

## 9. 告警入口

### 9.1 入口位置

| 页面区域 | 入口 |
| --- | --- |
| 列表行 | 当前告警列、行内“告警” |
| 详情页标题区 | 查看告警 |
| 核心指标卡 | 有阈值异常时显示告警数量 |
| 图表事件点 | 点击告警触发点查看告警 |
| 拓扑节点 | 右侧面板展示未恢复告警入口 |

### 9.2 跳转规则

跳告警列表时带入：对象 ID、类型、环境、未恢复优先、时间范围、最高级别。跳告警详情时带入返回对象详情或拓扑的上下文。

### 9.3 告警类型建议

| 类型 | 典型告警 |
| --- | --- |
| 数据库 | 连接数过高、慢 SQL 激增、锁等待、主从延迟、磁盘空间不足、实例不可用 |
| Redis | 内存水位高、命中率下降、淘汰 Key 激增、连接数过高、复制延迟 |
| MQ | Topic 积压、Consumer Group 离线、消费滞后、消息重试失败、Broker 不可用 |
| 注册中心 | 节点不可用、健康实例下降、推送失败、心跳异常 |
| 网关 | 错误率高、P95/P99 升高、上游不可用、限流/熔断异常 |

## 10. 日志、慢 SQL 与队列积压入口

### 10.1 日志入口

日志入口出现在列表行、详情标题区、节点表、告警 Tab、拓扑节点面板。跳转时带入对象、环境、实例、时间窗口和日志级别，数据源未接入时显示未接入态而不是空白结果。

### 10.2 慢 SQL 入口

数据库对象展示“慢 SQL”入口：

| 模块 | 高保真要求 |
| --- | --- |
| 筛选 | 数据库、Schema、实例、SQL 指纹、耗时、时间范围 |
| 表格 | SQL 指纹、平均耗时、最大耗时、执行次数、扫描行数、影响库表、最近出现、操作 |
| 详情抽屉 | 脱敏 SQL 样例、执行计划入口、关联告警、指标时间点 |
| 权限 | SQL 文本、库表名、参数值默认脱敏；明文查看需敏感权限并审计 |
| 空态 | 当前时间范围暂无慢 SQL，可扩大时间范围或检查慢日志接入 |

### 10.3 队列积压入口

MQ 对象展示“队列积压”入口：

| 模块 | 高保真要求 |
| --- | --- |
| 筛选 | Topic/Queue、Consumer Group、实例、积压阈值、时间范围 |
| 表格 | Topic/Queue、Consumer Group、积压量、消费速率、生产速率、滞后时间、消费者在线、最近更新时间 |
| 详情抽屉 | 消费者实例、分区/队列明细、重试队列、死信队列、关联告警 |
| 状态 | 积压、消费者离线、重试异常、死信增长使用状态标签 |
| 空态 | 当前队列无明显积压 |

## 11. 权限表现

### 11.1 权限边界

| 场景 | 页面表现 |
| --- | --- |
| 无对象权限 | 不展示对象名称、地址、指标、日志、拓扑节点和统计数 |
| 有应用权限但无资源权限 | 可在应用依赖摘要中看到“受限资源”，不可查看详情 |
| 有对象只读权限 | 可查看指标、告警、日志摘要；处理、导出、配置入口隐藏或禁用 |
| 无日志权限 | 日志入口锁定，提示申请日志查看权限 |
| 无慢 SQL 明文权限 | SQL 文本、参数、库表敏感字段脱敏 |
| 无队列详情权限 | 只显示授权 Topic/Queue 和 Consumer Group |
| 值班临时授权 | 仅展示告警对象和触发窗口附近的数据 |
| URL 直访未授权对象 | 展示无权限状态页，不回显对象名称 |

### 11.2 控件策略

无权限会造成信息泄露时隐藏控件；用户需要理解能力不可用原因时置灰并显示 tooltip。例如导出按钮可置灰提示“当前角色暂无导出权限”，但未授权对象行不出现。

## 12. 数据源异常表现

### 12.1 异常类型

| 来源 | 异常表现 | 页面处理 |
| --- | --- | --- |
| 指标源 | Prometheus/Grafana 延迟、异常、停用 | 图表和列表展示最近成功采集时间，可局部重试 |
| 日志源 | 日志查询失败、字段聚合失败 | 日志入口提示结果可能不完整，主详情不阻塞 |
| Exporter/Agent | 心跳异常、版本过低、配置异常 | 行内数据质量标签 + 接入状态 Tab 展示原因 |
| 链路源 | SkyWalking 未接入或异常 | 拓扑边和 Trace 相关入口显示不可用 |
| 配置关系源 | CMDB/注册中心同步延迟 | 依赖拓扑提示“依赖关系可能不是最新” |

### 12.2 展示规则

- 数据源异常提示必须说明异常源、影响范围、最近成功时间和重试入口。
- 局部异常不阻塞整个页面；例如慢 SQL 查询失败时，指标和告警仍可查看。
- 加载中不显示 0 值，避免误判。
- 展示缓存数据时必须标注采集时间。

## 13. 响应式设计

| 断点 | 表现 |
| --- | --- |
| >= 1440px | 默认桌面布局，列表完整列，详情 `8 + 4`，图表双列，拓扑右侧摘要常驻 |
| 1200px-1439px | 次要表格列可隐藏，筛选区保持两行内，拓扑摘要可折叠 |
| 1024px-1199px | 详情改为单列，右侧摘要移至顶部折叠面板，图表单列 |
| 768px-1023px | 左侧导航折叠，列表保留对象、类型、状态、关键指标、告警、操作 |
| < 768px | 列表改为摘要行/卡片，保留告警、日志、指标、慢 SQL/积压入口；复杂拓扑默认切换依赖摘要 |

移动端优先满足应急查看和处理，不承载完整拓扑编辑或复杂多指标对比。

## 14. 验收点

1. 只在授权范围内展示数据库、中间件对象、关联应用、Topic、Consumer Group、SQL 和拓扑节点。
2. 列表页具备对象类型、环境、状态、负责人、关联应用、接入状态、数据源状态、时间范围筛选。
3. 表格默认风险优先排序，严重、异常、采集异常和未接入语义清晰区分。
4. 详情页必须展示健康摘要、接入状态、核心指标、依赖摘要、告警入口、日志入口，以及慢 SQL或队列积压入口。
5. 依赖拓扑支持一跳/二跳、节点状态、边类型、选中节点摘要、无权限节点保护和数据源异常提示。
6. 指标图表必须展示单位、时间范围、采样粒度、阈值线、告警点、数据延迟和最近采集时间。
7. 数据库对象可进入慢 SQL，MQ 对象可进入队列积压；入口按对象类型和权限展示。
8. 告警入口能从列表、详情、图表、拓扑进入，并完整带入对象、环境、时间窗口和来源。
9. 日志、慢 SQL、队列积压中的敏感字段默认脱敏，明文查看、复制和导出均需权限与审计。
10. 数据源异常可局部重试，不把未接入或采集异常误判为业务正常。
11. URL 直访未授权对象不泄露对象名称、连接信息、指标值、SQL、队列名称或统计数。
12. 响应式下保留对象状态、关键指标、告警、日志、指标和慢 SQL/积压核心入口。
