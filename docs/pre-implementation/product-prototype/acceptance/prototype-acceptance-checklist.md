## 3. 产品原型通用验收标准

| 编号 | 验收项 | 验收标准 | 主要评审角色 |
| --- | --- | --- | --- |
| G-01 | 一期范围一致性 | 原型页面覆盖全局总览、应用列表、应用详情、服务器列表、服务器详情、日志查询、指标查询、告警规则、告警列表、告警详情、通知/联系人基础管理、用户权限基础管理 | 产品/研发/测试 |
| G-02 | 导航一致性 | 一级导航与信息架构一致；一期不应暴露空白的二期页面；二期能力可隐藏或标记为后续增强 | 产品 |
| G-03 | 排障优先 | 首页和详情页优先展示异常对象、影响范围、负责人、持续时间、处理入口、关联日志和指标 | 产品/运维 |
| G-04 | 3 次点击可达 | 高频任务从首页或一级导航进入后，3 次点击内可到达目标详情、日志、指标或告警处理入口 | 产品/测试 |
| G-05 | 筛选一致性 | 环境、时间范围、应用/服务器、负责人等筛选在列表和查询页保持统一命名与交互 | 产品/测试 |
| G-06 | 上下文传递 | 跨页面跳转需携带应用、环境、实例、服务器、时间范围、告警 ID 或指标等必要上下文 | 产品/研发/测试 |
| G-07 | 状态语义一致 | 正常、预警、异常、严重、未知，以及 P0/P1/P2/P3 告警级别在全平台含义一致 | 产品/测试/运维 |
| G-08 | 关键操作可识别 | 导出、创建/修改规则、启停规则、确认/处理/关闭告警、权限配置等操作在原型中明确入口和权限要求 | 产品/研发/测试 |
| G-09 | 安全与脱敏 | 手机号、敏感日志字段、生产数据、导出操作、敏感字段明文查看均有权限和脱敏说明 | 产品/安全/测试 |
| G-10 | 审计可追踪 | 规则修改、告警处理、权限变更、导出、接入配置变更在原型说明中明确需要审计 | 产品/研发/测试 |
| G-11 | 性能预期可表达 | 首页 5 秒内看到核心健康状态、默认 30 秒刷新、日志查询和指标查询的等待/超时状态有设计承接 | 产品/研发/测试 |
| G-12 | 术语一致 | 应用、实例、服务器、指标、告警规则、告警事件、联系人、值班组、数据源等术语在各页面一致 | 产品/研发 |

## 4. 页面覆盖矩阵

| 页面/模块 | 一期要求 | 原型验收点 | 必须覆盖状态 | 主要角色 |
| --- | --- | --- | --- | --- |
| 全局总览 | 排障视角首页、核心统计、活跃告警、待处理问题、异常排行、基础筛选 | 可在 5 秒内识别整体健康、P0/P1、异常对象、负责人和快捷处理入口；支持环境/业务线/部门/负责人/时间筛选 | 无数据、加载、数据源异常、仅授权范围 | 应用研发负责人、运维/SRE、业务负责人 |
| 应用列表 | 应用检索与状态总览 | 字段包含应用名称、编码、所属系统、业务线、环境、负责人、状态、实例数、最近发布时间、当前告警；支持详情/日志/指标/告警跳转 | 无匹配、加载、查询失败、未授权不展示 | 应用研发负责人、测试人员、运维/SRE |
| 应用详情 | 应用健康、实例、接口、运行时、依赖、最近告警 | 可定位异常实例或异常接口；可跳转日志、指标、服务器、告警详情 | 无指标/无日志、图表加载、指标源异常、无权限申请 | 应用研发负责人、运维/SRE、测试人员 |
| 服务器列表 | 主机资源与状态检索 | 字段包含主机名、IP、环境、机房/区域、负责人、CPU、内存、磁盘、网络、状态；支持分组和详情入口 | 无匹配、加载、查询失败、未授权不展示 | 运维/SRE |
| 服务器详情 | 资源趋势、进程端口、部署应用、告警 | 可查看 CPU/内存/磁盘/网络趋势、进程端口、部署应用和最近告警；可跳转应用、指标、告警 | 无进程/端口、图表加载、Agent 异常、敏感信息隐藏 | 运维/SRE、应用研发负责人 |
| 日志查询 | 应用日志检索、Trace ID、上下文、错误聚合、受控导出 | 支持应用、环境、实例、级别、时间、关键字、Trace ID/Request ID/业务字段；支持上下文、堆栈折叠、导出、从告警带参进入 | 无命中、查询中、超时、数据源异常、无导出权限 | 应用研发负责人、测试人员、运维/SRE |
| 指标查询 | 基础指标查询、详情、规则数据源 | 支持应用/服务器/指标类型/时间范围查询趋势；支持指标详情、创建告警规则、基础注册入口 | 无指标、图表加载、指标源异常、无权限指标隐藏 | 运维/SRE、应用研发负责人、业务负责人 |
| 告警规则 | 简单阈值规则配置 | 字段包含规则名称、对象、指标、环境、操作符、阈值、持续时间、检测周期、级别、生效时间、恢复条件、通知对象、通知渠道、启用状态 | 无规则、加载、保存失败、只读 | 运维/SRE、平台管理员 |
| 告警列表 | 告警事件筛选和处理入口 | 支持级别、状态、对象、应用/服务器、负责人、环境、时间、关键字筛选；提供详情、确认、处理等入口 | 无告警、加载、查询失败、仅授权告警 | 值班人员、运维/SRE、应用研发负责人 |
| 告警详情 | 告警闭环处理 | 展示摘要、触发规则、触发值、影响对象、指标趋势、关联日志、通知记录、处理记录；提供确认、处理中、备注、转派、静默、关闭入口 | 无关联日志/指标、模块加载、记录失败、无处理权限 | 值班人员、应用研发负责人、运维/SRE |
| 通知/联系人基础管理 | 联系人、负责人、渠道、模板、通知记录、值班组基础能力 | 联系人字段、负责人配置、渠道测试、通知记录和值班组入口清晰；手机号脱敏 | 无联系人、加载、测试通知失败、脱敏展示 | 平台管理员、运维/SRE |
| 用户权限基础管理 | 用户、角色、菜单权限、操作权限、应用数据权限、审计 | 用户/角色/权限配置抽屉完整；说明应用授权衍生日志、指标、告警、关联服务器可见范围 | 无用户/角色、加载、保存失败、仅管理员可管理 | 平台管理员、测试人员 |

## 5. 角色覆盖矩阵

| 角色 | 原型需覆盖的高频任务 | 必须可见信息 | 必须受控信息/操作 |
| --- | --- | --- | --- |
| 平台管理员 | 管理用户、角色、权限、数据源、通知渠道、字典、审计 | 全部菜单、全部应用、全部环境、全部审计入口 | 敏感日志明文仍需单独授权；关键配置变更需审计 |
| 运维/SRE | 巡检基础设施、维护告警规则、处理生产故障、维护数据源 | 首页、服务器、应用、日志、指标、告警、接入配置、通知记录 | 权限变更需管理员授权；导出和规则变更需审计 |
| 应用研发负责人 | 查看负责应用状态、实例、日志、接口性能和本应用告警 | 授权应用、实例、日志、指标、告警、关联服务器摘要 | 非授权应用日志、生产敏感字段、全局权限配置不可见 |
| 业务负责人 | 查看业务指标、可用性、重大故障和报表入口 | 授权业务线指标、服务可用性、重大告警、业务指标卡片 | 技术日志明细、服务器敏感配置、规则修改受控 |
| 测试人员 | 在测试/预发环境查看应用状态、日志、接口异常 | 授权测试/预发应用、日志、接口指标、实例状态 | 生产环境日志和指标、告警规则修改不可见或只读 |
| 值班人员 | 接收、确认、处理、备注、转派、升级告警 | 值班组覆盖告警、影响对象、关联日志/指标、处理记录 | 非值班范围数据、系统配置不可见 |
| 只读用户 | 查看授权范围内看板、列表、详情 | 授权范围内首页、列表、详情和筛选 | 导出、规则修改、告警处理、权限配置不可操作 |

## 6. 核心任务路径验收

| 路径 | 起点与终点 | 验收标准 | 评审关注点 |
| --- | --- | --- | --- |
| 全局巡检 | 首页总览 -> 应用详情/服务器详情/告警详情 | 筛选环境/业务线后能识别异常对象；异常应用、服务器、活跃告警均可点击进入对应详情 | 首页是否足够排障；上下文是否保留 |
| 应用故障定位 | 首页/应用列表/告警详情 -> 应用详情 -> 日志/指标/告警 | 应用详情能展示健康、实例、接口、依赖和最近告警；从异常实例或告警可带参进入日志和指标 | 是否能定位到异常实例、接口、Trace ID 和时间窗口 |
| 告警处理 | 告警列表 -> 告警详情 -> 确认/处理/恢复/关闭 | 告警详情展示触发规则、触发值、通知记录、处理记录、关联日志和指标趋势；处理动作记录操作人和时间 | 一期基础闭环是否够用；二期操作是否被合理预留 |
| 日志查询 | 日志中心或告警详情 -> 日志查询 -> 上下文/导出/关联跳转 | 可按应用、环境、实例、级别、时间、关键字、Trace ID 查询；支持上下文、堆栈折叠、错误聚合和受控导出 | 查询条件是否完整；导出和敏感字段是否受控 |
| 服务器高负载定位 | 首页/服务器列表 -> 服务器详情 -> 部署应用/指标/告警 | 服务器详情可查看资源趋势、进程端口、部署应用；可跳转应用详情、指标趋势和告警详情 | 高负载原因是否能继续追踪到应用 |
| 新应用接入 | 接入管理 -> 应用接入 -> 应用详情/指标/日志/告警 | 原型或评审说明中应覆盖接入申请、审核、基础信息、环境实例、负责人、健康检查、指标/日志/默认规则、验证采集状态 | 低保真原型当前未展开接入管理页面，需确认是否补充 |
| 权限配置 | 系统管理 -> 用户/角色 -> 权限配置 | 可配置菜单、操作、应用数据权限；说明日志、指标、告警、关联服务器按应用授权衍生 | 测试用例是否能覆盖授权、未授权、只读、管理员 |
| 通知对象维护 | 通知管理 -> 联系人/负责人/值班组/渠道 | 告警规则可选择负责人和值班组；联系人渠道完整性、测试通知、通知记录可评审 | 一期通知渠道优先级和失败处理边界需确认 |

## 7. 权限验收清单

| 编号 | 权限项 | 验收标准 | 责任角色 |
| --- | --- | --- | --- |
| P-01 | 菜单权限 | 不同角色看到的一级导航和页面入口与角色定位一致 | 产品/测试 |
| P-02 | 操作权限 | 导出、新建规则、修改规则、启停规则、确认告警、处理告警、关闭告警、管理用户等操作有权限说明 | 产品/研发/测试 |
| P-03 | 应用数据权限 | 一期以应用授权为主；未授权应用在列表、搜索、下拉、详情入口中不可见或提示无权限 | 产品/研发/测试 |
| P-04 | 衍生数据权限 | 日志、指标、告警、关联服务器按应用授权衍生过滤；告警详情只展示必要时间窗口和对象范围 | 产品/研发/测试 |
| P-05 | 环境权限 | 生产环境数据权限高于测试/预发；测试人员默认不可查看生产日志和指标 | 产品/测试 |
| P-06 | 导出权限 | 日志、报表、列表导出需要独立权限；无权限时隐藏或置灰并给出原因 | 产品/测试 |
| P-07 | 敏感字段权限 | 手机号脱敏展示；敏感日志字段明文查看需授权；未授权时应脱敏或不可见 | 产品/安全/测试 |
| P-08 | 告警处理权限 | 只有责任人、值班人员、运维或授权用户可确认、处理、转派、关闭告警 | 产品/测试/运维 |
| P-09 | 系统管理权限 | 用户、角色、权限配置仅平台管理员可管理 | 产品/测试 |
| P-10 | 审计权限 | 审计日志入口和可见范围需受管理员或审计角色控制 | 产品/测试 |

## 8. 状态验收清单

| 状态类型 | 需覆盖页面 | 验收标准 |
| --- | --- | --- |
| 空状态 | 首页、应用列表、服务器列表、日志查询、指标查询、告警规则、告警列表、联系人、用户权限 | 空状态文案能说明原因，并提供接入、调整筛选、刷新或创建入口 |
| 加载状态 | 首页卡片、列表、图表、日志结果、告警详情模块 | 加载中不误导为 0 数据；长耗时查询有进度或等待提示 |
| 查询失败 | 应用列表、服务器列表、日志查询、指标查询、告警列表 | 展示失败原因摘要和重试入口 |
| 数据源异常 | 首页、应用详情、服务器详情、日志查询、指标查询 | 明确是 Prometheus/Grafana、SkyWalking、日志源、Agent 或其他数据源异常 |
| 权限不足 | 应用详情、服务器详情、日志导出、规则修改、告警处理、用户权限 | 提示无权限或申请权限入口；未授权数据不泄露名称、日志内容和敏感字段 |
| 部分数据缺失 | 应用详情、服务器详情、告警详情 | 指标、日志、依赖、进程端口缺失时局部展示缺失原因，不影响其他模块查看 |
| 通知失败 | 告警详情、通知记录、通知渠道 | 展示渠道、接收人、失败原因、重试状态或后续处理入口 |
| 告警生命周期状态 | 告警列表、告警详情 | 已触发、已通知、已确认、处理中、已恢复、已关闭、已升级、已静默状态含义和可操作动作明确 |
| 规则状态 | 告警规则 | 启用、停用、草稿、保存失败等状态明确；修改规则需要审计 |
| 接入状态 | 接入管理、应用列表/详情 | 已接入 Prometheus/Grafana、已接入 SkyWalking、仅日志接入、仅指标接入、未接入监控、Agent 异常等状态可展示 |

## 9. 数据源接入验收清单

| 数据源/接入对象 | 原型验收点 | 评审结论 |
| --- | --- | --- |
| Prometheus/Grafana | 支持作为服务器、应用和基础指标来源；数据源异常时能在页面提示采集异常 | 待评审 |
| SkyWalking | 支持标记少量应用已接入；应用详情或指标查询中能承接链路/应用性能数据入口 | 待评审 |
| 日志源 | 日志查询支持应用、环境、实例、级别、时间、关键字、Trace ID 和上下文；从告警跳转日志带入时间窗口 | 待评审 |
| Agent | 服务器详情能体现 Agent 安装、心跳或采集异常状态；Agent 异常不应误判为业务正常 | 待评审 |
| 未接入应用 | 应用接入状态可标记为未接入监控；首页和应用详情有无数据/接入引导处理 | 待评审 |
| 仅日志接入 | 指标区域展示未接入或无数据原因，日志功能可用 | 待评审 |
| 仅指标接入 | 日志区域展示未接入或无数据原因，指标和告警规则可用 | 待评审 |
| 数据源配置变更 | 接入配置变更需有审计说明；数据源状态应可被管理员或运维查看 | 待评审 |
| 新应用接入流程 | 覆盖申请、审核、基础信息、环境实例、负责人、健康检查、指标/日志接入、默认规则、采集验证 | 待评审 |
| API/Webhook 基础入口 | 一期如保留 API 接入或 Webhook 入口，需明确是基础能力还是二期增强 | 待评审 |

## 13. 验收通过条件

1. 页面覆盖矩阵中一期页面均达到“线框、字段、操作、状态、跳转、权限”六项可评审。
2. 角色覆盖矩阵中各角色至少有一条完整高频任务路径，并明确可见与受控信息。
3. 核心任务路径中全局巡检、应用故障定位、告警处理、日志查询、服务器高负载定位、权限配置均可走通。
4. 告警规则满足一期简单阈值规则配置，并支持负责人和值班组作为通知对象。
5. 权限验收清单覆盖菜单、操作、应用数据、衍生日志/指标/告警/服务器、导出、敏感字段和审计。
6. 状态验收清单覆盖空、加载、异常、权限不足、数据源异常、通知失败和告警生命周期状态。
7. 数据源接入验收清单覆盖 Prometheus/Grafana、SkyWalking、日志源、Agent、未接入、仅日志、仅指标等场景。
8. 待确认问题均有责任方和优先级；高优先级问题不影响原型评审结论时，需记录为带问题通过。
