# 配置管理链路产品原型设计

## 1. 原型定位

本文档基于 `demand/monitoring-platform-requirements.md`、`architecture/information-architecture.md`、`prototype/low-fidelity-prototype.md` 输出企业级统一监控平台一期“配置管理链路”中高保真产品原型说明。

设计范围：

- 告警规则配置
- 值班组与联系人管理
- 通知渠道管理
- 用户、角色与应用授权
- 应用接入与数据源管理

一期目标是让平台管理员、运维/SRE、应用研发负责人可以完成“应用接入 -> 数据源确认 -> 告警规则配置 -> 通知对象和值班组选择 -> 按应用授权 -> 告警可触达”的基础闭环。

## 2. 全局配置管理框架

### 2.1 页面入口

配置管理相关能力分布在三个一级导航下，页面之间保留上下文跳转：

| 一级导航 | 二级页面 | 页面定位 |
| --- | --- | --- |
| 告警中心 | 告警规则 | 配置简单阈值规则、通知对象、通知渠道和启停状态 |
| 通知与值班 | 联系人、值班组、通知渠道、通知记录 | 维护告警触达对象和发送通道 |
| 接入管理 | 应用接入、数据源管理、Agent 管理 | 管理应用监控接入状态和采集源 |
| 系统管理 | 用户管理、角色管理、权限管理、操作审计 | 管理菜单、操作和应用数据权限 |

### 2.3 通用交互约定

| 类型 | 约定 |
| --- | --- |
| 筛选条件 | 环境、应用、业务线、负责人、状态为配置链路通用筛选项 |
| 权限继承 | 日志、指标、告警、关联服务器可见范围从应用授权继承 |
| 审计记录 | 规则修改、渠道修改、值班组变更、权限变更、接入配置变更必须记录审计 |
| 保存动作 | 复杂表单支持“保存草稿”和“保存并启用”；草稿不参与告警检测 |
| 数据脱敏 | 手机号、邮箱、Webhook 密钥、Token 默认脱敏展示 |
| 反馈方式 | 保存成功使用轻提示；校验失败定位到字段；高风险操作使用确认弹窗 |

## 3. 告警规则配置

### 3.1 页面目标

让运维/SRE 或有权限的应用负责人可以为授权应用、服务器、数据库、中间件或业务指标配置一期简单阈值规则，并选择应用负责人和值班组作为通知对象。

一期只支持单指标阈值规则：选择对象、选择指标、设置比较条件、阈值、持续时间、检测周期、告警级别、生效时间、恢复条件、通知对象和通知渠道。

### 3.2 告警规则列表布局

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 告警中心 / 告警规则                              [新建规则] [批量启用/停用] │
├──────────────────────────────────────────────────────────────────────────────┤
│ 关键字[规则名/对象] 环境[全部] 对象类型[全部] 应用[搜索] 级别[全部] 状态[全部] │
│ 通知对象[负责人/值班组] 数据源[Prometheus/Grafana/SkyWalking/其他] [查询]    │
├──────────────────────────────────────────────────────────────────────────────┤
│ 统计：全部 186 | 启用 152 | 停用 24 | 草稿 10 | 配置异常 3                  │
├──────────────────────────────────────────────────────────────────────────────┤
│ □ 规则名称 | 对象 | 环境 | 指标 | 条件 | 级别 | 通知对象 | 状态 | 最近触发 │
│   order-api错误率过高 | order-api | 生产 | error_rate | >5%持续5m | P1 | 负责人+交易值班组 | 启用 | 10:21 │
│ 操作：查看 | 编辑 | 复制 | 启停 | 触发记录 | 审计                         │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 3.3 告警规则字段表

| 字段 | 控件 | 必填 | 说明 |
| --- | --- | --- | --- |
| 规则名称 | 输入框 | 是 | 2-60 字，建议包含对象和异常类型 |
| 规则描述 | 多行输入 | 否 | 说明规则用途和处理建议 |
| 启用状态 | 开关 | 是 | 草稿、启用、停用 |
| 对象类型 | 单选 | 是 | 应用、服务器、数据库、中间件、业务指标 |
| 环境 | 下拉单选/多选 | 是 | 生产、预发、测试、开发 |
| 监控对象 | 搜索选择器 | 是 | 仅展示当前用户授权范围内对象 |
| 对象范围 | 单选 | 是 | 单对象、应用下全部实例、服务器分组 |
| 指标来源 | 下拉 | 是 | Prometheus、Grafana、SkyWalking、平台内置指标 |
| 指标 | 搜索选择器 | 是 | 只展示已接入且可用于告警的指标 |
| 聚合方式 | 下拉 | 是 | 平均值、最大值、最小值、P95、P99、原始值 |
| 触发条件 | 下拉 | 是 | 大于、小于、等于、不等于 |
| 阈值 | 数字输入 | 是 | 支持整数、小数和百分比 |
| 持续时间 | 下拉/数字 | 是 | 1 分钟、3 分钟、5 分钟、10 分钟、自定义 |
| 检测周期 | 下拉 | 是 | 30 秒、1 分钟、3 分钟、5 分钟 |
| 告警级别 | 单选 | 是 | P0 紧急、P1 严重、P2 一般、P3 提示 |
| 生效时间 | 单选 + 时间段 | 是 | 全天、工作日、指定时间段 |
| 恢复条件 | 自动/自定义 | 是 | 默认指标不再满足触发条件即恢复 |
| 通知对象 | 复选 | 是 | 应用负责人、备份负责人、值班组 |
| 值班组 | 搜索选择器 | 条件必填 | 通知对象包含值班组时必填 |
| 通知渠道 | 复选 | 是 | 邮件、短信、企业微信、钉钉、电话、Webhook |
| 重复通知间隔 | 下拉 | 是 | 一期用于避免短时间刷屏，默认 10 分钟 |
| 处理建议 | 多行输入 | 否 | 告警详情和通知消息中展示 |

### 3.4 表单校验

| 校验项 | 规则 |
| --- | --- |
| 规则名称 | 同一环境、同一对象下不可重名；超过 60 字提示缩短 |
| 监控对象 | 无应用授权时不可选择；对象未接入指标时提示先完成接入 |
| 指标 | 指标必须存在最近采集数据；无数据指标可保存草稿但不能启用 |
| 阈值 | 必须为合法数字；百分比指标范围为 0-100 |
| 持续时间 | 必须大于等于检测周期 |
| 检测周期 | P0/P1 默认不超过 1 分钟；超出时提示风险但可由管理员确认 |
| 通知对象 | 至少选择应用负责人或一个值班组 |
| 值班组 | 已停用、无成员、无有效联系方式的值班组不可启用 |
| 通知渠道 | P0 必须包含电话或短信；P1 必须包含短信或 IM |
| Webhook 渠道 | 必须通过连通性测试后才可启用 |
| 权限 | 无“新建规则/修改规则”权限时表单只读 |

### 3.5 简单阈值规则配置流程

```text
1. 点击“新建规则”
2. 选择对象类型和环境
3. 选择授权范围内的监控对象
4. 选择指标来源和具体指标
5. 配置触发条件：聚合方式、比较符、阈值、持续时间、检测周期
6. 设置告警级别、生效时间和恢复条件
7. 选择通知对象：应用负责人、备份负责人、值班组
8. 选择通知渠道并查看渠道可用性
9. 点击“规则预览”，查看自然语言规则描述
10. 保存草稿或保存并启用
```

规则预览示例：

```text
当生产环境 order-api 的 error_rate 在 5 分钟内平均值持续大于 5% 时，触发 P1 严重告警；每 1 分钟检测一次；通知应用负责人张三、备份负责人李四和交易系统值班组，通过短信、企业微信发送；指标恢复到 5% 及以下后自动恢复。
```

### 3.6 值班组选择交互

| 场景 | 交互 |
| --- | --- |
| 选择值班组 | 搜索框支持按值班组名称、业务线、负责人检索 |
| 查看覆盖范围 | 值班组卡片展示业务线、覆盖应用、当前值班人、下一值班人 |
| 冲突提示 | 当前时间无值班人时标记“排班缺失”，不可保存并启用 |
| 联系方式提示 | 当前值班人手机号或 IM 缺失时提示补全联系人 |
| 规则绑定 | 一个规则可绑定多个值班组，通知时按当前排班解析成员 |

### 3.7 关键状态设计

| 状态 | 展示 | 处理 |
| --- | --- | --- |
| 草稿 | 灰色标签 | 不参与检测，可继续编辑 |
| 启用 | 绿色标签 | 正常参与检测 |
| 停用 | 灰色标签 | 不触发告警，保留历史事件 |
| 配置异常 | 红色标签 | 数据源不可用、指标失效、通知对象无效时展示 |
| 无指标数据 | 黄色提示 | 可保存草稿，不可启用 |
| 权限不足 | 只读态 | 隐藏保存和启停操作 |

维护告警通知对象的基础信息，支持告警规则按应用负责人和值班组自动解析接收人。值班人员变更后，不需要逐条修改告警规则。

│ □ 姓名 | 账号 | 部门 | 手机号 | 邮箱 | 企业微信 | 钉钉 | 状态 | 操作        │

### 4.5 值班组字段表

| 字段 | 控件 | 必填 | 说明 |

### 4.6 值班组状态设计

| 状态 | 触发条件 | 页面表现 |
| --- | --- | --- |
| 正常 | 有成员、有当前值班人、联系方式完整 | 绿色标签 |
| 排班缺失 | 当前时间无法解析值班人 | 黄色标签，规则保存并启用时阻断 |
| 联系方式缺失 | 当前值班人缺少规则所需渠道 | 黄色标签，提示补全 |
| 停用 | 手动停用 | 灰色标签，不可被新规则选择 |
| 被规则引用 | 规则数大于 0 | 停用时二次确认并提示影响规则 |

## 5. 通知渠道管理

### 5.1 页面目标

配置平台可用的告警通知通道，保证不同级别告警能够通过合适渠道触达负责人和值班组。

### 5.2 通知渠道列表布局

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 通知与值班 / 通知渠道                                  [新增渠道] [测试全部] │
├──────────────────────────────────────────────────────────────────────────────┤
│ 渠道类型[全部] 状态[全部] 适用级别[全部] 关键字[输入] [查询]                │
├──────────────────────────────────────────────────────────────────────────────┤
│ 渠道名称 | 类型 | 适用级别 | 状态 | 最近测试 | 成功率 | 失败原因 | 操作      │
│ 企业微信机器人 | 企业微信 | P0/P1/P2 | 启用 | 10:00成功 | 99.2% | - | 编辑/测试/停用 │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 5.3 渠道字段表

| 字段 | 说明 |
| --- | --- |
| 渠道名称 | 平台内展示名称 |

| 重试策略 | 失败后重试次数和间隔 |
| 超时时间 | 单次发送超时时间 |
| 状态 | 启用、停用、异常 |

### 5.4 表单校验

| 渠道 | 必要校验 |
| --- | --- |
| 邮件 | SMTP 地址、端口、发件人、认证信息、测试收件人 |
| 短信 | 服务商、签名、模板 ID、密钥、测试手机号 |
| 企业微信/钉钉 | Webhook 地址、签名密钥、连通性测试 |
| 电话 | 服务商配置、呼叫模板、测试号码 |
| Webhook | URL 必须为 HTTPS；必须通过测试；响应码 2xx 视为成功 |

## 6. 用户权限与按应用授权

### 6.1 页面目标

支持平台管理员维护用户、角色、菜单权限、操作权限和应用数据权限。应用授权是一期数据权限核心，日志、指标、告警和关联服务器可见性从应用授权继承。

| --- | --- | --- |
| 菜单权限 | 首页、应用监控、服务器监控、日志中心、指标中心、告警中心、通知与值班、接入管理、系统管理 | 控制入口是否可见 |
| 操作权限 | 查看、导出、新建规则、修改规则、启停规则、处理告警、管理联系人、管理渠道、管理用户 | 控制按钮和 API 操作 |
| 数据权限 | 应用、应用组、业务线 | 一期以应用授权为主 |
| 环境约束 | 生产、预发、测试、开发 | 可作为附加条件限制 |
| 敏感权限 | 日志导出、敏感字段明文、Webhook 密钥查看 | 必须审计 |

### 6.5 按应用授权规则

| 被授权对象 | 可见范围 |
| --- | --- |
| 应用详情 | 授权应用的基础信息、实例、接口指标、最近告警 |
| 日志中心 | 授权应用产生的日志；敏感字段仍按敏感权限控制 |
| 指标中心 | 授权应用及其实例指标 |
| 告警中心 | 授权应用相关规则和告警事件 |
| 服务器监控 | 部署授权应用的服务器摘要；无服务器权限时隐藏进程、端口等敏感信息 |
| 接入管理 | 授权应用的接入状态可查看；修改接入配置需额外操作权限 |

### 6.6 权限校验与状态

| 场景 | 处理 |
| --- | --- |
| 用户无菜单权限 | 左侧导航不展示入口 |
| 用户有菜单但无数据权限 | 展示空状态“暂无授权应用”，提供申请权限入口 |
| 用户无操作权限 | 按钮隐藏或置灰，并显示权限说明 |
| 配置生产权限 | 二次确认并写入审计 |
| 禁用用户 | 立即失效登录态，保留历史操作记录 |

### 7.6 数据源字段与校验

| 字段 | 校验 |
| --- | --- |
| 数据源名称 | 同类型、同环境下唯一 |
| 数据源类型 | Prometheus、Grafana、SkyWalking、OpenTelemetry、ELK、Loki |
| 访问地址 | 必须为 HTTP/HTTPS URL |
| 鉴权方式 | 无、Basic、Token、Header；密钥脱敏 |

| 超时时间 | 1-30 秒 |
| 健康检查路径 | 保存前必须通过测试，异常可保存但不能绑定新应用 |
| 关联应用 | 数据源停用前提示受影响应用和告警规则 |

### 7.7 标准应用接入流程

```text
1. 进入“接入管理 / 应用接入”
2. 点击“新增接入”或选择未接入应用的“接入向导”
3. 填写应用基础信息：应用编码、环境、业务线、负责人
4. 配置健康检查地址
5. 选择指标数据源：Prometheus/Grafana
6. 可选配置链路数据源：SkyWalking
7. 可选配置日志数据源：ELK/Loki
8. 勾选默认告警规则模板
9. 点击“验证接入”
10. 验证通过后状态变为已接入，并可在应用详情、指标查询、告警规则中使用
```

## 9. 异常、空态与权限状态

| 页面 | 空状态 | 异常状态 | 权限状态 |
| --- | --- | --- | --- |
| 告警规则 | 无规则时展示“新建第一条阈值规则” | 指标失效、数据源异常、通知对象无效 | 无修改权限时只读 |
| 联系人 | 无联系人时提示导入或新增 | 联系方式不完整、测试通知失败 | 非管理员不可查看完整手机号 |
| 值班组 | 无值班组时提示创建并绑定规则 | 排班缺失、成员禁用、联系方式缺失 | 无管理权限不可编辑排班 |

| 用户权限 | 无授权应用时提示申请权限 | 用户同步失败、角色冲突 | 仅管理员可配置 |
| 应用接入 | 无应用时提示导入资产 | 数据源不可用、Agent 无心跳 | 无接入权限只可查看状态 |
| 数据源 | 无数据源时提示新增 Prometheus/Grafana | 健康检查失败、鉴权失败 | 鉴权信息脱敏不可见 |

## 10. 验收点

## 11. 一期与二期边界

| 能力 | 一期实现 | 二期增强 |
| --- | --- | --- |
| 告警规则 | 单指标简单阈值 | 组合条件、动态阈值、告警合并、完整静默 |
| 值班组 | 成员、当前值班人、基础轮值 | 排班日历、节假日、升级策略 |
| 通知 | 基础渠道、测试发送、失败记录 | 重试策略细化、无人确认升级、模板变量增强 |
| 权限 | 按应用授权、菜单和操作权限 | 环境精细化、多租户、审批流 |
| 接入 | Prometheus/Grafana、SkyWalking、未接入状态管理 | OpenTelemetry 深度接入、Webhook/SSO 增强 |
