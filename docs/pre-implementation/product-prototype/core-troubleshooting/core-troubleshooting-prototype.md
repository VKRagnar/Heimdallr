# 核心排障链路产品原型设计

## 1. 文档定位

本文基于 `demand/monitoring-platform-requirements.md`、`architecture/information-architecture.md`、`prototype/low-fidelity-prototype.md`，输出企业级统一监控平台一期“核心排障链路”的中高保真产品原型说明。

设计范围聚焦以下主链路：

```text
排障视角首页总览
  -> 告警详情
  -> 日志查询
  -> 应用详情
  -> 指标趋势
  -> 回到告警详情补充处理记录
```

一期优先服务应用研发负责人，其次服务运维/SRE和值班人员。页面设计以“快速确认影响、带上下文跳转、保留证据、受权限约束”为原则，不展开完整 APM、自动根因分析、复杂告警合并和报表复盘。

## 2. 设计目标与原则

| 目标 | 原型要求 |
| --- | --- |
| 研发负责人优先 | 默认展示“我负责/我值班/我被授权”的应用、告警、日志和指标；首页问题队列优先按本人责任范围排序 |
| Trace ID 贯穿 | 告警详情、日志查询、应用详情和指标趋势均支持携带 Trace ID、Request ID 或业务字段 |
| 告警跳日志 | 从告警详情进入日志查询时自动带入应用、环境、实例、时间窗口、日志级别和关键词 |
| 错误聚合 | 日志查询默认提供错误签名、异常类型、接口、实例维度聚合，用于先看模式再看明细 |
| 按应用授权 | 应用授权决定用户可见的告警、日志、指标和关联服务器；无权限时不泄露应用名称、日志内容和敏感字段 |
| 三步定位 | 从首页进入异常对象后，3 次点击内到达告警证据、关联日志或指标趋势 |

## 3. 全局交互框架

### 3.1 页面骨架

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 顶部栏：统一监控平台 | 全局搜索 | 环境切换 | 自动刷新状态 | 通知 | 用户菜单   │
├───────────────┬──────────────────────────────────────────────────────────────┤
│ 左侧导航       │ 面包屑 / 页面标题 / 关键状态标签                            │
│ 首页总览       ├──────────────────────────────────────────────────────────────┤
│ 应用监控       │ 页面级筛选条：环境、应用、负责人、时间范围、状态、Trace ID    │
│ 日志中心       ├──────────────────────────────────────────────────────────────┤
│ 指标中心       │ 页面主体：摘要区 + 证据区 + 明细区 + 操作区                  │
│ 告警中心       │                                                              │
└───────────────┴──────────────────────────────────────────────────────────────┘
```

### 3.2 通用筛选与上下文

| 字段 | 控件 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 环境 | 单选/多选下拉 | 生产 | 生产权限不足时默认首个授权环境 |
| 应用 | 远程搜索选择器 | 当前上下文应用 | 仅返回授权应用 |
| 负责人 | 人员搜索 | 当前用户 | 首页默认为“我负责 + 我值班” |
| 时间范围 | 快捷时间 + 自定义 | 最近 30 分钟或告警触发窗口 | 告警跳转时使用触发前 10 分钟至触发后 20 分钟 |
| Trace ID | 输入框 | 跳转带入 | 支持精确匹配，可为空 |
| 实例 IP | 下拉/输入 | 跳转带入 | 从告警、应用实例或日志行带入 |

### 3.3 权限约束

| 场景 | 表现 |
| --- | --- |
| 未授权应用 | 列表不展示；通过链接访问时显示“无应用数据权限”，不展示应用名称、指标值、日志内容 |
| 有应用权限但无日志权限 | 可见告警和指标，日志入口显示锁定态，提示申请日志查看权限 |
| 有日志查看权限但无导出权限 | 可查询日志，导出按钮禁用并展示权限说明 |
| 生产敏感字段无权限 | 日志内容脱敏展示；查看明文入口不可见或禁用 |
| 值班临时授权 | 告警详情只开放告警对象和触发窗口附近的日志、指标，不扩展到全应用历史数据 |

## 4. 主链路总览

```mermaid
flowchart LR
  H["首页总览：待处理问题"] --> A["告警详情：确认影响和证据"]
  A --> L["日志查询：Trace ID / 错误聚合"]
  L --> APP["应用详情：实例、接口、依赖"]
  APP --> M["指标趋势：错误率、P95、QPS"]
  M --> A2["告警详情：处理备注和关闭"]
```

| 起点 | 触发动作 | 目标 | 入参 | 出参 |
| --- | --- | --- | --- | --- |
| 首页总览 | 点击待处理问题 | 告警详情 | `alertId`、`appId`、`env`、`timeRange` | 当前告警上下文 |
| 首页总览 | 点击“查日志” | 日志查询 | `appId`、`env`、`instanceIp`、`timeRange`、`level=ERROR` | 日志筛选上下文 |
| 告警详情 | 点击关联日志 | 日志查询 | `alertId`、`appId`、`env`、`instanceIp`、`triggerTime±window`、`traceId?` | 命中日志、错误聚合 |
| 日志查询 | 点击 Trace ID | 日志查询 | `traceId`、`appId`、`timeRange` | Trace 全链路日志结果 |
| 日志查询 | 点击应用名/实例 | 应用详情 | `appId`、`env`、`instanceIp?`、`timeRange` | 应用运行上下文 |
| 应用详情 | 点击指标卡或曲线 | 指标趋势 | `appId`、`env`、`metricCodes`、`instanceIp?`、`timeRange` | 指标对比上下文 |
| 指标趋势 | 点击告警标记点 | 告警详情 | `alertId`、`timeRange` | 告警处理上下文 |

## 5. 页面一：排障视角首页总览

### 5.1 页面目标

让研发负责人进入平台后，在 5 秒内看清“我负责的应用是否异常、当前最该处理哪条告警、下一步看日志还是指标”。首页不是管理驾驶舱，首屏优先展示待处理问题和异常证据入口。

### 5.2 适用角色

| 角色 | 主要任务 |
| --- | --- |
| 应用研发负责人 | 查看负责应用的异常、告警、错误日志入口和性能趋势 |
| 运维/SRE | 查看生产全局异常、跨应用高负载和待处理告警 |
| 值班人员 | 处理值班组覆盖范围内的 P0/P1/P2 告警 |
| 业务负责人 | 只读查看授权业务线的重大告警和核心业务指标 |

### 5.3 页面布局

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 首页总览                                  自动刷新 30s  最近刷新 10:32:15    │
├──────────────────────────────────────────────────────────────────────────────┤
│ 环境[生产]  范围[我负责/我值班]  业务线[全部]  负责人[当前用户]  时间[24h]   │
├──────────────────────────────────────────────────────────────────────────────┤
│ ┌──────────────┐ ┌────────────┐ ┌────────────┐ ┌────────────┐ ┌───────────┐ │
│ │整体健康 严重  │ │我的异常应用│ │待处理告警  │ │ERROR 增长  │ │慢接口 TOP │ │
│ │P0 1 / P1 4    │ │3/18        │ │8           │ │+36%        │ │12         │ │
│ └──────────────┘ └────────────┘ └────────────┘ └────────────┘ └───────────┘ │
├──────────────────────────────────────────────────────────────────────────────┤
│ 待处理问题队列                                                               │
│ 级别 状态 应用/实例 问题摘要 影响接口/指标 Trace ID 负责人 持续 操作        │
│ P1 已通知 order-api 错误率 6.2% /api/pay - 张三 8m [详情][日志][指标]       │
│ P2 处理中 stock-sync 任务积压 12k trace-8f.. 王五 22m [详情][日志][应用]    │
├──────────────────────────────────────────────────────────────────────────────┤
│ ┌──────────────────────────────┐ ┌─────────────────────────────────────────┐ │
│ │ 24h 告警趋势                  │ │ 错误聚合 TOP5                           │ │
│ │ P0/P1/P2/P3 折线 + 告警点     │ │ 异常类型 | 应用 | 次数 | 首次/最近       │ │
│ └──────────────────────────────┘ └─────────────────────────────────────────┘ │
├──────────────────────────────────────────────────────────────────────────────┤
│ ┌──────────────────────┐ ┌──────────────────────┐ ┌──────────────────────┐ │
│ │ TOP 异常应用          │ │ TOP 慢接口            │ │ 数据接入异常          │ │
│ │ 应用 状态 告警 错误率 │ │ 接口 应用 P95 错误率  │ │ 应用 数据源 最近心跳  │ │
│ └──────────────────────┘ └──────────────────────┘ └──────────────────────┘ │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 5.4 关键组件与字段

| 组件 | 字段 | 说明 |
| --- | --- | --- |
| 健康摘要卡 | 整体健康、P0/P1 数、异常应用数、ERROR 增长率、慢接口数 | 点击进入对应筛选后的告警列表、应用列表或日志查询 |
| 待处理问题队列 | 级别、状态、应用、实例 IP、问题摘要、影响接口、触发指标、Trace ID、负责人、持续时长、操作 | 首页核心区，默认按 P0/P1、持续时间、本人责任排序 |
| 错误聚合 TOP5 | 错误签名、异常类型、应用、实例数、日志次数、最近出现时间 | 点击进入日志查询并带入错误签名 |
| 告警趋势 | 时间、级别、数量、告警标记点 | 点击趋势点进入告警列表或详情 |
| 数据接入异常 | 应用、数据源、接入状态、最近心跳 | 标识未接入或采集异常，避免误判“无异常” |

### 5.5 交互状态

| 操作 | 状态变化 |
| --- | --- |
| 切换“我负责/我值班/全部授权” | 刷新所有卡片与队列；筛选条件写入 URL |
| 点击问题行 | 进入告警详情；保留首页筛选作为返回上下文 |
| 点击“日志” | 进入日志查询；默认 `level=ERROR`，时间窗口为告警触发前 10 分钟至后 20 分钟 |
| 点击“指标” | 进入指标趋势；默认展示触发指标、请求量、错误率、P95 |
| 自动刷新 | 卡片和队列局部刷新；正在查看的弹窗、展开行不被收起 |
| 新 P0/P1 出现 | 顶部轻提示 + 队列置顶；不打断当前页面操作 |

### 5.6 状态设计

| 状态 | 表现 |
| --- | --- |
| 空状态 | “当前授权范围内暂无待处理问题”，展示最近已恢复告警入口和接入健康摘要 |
| 加载状态 | 卡片骨架屏、队列表格骨架行，保留筛选区可操作 |
| 异常状态 | 显示数据源异常条，标明 Prometheus、日志源或告警服务异常；支持重试 |
| 无权限状态 | 若用户无首页菜单权限，提示无权限；若无应用数据，仅展示申请授权入口 |

### 5.7 验收点

- 首页默认只展示用户授权应用及其衍生日志、指标、告警。
- 研发负责人进入首页后，首屏可看到本人负责应用的待处理问题。
- 从待处理问题点击“日志”可带入应用、环境、实例、时间窗口和 ERROR 级别。
- Trace ID 存在时在队列中可见并可一键复制或跳转查询。
- 自动刷新默认 30 秒，且不清空当前筛选和展开状态。

## 6. 页面二：告警详情

### 6.1 页面目标

让处理人确认告警是否真实、影响哪个应用/实例/接口、触发指标是什么、应该先看哪段日志，并记录确认、处理和关闭过程。

### 6.2 适用角色

| 角色 | 主要任务 |
| --- | --- |
| 应用研发负责人 | 确认、处理本人应用告警，查看日志与指标证据 |
| 值班人员 | 确认值班范围告警，备注处理进展或转派 |
| 运维/SRE | 查看跨对象影响、通知记录和采集状态 |
| 只读用户 | 查看授权范围内告警，不可处理 |

### 6.3 页面布局

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 告警中心 / 告警详情 / ALM-20260426-001       P1 严重  已通知  持续 8m       │
│ [确认告警] [标记处理中] [添加备注] [转派] [关闭] [更多]                    │
├──────────────────────────────────────────────────────────────────────────────┤
│ 摘要：order-api 生产环境错误率过高                                           │
│ 应用 order-api | 实例 10.2.8.15:8080 | 负责人 张三 | 值班组 交易一线        │
│ 触发：错误率 6.2% > 5%，持续 5m | 首次触发 10:01 | 最近通知 10:02          │
├──────────────────────────────────────────────────────────────────────────────┤
│ ┌──────────────────────────────┐ ┌─────────────────────────────────────────┐ │
│ │ 触发指标趋势                  │ │ 快速定位                                │ │
│ │ 错误率/QPS/P95 触发点标记     │ │ Trace ID[-]  错误签名[NullPointer...]   │ │
│ └──────────────────────────────┘ │ [查关联日志] [查同类错误] [看应用详情]   │ │
│                                  └─────────────────────────────────────────┘ │
├──────────────────────────────────────────────────────────────────────────────┤
│ Tab：[处理记录] [关联日志] [影响对象] [通知记录] [规则信息] [审计]          │
│ 关联日志预览：时间 | 级别 | 实例 | Trace ID | 错误摘要 | 操作               │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 6.4 关键组件与字段

| 区域 | 字段 |
| --- | --- |
| 告警摘要 | 告警 ID、标题、级别、状态、环境、应用、实例、负责人、值班组、持续时长 |
| 触发规则 | 规则 ID、规则名称、指标编码、触发条件、阈值、持续时间、检测周期、通知对象 |
| 指标趋势 | 触发指标、当前值、触发值、阈值线、触发点、恢复点、数据源 |
| 快速定位 | Trace ID、Request ID、错误签名、影响接口、关联日志数量、最近 ERROR 时间 |
| 关联日志 | 时间、级别、应用、实例、Trace ID、线程、日志摘要、堆栈展开、上下文入口 |
| 影响对象 | 应用、实例、接口、服务器、依赖服务、影响范围 |
| 通知记录 | 发送时间、渠道、接收人、状态、失败原因、重试次数 |
| 处理记录 | 操作人、动作、时间、备注、状态变更 |

### 6.5 交互状态

| 操作 | 状态变化 |
| --- | --- |
| 确认告警 | 状态从已通知变为已确认，记录确认人和确认时间 |
| 标记处理中 | 状态变为处理中，要求填写可选处理备注 |
| 添加备注 | 追加到处理时间线，支持关联日志行或指标截图引用 ID |
| 转派 | 选择授权用户或值班组；记录转派前后处理人 |
| 关闭 | 必填关闭原因；未恢复告警关闭时要求二次确认 |
| 查关联日志 | 跳转日志查询，带入告警对象和触发窗口 |
| 查同类错误 | 跳转日志查询，带入错误签名，不强制带 Trace ID |
| 看应用详情 | 跳转应用详情，带入应用、环境、实例和告警时间窗口 |

### 6.6 跳转入参/出参

| 跳转 | 入参 | 出参 |
| --- | --- | --- |
| 首页 -> 告警详情 | `alertId`、`source=home`、`backFilter` | 告警上下文、处理状态 |
| 告警详情 -> 日志查询 | `alertId`、`appId`、`env`、`instanceIp`、`startTime`、`endTime`、`level=ERROR`、`traceId?`、`errorSignature?` | `selectedLogIds`、`traceId`、`errorSignature` |
| 告警详情 -> 应用详情 | `appId`、`env`、`instanceIp?`、`timeRange`、`alertId` | 应用运行上下文 |
| 告警详情 -> 指标趋势 | `appId`、`env`、`metricCodes`、`instanceIp?`、`alertId`、`timeRange` | 指标证据上下文 |

### 6.7 状态设计

| 状态 | 表现 |
| --- | --- |
| 空状态 | 无关联日志时显示“当前窗口无 ERROR 日志”，提供扩大时间范围和查看应用日志入口 |
| 加载状态 | 摘要优先加载，日志、通知、处理记录分区加载 |
| 异常状态 | 指标趋势失败时保留告警摘要，提示数据源异常；日志预览失败时提供跳转日志中心重试 |
| 无权限状态 | 无处理权限时隐藏确认、处理、关闭按钮；无日志权限时关联日志内容脱敏或不可见 |

### 6.8 验收点

- 告警详情必须展示触发值、阈值、持续时间和触发前后指标趋势。
- “查关联日志”必须自动带入应用、环境、实例和告警时间窗口。
- 若告警关联 Trace ID，详情页必须支持一键复制和一键查 Trace 日志。
- 所有处理动作进入处理记录和审计记录。
- 未授权用户不能通过告警详情反查未授权应用日志或指标。

## 7. 页面三：日志查询

### 7.1 页面目标

支持研发负责人围绕告警、Trace ID、错误签名和业务字段快速定位日志证据，先通过错误聚合识别主要异常，再展开上下文和堆栈明细。

### 7.2 适用角色

| 角色 | 主要任务 |
| --- | --- |
| 应用研发负责人 | 查询本人应用日志、Trace ID、错误堆栈和上下文 |
| 运维/SRE | 跨实例排查生产问题，查看采集状态 |
| 测试人员 | 查询测试/预发环境授权应用日志 |
| 业务负责人 | 默认不可见技术日志明细，除非单独授权 |

### 7.3 页面布局

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 日志中心 / 日志查询                                      [保存查询] [导出]   │
├──────────────────────────────────────────────────────────────────────────────┤
│ 应用[order-api] 环境[生产] 实例[10.2.8.15] 时间[10:00-10:30] 级别[ERROR]    │
│ Trace ID[输入] Request ID[输入] 关键字/错误签名[NullPointer...] [查询]      │
├──────────────────────────────────────────────────────────────────────────────┤
```

| 状态 | 表现 |

### 7.8 验收点

- 从告警详情跳转日志查询时，筛选条件必须完整回显。
- Trace ID 查询支持精确匹配，且日志明细中 Trace ID 可复制。
- ERROR 日志支持按错误签名、异常类型、接口、实例聚合。
- 日志上下文支持命中行前后 N 行查看，并保持敏感字段脱敏。
- 日志导出必须受权限控制并记录审计。

## 13. 一期边界

一期纳入：

- 排障视角首页总览。
- 告警详情的摘要、指标趋势、关联日志、通知记录、处理记录。
- 日志查询的 Trace ID、上下文、错误聚合和受控导出。
- 应用详情的健康摘要、实例、接口、最近告警、接入状态。
- 指标趋势的多指标查看、阈值线、告警点和日志命中点。
- 按应用授权过滤日志、指标、告警和关联服务器。

一期不纳入：

- 完整分布式链路追踪拓扑。
- 自动根因分析和自动修复。
- 复杂告警合并、动态阈值、完整静默和升级策略。
- 故障复盘报表和容量预测。
