# 企业级统一监控平台列表、查询与状态页中高保真产品原型

## 1. 文档定位

本文基于 `demand/monitoring-platform-requirements.md`、`architecture/information-architecture.md`、`prototype/low-fidelity-prototype.md`，细化一期“列表、查询与状态页”产品原型。范围仅覆盖：

- 应用列表
- 服务器列表
- 指标查询
- 告警列表
- 日志查询补充态
- 通用空状态、加载状态、数据源异常、无权限状态、导出受控状态

一期设计主线：

1. 所有数据默认按应用授权过滤；日志、指标、告警和关联服务器由应用授权衍生可见范围。
2. 筛选器、时间范围、环境、状态和导出交互在各列表/查询页保持一致。
3. 列表页优先支持排障定位：看状态、缩范围、跳日志/指标/告警、执行受控处理。
4. 导出、敏感日志查看、告警处理、规则关联和权限申请均需留审计入口。

## 2. 全局列表与查询框架

### 2.1 页面骨架

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 面包屑 / 页面标题                  次要信息：授权范围、刷新时间、数据源状态 │
├──────────────────────────────────────────────────────────────────────────────┤
│ 筛选区：核心筛选第一行，高级筛选可展开；支持保存查询、重置、刷新             │
├──────────────────────────────────────────────────────────────────────────────┤
│ 状态汇总条：总数、正常/异常/未知、活跃告警、已选数量、当前过滤说明          │
├──────────────────────────────────────────────────────────────────────────────┤
│ 批量操作条：选择后出现；未选择时收起或弱化                                  │
├──────────────────────────────────────────────────────────────────────────────┤
│ 表格 / 图表 / 日志结果区：支持排序、列设置、分页、快捷跳转                  │
├──────────────────────────────────────────────────────────────────────────────┤
│ 分页与结果说明：每页条数、总数、查询耗时、数据延迟提示                      │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 2.2 全局交互约定

| 项目 | 原型要求 |
| --- | --- |
| 环境筛选 | 全部、生产、预发、测试、开发；生产环境默认在标签上突出显示 |
| 时间范围 | 最近 15 分钟、1 小时、6 小时、24 小时、7 天、30 天、自定义；日志默认 1 小时，指标默认 6 小时，告警默认 24 小时 |
| 授权过滤 | 应用下拉、对象搜索、负责人搜索只返回用户授权范围；不可见数据不在计数中泄露 |
| 排序 | 表格字段中带数值、时间、状态优先级的列支持排序；默认按风险或更新时间降序 |
| 列设置 | 支持调整列显隐；关键列如名称、状态、操作不可隐藏 |
| 保存查询 | 日志查询、指标查询、告警列表支持保存；应用/服务器列表支持保存筛选视图 |
| 导出 | 默认导出当前筛选结果；超量进入导出任务；无权限时展示受控态 |
| 审计 | 导出、保存共享查询、批量告警处理、敏感字段明文查看需记录操作人、时间、条件和结果范围 |

### 2.3 状态与级别视觉语言

| 类型 | 文案 | 颜色语义 | 展示位置 |
| --- | --- | --- | --- |
| 正常 | 正常 | 绿色 | 状态标签、汇总卡、表格行 |
| 预警 | 预警 | 黄色 | 资源接近阈值、P2/P3 告警 |
| 异常 | 异常 | 橙色 | P1、健康检查失败、错误率异常 |
| 严重 | 严重 | 红色 | P0、核心业务不可用、生产大面积异常 |
| 未知 | 未知 | 灰色 | 数据源无返回、Agent 离线、未接入 |
| 受限 | 无权限 | 灰色描边 | 受控按钮、权限状态页、脱敏字段 |

### 3.3 筛选器

| 筛选器 | 控件 | 默认值 | 规则 |
| --- | --- | --- | --- |
| 应用名称/编码 | 搜索框 | 空 | 支持模糊搜索；只返回授权应用 |
| 环境 | 多选下拉 | 全部授权环境 | 可保存为默认筛选 |

| 所属系统 | 所属业务系统 | 支持 |

### 3.5 批量操作

| 操作 | 出现条件 | 权限 | 说明 |
| --- | --- | --- | --- |
| 批量查看告警 | 已选应用数大于 0 | 告警查看 | 跳转告警列表，带入应用集合、环境和未恢复状态 |
| 批量导出 | 已选应用数大于 0 | 导出权限 | 导出所选应用摘要；超 5000 行进入导出任务 |
| 批量添加到关注 | 已选应用数大于 0 | 查看权限 | 加入个人关注，影响首页和筛选快捷项 |

### 3.6 保存视图

保存内容包括筛选条件、排序、列设置、分页条数。个人视图默认仅本人可见；共享给团队需要“共享查询”权限，并记录审计。

### 3.7 状态文案

| 场景 | 页面文案 | 主操作 |
| --- | --- | --- |
| 无匹配应用 | 未找到符合条件的应用。请调整筛选条件，或确认你是否已获得应用授权。 | 重置筛选 |
| 无授权应用 | 当前账号暂无可查看应用。请联系平台管理员或应用负责人申请应用数据权限。 | 申请权限 |
| 未接入监控 | 该应用尚未接入指标或日志，状态可能不完整。 | 查看接入指引 |
| 数据延迟 | 部分应用数据延迟超过 5 分钟，列表状态可能不是最新。 | 查看数据源状态 |

| 操作 | 权限 | 说明 |
| --- | --- | --- |
| 批量查看指标 | 指标查看 | 跳转指标查询，带入所选服务器、系统指标、最近 6 小时 |

### 4.6 按应用授权过滤

服务器列表默认只显示与授权应用存在部署关系的服务器，或用户直接拥有基础设施查看权限的服务器。若一台服务器部署了多个应用，仅展示用户有权查看的应用名称；未授权应用用“其他应用”计数，不展示名称、端口、日志和指标细节。

### 4.7 状态文案

| 场景 | 页面文案 | 主操作 |
| --- | --- | --- |
| 无匹配服务器 | 未找到符合条件的服务器。请调整筛选条件或检查应用关联关系。 | 重置筛选 |
| Agent 离线 | Agent 已离线，资源指标可能停止更新。 | 查看 Agent 状态 |
| 部分应用不可见 | 该服务器部署了你无权查看的应用，相关应用名称和日志已隐藏。 | 申请更多权限 |
| 数据源异常 | 服务器指标源当前不可用，列表展示最近一次成功采集数据。 | 重试 |

## 5. 指标查询

### 5.1 页面目标

支持应用、服务器、中间件、数据库和业务指标统一查询趋势，并提供收藏、保存查询、对比、导出和创建告警规则入口。

### 5.2 中高保真布局

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 指标中心 / 指标查询                   [保存查询] [收藏] [添加到告警规则] [导出]│
├──────────────────────────────────────────────────────────────────────────────┤
│ 对象类型[应用 v] 对象[order-api v] 环境[生产 v] 指标类型[应用 v] 指标[搜索] │
│ 实例[全部 v] 聚合[平均 v] 对比[按实例 v] 时间[最近6小时 v]       [查询]     │
│ 高级：标签过滤、采样粒度、同比/环比基准、空值处理、展示单位                │
├──────────────────────────────────────────────────────────────────────────────┤
│ 当前值 6.2% | 最大 8.1% | 最小 0.3% | 平均 3.7% | P95 7.6% | 数据延迟 30s  │

│ 趋势图区域：多指标 / 多实例 / 多时间段对比；异常点可点击                    │

├──────────────────────────────────────────────────────────────────────────────┤

```

### 5.3 筛选器

| 筛选器 | 控件 | 默认值 | 规则 |
| --- | --- | --- | --- |
| 对象类型 | 单选下拉 | 应用 | 应用、服务器、数据库、中间件、业务指标 |
| 对象 | 搜索多选 | 空 | 受应用授权过滤；服务器对象按授权应用关联过滤 |
| 环境 | 单选/多选 | 生产或上游带入 | 不同对象可用环境不同 |
| 指标类型 | 单选下拉 | 全部 | 系统、应用、中间件、数据库、业务 |
| 指标 | 搜索多选 | 空 | 支持中文名、编码、标签搜索 |
| 实例 | 多选下拉 | 全部 | 选择应用后可用 |
| 聚合方式 | 单选 | 平均值 | 平均值、最大值、最小值、P95、P99、同比、环比 |
| 对比方式 | 单选 | 按实例 | 跨应用、跨实例、跨时间 |
| 时间范围 | 快捷时间 | 最近 6 小时 | 自定义范围过大时提示降采样 |
| 采样粒度 | 单选 | 自动 | 10 秒、1 分钟、5 分钟、1 小时、自动 |

### 5.5 保存查询与收藏

| 功能 | 说明 |
| --- | --- |
| 保存查询 | 保存筛选条件、指标、对象、时间快捷项、图表展示方式；可设为默认查询 |
| 收藏指标 | 收藏指标编码和展示名称，出现在指标中心左侧“我的指标” |
| 共享查询 | 需要共享权限；共享后团队成员仍只能看到自己授权的数据子集 |

### 5.6 导出权限

导出内容包括趋势数据 CSV、明细表 CSV 和图表 PNG。无导出权限时按钮置灰并提示“当前角色暂无指标导出权限”；导出生产指标或超 10000 点数据时进入导出任务，并记录查询条件、对象范围和下载人。

### 5.7 状态文案

| 场景 | 页面文案 | 主操作 |
| --- | --- | --- |
| 无指标数据 | 当前条件下暂无指标数据。请扩大时间范围，或确认对象已接入指标采集。 | 查看接入状态 |

## 9. 验收点

### 9.1 应用列表

1. 能按应用名称、编码、负责人、环境、状态、业务线和接入状态筛选。
2. 普通用户只能看到授权应用；未授权应用不出现在筛选项、表格和统计数中。
3. 表格支持按状态、当前告警、错误率、P95、最近发布时间排序。
4. 应用行可跳转应用详情、日志查询、指标查询和告警列表，并带入应用与环境上下文。
5. 导出受权限控制，导出操作记录审计。

### 9.2 服务器列表

1. 能按主机名/IP、环境、区域、分组、状态、关联应用、负责人和 Agent 状态筛选。
2. 服务器可见性遵循应用授权衍生规则；未授权应用信息不泄露。
3. CPU、内存、磁盘、当前告警、更新时间支持排序。
4. 支持批量查看指标、批量查看告警和受控导出。
5. Agent 离线、数据源异常和数据延迟有明确状态提示。

### 9.3 指标查询

1. 支持对象类型、对象、环境、指标类型、指标、实例、聚合方式、对比方式和时间范围查询。
2. 支持保存查询、收藏指标、共享查询且共享后仍按接收人的应用授权过滤。
3. 趋势图支持阈值线、告警触发点、异常点弹层和跳转日志/告警。
4. 导出指标趋势和明细受权限控制，超量进入导出任务。
5. 查询响应时间常规场景不超过 3 秒；大范围查询需给出降采样提示。

### 9.4 告警列表

1. 支持按级别、状态、对象类型、应用/服务器、负责人、环境、时间范围、通知状态和值班组筛选。
2. 默认优先展示未恢复、未确认和高级别告警。
3. 支持批量确认、批量标记处理中、批量转派和批量导出，并进行权限校验。
4. 告警行可跳转告警详情、影响对象、日志查询和指标查询。
5. 告警处理操作记录操作人、操作时间、动作和备注。

### 9.5 日志查询补充态

1. 从告警跳转日志时自动带入应用、环境、实例和触发时间前后窗口。
2. 支持错误签名聚合、按签名过滤、查看样例日志和关联告警。
3. 支持上下文查看、堆栈折叠/展开、关键字高亮和敏感字段脱敏。
4. 支持保存查询和共享查询，且严格按应用授权过滤结果。
5. 日志导出受权限、环境、数据量和脱敏策略控制，并记录审计。

### 9.6 通用状态

1. 空状态、加载状态、数据源异常、无权限状态和导出受控状态在各页面文案一致。
2. 数据源异常不阻塞页面整体使用；可展示最近一次成功数据时必须标注采集时间。
3. 无权限状态不泄露未授权对象明细、数量和敏感字段。
4. 所有受控导出均有二次确认、任务状态或失败重试路径。
