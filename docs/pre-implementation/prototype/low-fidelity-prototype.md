# 企业级统一监控平台一期低保真原型

## 1. 原型说明

本文档基于 `demand/monitoring-platform-requirements.md` 输出一期核心页面低保真原型，用于产品、研发、测试、运维和 SRE 在详细设计前对齐页面范围、信息层级、筛选项、表格字段、操作按钮、状态展示和页面跳转关系。

一期核心页面范围：

- 全局总览
- 应用列表
- 应用详情
- 服务器列表
- 服务器详情
- 日志查询
- 指标查询
- 告警规则
- 告警列表
- 告警详情
- 通知/联系人基础管理
- 用户权限基础管理

已确认的一期产品输入：

- 核心用户优先级：应用研发负责人优先，其次是运维/SRE，再其次是业务负责人。
- 首页大盘采用排障视角，优先展示当前异常、影响对象、负责人、持续时间和处理入口。
- 告警配置一期只做简单阈值规则，并支持值班组作为通知对象。
- 日志查询一期支持 Trace ID、上下文、错误聚合、日志导出、从告警跳转日志。
- 数据源现状包括 Prometheus、Grafana、少量 SkyWalking，以及未接入监控的应用。
- 权限模型一期按应用授权，日志、指标、告警和关联服务器可见性从应用授权衍生。

### 2.2 通用交互约定

| 类型 | 说明 |
| --- | --- |
| 环境筛选 | 生产、预发、测试、开发，默认跟随用户权限范围 |
| 时间范围 | 最近 15 分钟、1 小时、6 小时、24 小时、7 天、自定义 |
| 状态颜色 | 正常、预警、异常、严重、未知 |

| 权限控制 | 一期按应用授权；未授权应用及其日志、指标、告警不展示，关联服务器按应用关系限制；导出和规则修改需要操作权限 |
| 跳转方式 | 列表名称、状态标签、告警标题、指标图表异常点均可作为详情入口 |

## 3. 页面导航关系

```text
全局总览
├─ 点击异常应用卡片 / TOP 异常应用 -> 应用详情
├─ 点击高负载服务器 -> 服务器详情
├─ 点击活跃告警 / 告警趋势点 -> 告警列表 / 告警详情
└─ 点击业务指标卡片 -> 指标查询

└─ 点击应用名称 / 状态 -> 应用详情
   ├─ 查看关联日志 -> 日志查询
   ├─ 查看指标趋势 -> 指标查询
   ├─ 查看服务器 -> 服务器详情
   └─ 查看最近告警 -> 告警详情

服务器列表
└─ 点击主机名 / IP / 状态 -> 服务器详情
   ├─ 查看部署应用 -> 应用详情
   ├─ 查看资源指标 -> 指标查询
   └─ 查看最近告警 -> 告警详情

告警列表
└─ 点击告警标题 -> 告警详情
   ├─ 查看关联日志 -> 日志查询

└─ 点击规则名称 -> 规则编辑 / 查看；点击触发记录 -> 告警列表
```

## 4. 全局总览

### 4.3 主要筛选项

| 筛选项 | 控件 | 说明 |
| --- | --- | --- |
| 环境 | 下拉单选/多选 | 生产、预发、测试、开发 |
| 业务线 | 下拉多选 | 按组织业务线过滤 |
| 部门 | 下拉多选 | 按应用或服务器归属部门过滤 |
| 负责人 | 下拉搜索 | 过滤本人或指定负责人范围 |
| 时间范围 | 快捷时间 + 自定义 | 默认最近 24 小时 |

### 4.4 状态展示

| 状态 | 展示位置 | 说明 |
| --- | --- | --- |
| 正常 | 全局状态卡、应用/服务器行 | 无活跃 P0/P1，关键指标正常 |
| 预警 | 全局状态卡、指标卡 | 存在 P2/P3 或容量接近阈值 |
| 异常 | 全局状态卡、对象状态 | 存在 P1 或多个对象异常 |
| 严重 | 全局状态卡、告警卡 | 存在 P0 或核心业务不可用 |

### 4.5 操作与跳转

| 操作 | 目标 |
| --- | --- |
| 点击异常应用名称 | 进入应用详情 |
| 点击服务器 IP | 进入服务器详情 |
| 点击活跃告警数量 | 带级别和状态筛选进入告警列表 |
| 点击告警趋势点 | 带时间范围进入告警列表 |
| 点击业务指标卡片 | 进入指标查询并预置指标 |
| 点击待处理问题 | 进入告警详情，并保留应用、环境、时间范围上下文 |
| 点击快捷定位日志 | 进入日志查询，并预置应用、实例、Trace ID 或告警时间窗口 |

### 9.2 页面线框图

## 16. 一期关键流程线框

### 16.1 告警处理流程

```text
指标触发规则
  -> 生成告警事件
  -> 告警列表出现未恢复告警
  -> 通知负责人
  -> 负责人进入告警详情
  -> 查看指标趋势 / 关联日志 / 影响对象
  -> 确认告警
  -> 添加处理备注或转派
  -> 指标恢复后自动恢复
  -> 关闭告警并进入记录
```

### 16.2 应用故障定位流程

```text
全局总览发现异常应用
  -> 应用详情
  -> 查看实例健康与接口指标
  -> 跳转日志查询查看 ERROR 和 Trace ID
  -> 跳转指标查询查看错误率、P95、JVM 指标
  -> 进入告警详情记录处理过程
```

### 16.3 服务器高负载定位流程

```text
全局总览发现高负载服务器
  -> 服务器详情
  -> 查看 CPU/内存/磁盘/网络趋势
  -> 查看进程与端口
  -> 查看部署应用
  -> 跳转应用详情或告警详情
```
