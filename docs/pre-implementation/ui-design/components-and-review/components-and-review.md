# 企业级统一监控平台 UI 高保真组件与评审清单

## 1. 文档定位

本文基于 `product-prototype/acceptance/prototype-acceptance-checklist.md`、`product-prototype/list-and-states/list-and-states-prototype.md`，并参考核心排障链路、配置管理链路原型，沉淀一期高保真 UI 组件清单与设计评审验收清单。

范围仅覆盖 UI 组件、状态、交互与评审标准，不包含前端实现代码、接口设计、数据库设计和详细技术方案。

一期 UI 设计主线：

1. 优先服务排障：用户进入平台后能快速看见异常、影响对象、负责人、持续时间和处理入口。
2. 保持上下文：环境、应用、实例、时间范围、告警 ID、Trace ID、错误签名在跨页面跳转中连续回显。
3. 权限先行：应用授权决定日志、指标、告警和关联服务器可见范围；导出、处理、明文查看和配置变更需单独受控。
4. 状态完整：空、加载、异常、数据源异常、权限不足、导出受控、通知失败等状态均有明确视觉和文案承接。
5. 一致可评审：同类组件在首页、列表、详情、查询、配置页中保持命名、控件、颜色语义和操作反馈一致。

## 2. 组件设计原则

| 原则 | 设计要求 | 评审关注 |
| --- | --- | --- |
| 排障优先 | 首屏、列表首列、详情摘要优先展示状态、级别、对象、负责人、持续时间、下一步动作 | 是否能 5 秒内判断风险和入口 |
| 语义一致 | 正常、预警、异常、严重、未知、无权限、P0/P1/P2/P3 全平台含义一致 | 同一状态是否出现不同颜色或文案 |
| 筛选一致 | 环境、时间、应用/服务器、负责人、状态等筛选在列表和查询页保持一致 | 用户是否能迁移使用经验 |
| 数据受控 | 未授权数据不在列表、下拉、统计数、导出任务中泄露 | URL 直访、搜索、聚合计数是否越权 |
| 局部可恢复 | 图表、日志、通知记录等模块失败时局部提示和重试，不阻断详情主信息 | 是否避免整页失败 |
| 操作可追踪 | 导出、告警处理、规则修改、权限变更、敏感字段明文查看需要二次确认或审计提示 | 是否明确审计信息 |
| 可访问 | 颜色不作为唯一信息；键盘可达；焦点、标签、错误提示可识别 | 是否满足基础无障碍要求 |

## 3. UI 组件清单

### 3.1 导航

| 组件 | 适用页面 | 高保真要求 | 状态与权限 |
| --- | --- | --- | --- |
| 顶部栏 | 全平台 | 包含平台名称、全局搜索、当前环境、自动刷新状态、通知入口、用户菜单 | 无权限入口不展示；通知失败或新 P0/P1 用非阻塞提示 |
| 左侧一级导航 | 全平台 | 首页总览、应用监控、服务器监控、日志中心、指标中心、告警中心、通知与值班、接入管理、系统管理 | 按菜单权限展示；一期不暴露空白二期页面 |
| 面包屑 | 列表、详情、配置页 | 展示模块层级和对象名称，支持返回上级列表 | 返回需保留原筛选、排序、时间范围 |
| 来源提示条 | 告警详情、日志查询、指标趋势、应用详情 | 展示来源页面、告警 ID、Trace ID、时间窗口和返回入口 | 来源上下文受权限过滤，不能暴露未授权对象 |
| 页内 Tab | 告警详情、应用详情、服务器详情、日志详情抽屉 | Tab 名称稳定，默认选中最利于排障的内容 | 无权限 Tab 隐藏或锁定并给出说明 |

### 3.2 筛选器

| 组件 | 控件形态 | 必备字段 | 交互要求 |
| --- | --- | --- | --- |
| 基础筛选条 | 搜索框、多选下拉、单选标签、快捷时间 | 环境、时间范围、应用/服务器、负责人、状态、关键字 | 核心筛选第一行可见，高级筛选可展开 |
| 时间范围选择器 | 快捷项 + 自定义范围 | 15 分钟、1 小时、6 小时、24 小时、7 天、30 天、自定义 | 告警跳日志默认触发前后窗口；大范围查询提示降采样或缩小范围 |
| 应用选择器 | 远程搜索多选 | 应用名称、编码、业务线、环境、负责人 | 仅返回授权应用；无授权时显示申请权限入口 |
| 对象选择器 | 远程搜索多选 | 应用、服务器、实例、指标对象 | 服务器按应用授权衍生过滤；未授权应用不出现在结果中 |
| 高级筛选 | 折叠面板 | 接入状态、通知状态、值班组、数据源、Agent 状态、是否升级/静默 | 展开状态和筛选值可保存到 URL 或保存查询 |
| 保存查询/视图 | 按钮 + 弹窗 | 筛选、排序、列设置、时间快捷项、图表展示方式 | 共享查询需权限，接收人仍按自身授权过滤 |

### 3.3 数据表格

| 组件 | 高保真要求 | 必备能力 |
| --- | --- | --- |
| 表格容器 | 表头固定、关键列清晰、行高适合扫描，名称/状态/操作不可隐藏 | 排序、列设置、分页、刷新、查询耗时、数据延迟提示 |
| 状态汇总条 | 位于筛选区下方，展示总数、正常、预警、异常、严重、未知、活跃告警、已选数量 | 统计仅包含授权范围；点击状态可反向筛选 |
| 批量操作条 | 选择行后出现，未选择时隐藏或弱化 | 批量查看告警、批量查看指标、批量导出、批量处理告警 |
| 行级操作 | 置于最右侧，优先详情、日志、指标、告警、处理 | 无权限操作置灰或隐藏，并提供原因 |
| 展开行/抽屉 | 展示实例、关联应用、错误样例、通知记录等二级信息 | 展开不打断自动刷新；局部加载失败可重试 |
| 分页说明 | 展示每页条数、总数、查询耗时、最近刷新、数据延迟 | 大数据量导出进入后台任务 |

### 3.4 状态标签

| 类型 | 标签 | 语义 | 使用位置 |
| --- | --- | --- | --- |
| 运行状态 | 正常、预警、异常、严重、未知 | 对象健康聚合结果 | 首页卡片、列表行、详情摘要 |
| 告警级别 | P0、P1、P2、P3 | 告警影响和处理优先级 | 告警卡片、告警列表、告警详情 |
| 告警生命周期 | 已触发、已通知、已确认、处理中、已恢复、已关闭、已升级、已静默 | 告警闭环状态 | 告警列表、详情摘要、时间线 |
| 接入状态 | 指标已接入、链路已接入、仅日志、仅指标、未接入、采集异常、验证中 | 数据源可用性 | 应用列表、应用详情、接入管理 |
| Agent 状态 | 在线、离线、版本过低、配置异常 | 主机采集状态 | 服务器列表、服务器详情 |
| 权限状态 | 无权限、只读、脱敏、需审批 | 数据或操作受控 | 按钮、字段、空状态、权限提示 |

标签要求：颜色、图标和文案同时表达状态；严禁只依赖颜色区分。严重、异常、预警、正常、未知在全平台不得混用语义。

### 3.5 告警卡片

| 区域 | 字段 | 交互 |
| --- | --- | --- |
| 头部 | 级别、状态、告警标题、持续时长 | 点击进入告警详情 |
| 对象摘要 | 应用/服务器、环境、实例、负责人、值班组 | 对象名可跳详情，负责人悬停展示脱敏联系方式 |
| 触发信息 | 指标、触发值、当前值、阈值、首次触发、最近通知 | 触发指标可跳指标趋势 |
| 证据入口 | 关联日志数、错误签名、Trace ID、影响接口 | 查日志、查同类错误、看应用详情 |
| 操作区 | 确认、处理中、备注、转派、关闭 | 按处理权限控制；高风险关闭需二次确认 |

### 3.6 日志行

| 字段 | 展示规则 |
| --- | --- |
| 时间 | 精确到毫秒或日志源可提供精度，支持按时间排序 |
| 级别 | ERROR、WARN、INFO 等，ERROR/FATAL 高亮但不遮挡内容 |
| 应用/环境/实例 | 从授权应用和实例中展示，未授权不显示 |
| Trace ID/Request ID | 可复制、可作为查询条件再次检索 |
| 线程/接口/业务字段 | 支持列设置，敏感字段默认脱敏 |
| 日志摘要 | 关键字高亮；长内容折叠；堆栈默认折叠中间重复行 |
| 操作 | 上下文、复制、看指标、看应用、关联告警 |

日志行要求：复制默认使用脱敏内容；明文查看、明文复制和导出必须校验权限并记录审计。

### 3.7 错误聚合面板

| 模块 | 字段 | 评审要求 |
| --- | --- | --- |
| 聚合列表 | 错误签名、异常类型、影响应用、影响实例、接口、日志次数、Trace 数、首次/最近出现 | 默认按次数或风险排序；仍按应用授权过滤 |
| 样例日志 | 典型日志行、堆栈摘要、脱敏标识 | 样例不泄露敏感字段 |
| 关联告警 | 告警 ID、状态、级别、触发时间 | 可跳转告警详情 |
| 操作 | 按签名过滤、查看样例、查看上下文、跳转指标 | 操作带入应用、环境、时间和错误签名 |

### 3.8 图表卡

| 组件 | 高保真要求 | 状态 |
| --- | --- | --- |
| 指标摘要卡 | 当前值、最大值、最小值、平均值、P95/P99、同比/环比预留、数据延迟 | 无数据时显示接入状态，不显示误导性 0 |
| 趋势图 | 阈值线、告警触发点、恢复点、日志命中点、发布事件、图例开关 | 图表加载骨架、数据源异常、缺失点提示 |
| 异常点弹层 | 时间、对象、实例、指标值、阈值、关联告警、查看日志 | 弹层内容受权限过滤 |
| 小型排行图 | TOP 异常应用、慢接口、错误聚合、数据接入异常 | 排序规则明确，点击可跳转筛选后列表 |

### 3.9 详情摘要

| 页面 | 摘要组件字段 |
| --- | --- |
| 告警详情 | 告警 ID、标题、级别、状态、环境、对象、实例、负责人、值班组、触发条件、持续时长 |
| 应用详情 | 应用名称、编码、环境、业务线、负责人、技术栈、最近发布、接入状态、核心健康指标 |
| 服务器详情 | 主机名、IP、环境、区域、负责人、Agent、CPU/内存/磁盘/网络、部署应用、当前告警 |
| 规则详情 | 规则名称、对象、指标、条件、级别、生效时间、通知对象、渠道、启用状态、最近触发 |
| 权限详情 | 用户/角色、菜单权限、操作权限、应用数据权限、衍生可见范围、敏感权限 |

摘要要求：基本信息优先加载；附属模块失败不得影响摘要可读。

### 3.10 处理时间线

| 节点 | 字段 | 要求 |
| --- | --- | --- |
| 触发 | 告警触发时间、规则、触发值、对象 | 系统节点不可编辑 |
| 通知 | 渠道、接收人、发送状态、失败原因、重试次数 | 失败节点提供查看通知记录或重试入口 |
| 确认 | 操作人、确认时间、备注 | 记录状态从已通知到已确认 |
| 处理中 | 操作人、处理开始时间、备注 | 可关联日志行、指标截图引用 ID |
| 转派/升级 | 原处理人、新负责人/值班组、原因 | 需要权限并记录审计 |
| 恢复/关闭 | 恢复时间、关闭人、关闭原因 | 未恢复关闭需二次确认 |

### 3.11 权限提示

| 场景 | 展示策略 | 文案要求 |
| --- | --- | --- |
| 无菜单权限 | 导航入口不展示；直访显示无权限页 | 不展示业务数据 |
| 无应用数据权限 | 列表、搜索、下拉中不可见；直访显示申请权限 | 不泄露未授权对象名称、数量、日志内容 |
| 有菜单无数据 | 展示授权范围为空状态 | 说明需申请应用数据权限 |
| 无操作权限 | 按钮隐藏或置灰，悬停/点击说明原因 | 明确当前角色不能执行该操作 |
| 敏感字段无权限 | 字段脱敏，明文入口禁用或隐藏 | 提示“字段已脱敏展示” |
| 只读用户 | 处理、导出、配置类操作不可用 | 保留查看路径 |

### 3.12 导出确认

| 状态 | 触发条件 | UI 要求 |
| --- | --- | --- |
| 可导出 | 有权限且数据量在阈值内 | 显示导出范围、格式、脱敏策略 |
| 二次确认 | 生产环境、日志、敏感字段、超 1000 行 | 弹窗展示应用、环境、时间、预估条数、字段范围、审计提示 |
| 后台任务 | 超 5000 行列表或超 10000 点指标 | 创建任务，展示任务状态、完成通知和有效期 |
| 无权限 | 无导出权限 | 按钮置灰或隐藏，提供申请入口 |
| 失败 | 数据源异常或任务失败 | 展示失败原因、重试入口、审计编号 |

### 3.13 加载骨架

| 场景 | 骨架要求 |
| --- | --- |
| 首页 | 卡片、问题队列、趋势图分区骨架；筛选区可操作 |
| 列表 | 保留表头、筛选和分页位置，使用表格行骨架 |
| 图表 | 指标卡骨架 + 图表占位，不显示 0 数据 |
| 日志查询 | 聚合面板和日志行分别加载，展示查询中与耗时提示 |
| 告警详情 | 摘要优先加载，日志、通知、处理记录局部加载 |
| 提交操作 | 按钮 loading 并禁用重复提交 |

### 3.14 空状态

| 场景 | 标题 | 主操作 |
| --- | --- | --- |
| 列表无匹配 | 未找到符合条件的数据 | 重置筛选 |
| 授权范围为空 | 暂无可查看数据 | 申请应用权限 |
| 未接入数据 | 暂无监控数据 | 查看接入指引 |
| 无未恢复告警 | 当前没有未恢复告警 | 查看历史告警 |
| 无命中日志 | 当前条件下未命中日志 | 扩大时间范围 |
| 无指标数据 | 当前条件下暂无指标数据 | 查看接入状态 |
| 无规则/联系人/值班组 | 暂无配置数据 | 新建或导入 |

空状态必须说明原因和下一步，不得只显示“暂无数据”。

### 3.15 异常状态

| 类型 | UI 表现 | 操作 |
| --- | --- | --- |
| 查询失败 | 页面或局部错误条，展示失败原因摘要 | 重试、调整筛选 |
| 查询超时 | 提示缩小时间范围或增加对象条件 | 缩小范围、继续查询 |
| 指标源异常 | 标明 Prometheus/Grafana 等来源，展示最近成功采集时间 | 重试、查看数据源状态 |
| 日志源异常 | 提示查询结果可能不完整 | 重试、缩小范围 |
| Agent 异常 | 标明 Agent 心跳异常、版本过低或配置异常 | 查看 Agent、联系负责人 |
| 通知失败 | 展示渠道、接收人、失败原因、重试状态 | 查看通知记录、重试 |
| 保存失败 | 定位到失败字段或表单顶部错误 | 修改后重试 |
| 部分数据缺失 | 模块内提示，不影响其他模块 | 查看接入状态 |

## 4. 响应式与可访问性

| 项目 | 验收标准 |
| --- | --- |
| 响应式布局 | 1440px 及以上支持导航 + 主内容密集展示；1024px 可折叠次要列；移动端优先保留筛选、状态、摘要和主操作 |
| 表格适配 | 小屏下关键列优先：名称、状态、级别、负责人、时间、操作；次要字段进入展开行或列设置 |
| 筛选适配 | 核心筛选保留在第一屏；高级筛选折叠；已选筛选以标签展示并可清除 |
| 图表适配 | 图例可换行或折叠；悬浮信息可改为点击查看；轴标签不重叠 |
| 键盘可达 | 导航、筛选、表格行、Tab、弹窗、抽屉、确认按钮可通过键盘聚焦和操作 |
| 焦点状态 | 所有可交互元素有可见焦点样式，弹窗打开后焦点限制在弹窗内 |
| 颜色对比 | 正文、标签、按钮、错误提示满足基础对比度；颜色不作为唯一状态信息 |
| 表单错误 | 错误信息与字段关联，保存失败自动定位首个错误字段 |
| 屏幕阅读 | 关键按钮、图标按钮、状态标签、图表摘要具备可读标签 |
| 动效 | 自动刷新、新告警提示、加载动效不打断当前输入和展开状态 |

### 5.2 筛选、表格与查询

## 7. UI 验收通过条件

1. 导航、筛选器、数据表格、状态标签、告警卡片、日志行、错误聚合面板、图表卡、详情摘要、处理时间线、权限提示、导出确认、加载骨架、空状态和异常状态均有高保真设计或明确规格。
2. 应用、服务器、日志、指标、告警、配置、权限和接入相关页面使用一致的状态语义、筛选交互、权限提示和审计提示。
3. 核心排障路径“首页/告警列表 -> 告警详情 -> 日志查询/错误聚合 -> 应用详情 -> 指标趋势 -> 处理记录”组件状态完整、上下文可传递。
4. 所有未授权、无导出权限、敏感字段明文、生产导出、告警处理、规则变更和权限变更场景都有明确 UI 表现。
5. 空、加载、异常、数据源异常、通知失败、部分数据缺失、无权限、导出受控等状态均可被测试用例验证。
6. 响应式和可访问性要求覆盖桌面、小屏、键盘操作、焦点管理、图表可读和非颜色状态表达。
