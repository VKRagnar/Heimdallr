# 配置管理 UI 高保真页面设计说明

## 1. 设计范围与依据

本文基于 `product-prototype/config-management/config-management-prototype.md`、`architecture/information-architecture.md`、`demand/monitoring-platform-requirements.md`，补充企业级统一监控平台一期“配置管理”相关页面的高保真 UI 设计说明。

覆盖页面：

- 告警中心 / 告警规则
- 通知与值班 / 联系人
- 通知与值班 / 值班组
- 通知与值班 / 通知渠道
- 系统管理 / 用户管理、角色管理、权限配置
- 接入管理 / 应用接入
- 接入管理 / 数据源管理

一期目标：让平台管理员、运维/SRE、应用研发负责人完成“应用接入 -> 数据源确认 -> 告警规则配置 -> 通知对象和值班组选择 -> 按应用授权 -> 告警可触达”的基础闭环。

## 2. 全局高保真规范

### 2.1 页面骨架

配置管理页面统一采用“左侧导航 + 顶部栏 + 内容区”的企业级后台布局。

| 区域 | 高保真要求 |
| --- | --- |
| 顶部栏 | 固定高度 56px，包含平台名称、全局搜索、环境切换、通知入口、用户菜单 |
| 左侧导航 | 宽 224px，一级导航常驻，当前二级页面在内容区顶部 Tab 或面包屑中体现 |
| 内容页头 | 左侧为面包屑、页面标题、说明短句；右侧为页面级主操作 |
| 筛选区 | 白底无卡片嵌套，按 4-6 列表单栅格排列；查询、重置靠右 |
| 状态概览 | 置于筛选区下方，使用轻量统计条展示总数、启用、异常、草稿等 |
| 主体区 | 列表表格为默认主体，抽屉承载复杂编辑，详情用右侧抽屉或独立详情页 |

### 2.2 视觉层级

| 层级 | 使用场景 | 样式说明 |
| --- | --- | --- |
| 主按钮 | 新建规则、新建值班组、新增渠道、保存并启用、验证接入 | 实心品牌色，仅每个操作区保留 1 个 |
| 次按钮 | 查询、测试、保存草稿、导入、同步用户 | 描边或浅底按钮 |
| 文本按钮 | 查看、编辑、复制、审计、触发记录、查看应用 | 表格行内操作 |
| 危险按钮 | 删除、停用被引用对象、禁用用户、停用数据源 | 红色文本或红色描边，必须二次确认 |
| 只读标签 | 草稿、停用、无权限、未接入 | 灰色或浅色标签 |
| 风险标签 | 配置异常、采集异常、排班缺失、渠道异常 | 红色标签；黄色用于可修复但未阻断状态 |

### 2.3 通用表单抽屉

复杂配置统一使用右侧抽屉，不使用全屏弹窗。

| 项 | 要求 |
| --- | --- |
| 宽度 | 普通表单 720px；复杂规则、权限、接入向导 960px |
| 标题区 | 标题 + 对象名称 + 状态标签；编辑态展示最近更新时间 |
| 内容区 | 分组表单，分组标题固定为 16px 粗体；分组之间 24px 间距 |
| 底部操作 | 固定底栏，左侧展示审计提示或校验摘要，右侧为取消、保存草稿、保存并启用 |
| 校验定位 | 保存失败时顶部出现错误摘要，点击错误项滚动到字段并聚焦 |
| 只读态 | 字段值用文本或禁用控件展示；隐藏保存按钮，保留关闭和查看审计 |

### 2.4 通用状态

| 状态 | 高保真表现 |
| --- | --- |
| 空状态 | 居中图标 + 原因文案 + 主操作；筛选后无结果优先提供“清空筛选” |
| 加载状态 | 表格骨架屏 5 行；图表区域使用局部骨架，不显示 0 数据 |
| 查询失败 | 顶部局部错误条 + 重试按钮；保留用户已输入筛选条件 |
| 保存失败 | 抽屉底栏展示错误数量；字段下方展示具体原因 |
| 数据源异常 | 状态标签标红，并在列表行展开提示影响范围 |
| 无权限 | 页面可进入时展示只读或申请权限入口；未授权对象不出现在选择器中 |
| 部分缺失 | 局部模块展示缺失原因，不阻断其他信息查看 |

### 2.5 审计提示

以下操作必须在确认或提交区域展示审计提示：

- 新建、修改、启停、复制、删除告警规则
- 联系人手机号、邮箱、IM 账号变更
- 值班组成员、排班、覆盖应用变更
- 通知渠道密钥、Token、Webhook 地址、状态变更
- 用户角色、菜单权限、操作权限、应用授权变更
- 应用接入配置、数据源配置、鉴权信息、绑定关系变更

审计提示文案模板：

```text
本次变更将记录操作人、操作时间、变更前后内容，并可在系统管理 / 操作审计中查询。
```

## 3. 告警规则

### 3.1 列表页

页面标题：告警规则  
页面说明：配置简单阈值规则、通知对象和值班组，规则启用后参与告警检测。

#### 页面布局

```text
面包屑：告警中心 / 告警规则
标题：告警规则                                      [批量启用] [批量停用] [新建规则]
筛选：关键字、环境、对象类型、应用、告警级别、状态、通知对象、数据源
统计：全部、启用、停用、草稿、配置异常、无指标数据
表格：规则名称、对象、环境、指标、触发条件、级别、通知对象、渠道、状态、最近触发、操作
```

#### 筛选字段

| 字段 | 控件 | 说明 |
| --- | --- | --- |
| 关键字 | 搜索输入框 | 支持规则名、对象名、指标编码 |
| 环境 | 多选下拉 | 生产、预发、测试、开发 |
| 对象类型 | 多选下拉 | 应用、服务器、数据库、中间件、业务指标 |
| 应用 | 远程搜索选择器 | 仅返回授权应用 |
| 告警级别 | 多选 | P0、P1、P2、P3 |
| 状态 | 多选 | 草稿、启用、停用、配置异常 |
| 通知对象 | 多选 | 应用负责人、备份负责人、值班组 |
| 数据源 | 多选 | Prometheus、Grafana、SkyWalking、平台内置指标 |

#### 表格行高保真

| 列 | 展示规则 |
| --- | --- |
| 规则名称 | 主文本为名称，副文本展示规则 ID；配置异常时名称前置风险图标 |
| 对象 | 主文本为对象名称，副文本展示对象类型、业务线 |
| 指标 | 展示指标名称、指标编码、数据源标签 |
| 触发条件 | 自然语言短句，例如“平均值 > 5%，持续 5 分钟” |
| 级别 | P0 红色、P1 橙红、P2 橙色、P3 蓝灰 |
| 通知对象 | 展示“负责人 + 交易值班组”等摘要，悬浮显示解析后的当前接收人 |
| 渠道 | 图标 + 文本标签，最多展示 3 个，超出折叠 |
| 状态 | 草稿、启用、停用、配置异常、无指标数据 |
| 最近触发 | 展示时间；从未触发显示“-” |
| 操作 | 查看、编辑、复制、启停、触发记录、审计；无权限时隐藏编辑和启停 |

#### 操作按钮层级

| 操作 | 层级 | 行为 |
| --- | --- | --- |
| 新建规则 | 主按钮 | 打开规则表单抽屉 |
| 批量启用/停用 | 次按钮 | 选中规则后可用，执行前二次确认 |
| 查看 | 文本按钮 | 打开只读抽屉 |
| 编辑 | 文本按钮 | 打开编辑抽屉 |
| 复制 | 文本按钮 | 打开新建抽屉，名称追加“副本”并状态为草稿 |
| 启停 | 文本按钮 | 对启用规则展示“停用”，对停用/草稿展示“启用” |
| 触发记录 | 文本按钮 | 跳转告警列表并带入规则 ID |
| 审计 | 文本按钮 | 打开审计侧边详情 |

### 3.2 告警规则表单抽屉

抽屉标题：新建告警规则 / 编辑告警规则  
抽屉宽度：960px  
底部操作：取消、保存草稿、规则预览、保存并启用

#### 字段分组

| 分组 | 字段 | 说明 |
| --- | --- | --- |
| 基本信息 | 规则名称、规则描述、启用状态 | 编辑规则的基础标识 |
| 监控对象 | 对象类型、环境、监控对象、对象范围 | 监控对象选择受应用授权过滤 |
| 指标条件 | 指标来源、指标、聚合方式、触发条件、阈值、持续时间、检测周期 | 一期只支持单指标阈值 |
| 告警策略 | 告警级别、生效时间、恢复条件、重复通知间隔 | 静默、升级为二期入口或隐藏 |
| 通知配置 | 通知对象、值班组、通知渠道 | 值班组选择器和渠道可用性联动 |
| 处理建议 | 处理建议、运行手册链接 | 展示在告警详情与通知消息中 |

#### 校验提示

| 字段/场景 | 提示位置 | 提示文案 |
| --- | --- | --- |
| 规则名称为空 | 字段下方 | 请输入规则名称 |
| 规则名称重复 | 字段下方 | 同一环境、同一对象下已存在同名规则 |
| 对象无授权 | 对象选择器空状态 | 暂无可配置对象，请申请应用权限 |
| 对象未接入指标 | 对象选择后提示条 | 当前对象暂无指标数据，可保存草稿，不能保存并启用 |
| 指标无最近数据 | 指标字段下方 | 该指标最近无采集数据，启用前需完成数据验证 |
| 阈值非法 | 字段下方 | 请输入合法数字；百分比指标范围为 0-100 |
| 持续时间小于检测周期 | 字段下方 | 持续时间需大于或等于检测周期 |
| P0/P1 检测周期过长 | 字段下方黄色提示 | 高级别告警建议检测周期不超过 1 分钟，管理员确认后可保存 |
| 通知对象缺失 | 分组顶部 | 至少选择应用负责人或一个值班组 |
| 值班组不可用 | 值班组卡片内 | 当前值班组排班缺失或联系方式不完整，不能保存并启用 |
| 渠道级别不匹配 | 渠道字段下方 | P0 必须包含电话或短信，P1 必须包含短信或 IM |
| Webhook 未测试 | 渠道卡片内 | Webhook 渠道需通过连通性测试后才可启用 |

#### 规则预览

点击“规则预览”后，在抽屉右侧或表单底部展示自然语言摘要：

```text
当生产环境 order-api 的 error_rate 在 5 分钟内平均值持续大于 5% 时，触发 P1 严重告警；每 1 分钟检测一次；通知应用负责人张三、备份负责人李四和交易系统值班组，通过短信、企业微信发送；指标恢复到 5% 及以下后自动恢复。
```

### 3.3 值班组选择器

值班组选择器用于告警规则表单，不使用普通下拉。

| 区域 | 高保真说明 |
| --- | --- |
| 搜索区 | 支持按值班组名称、业务线、覆盖应用、组负责人搜索 |
| 筛选区 | 状态、业务线、是否覆盖当前应用 |
| 结果列表 | 卡片式列表，每张卡片展示值班组名称、业务线、覆盖应用数、当前值班人、下一值班人、规则引用数 |
| 状态标签 | 正常、排班缺失、联系方式缺失、停用 |
| 详情展开 | 展示成员、当前排班、联系方式完整性、引用规则摘要 |
| 选择规则 | 停用、排班缺失、当前值班人无有效联系方式时可查看但不可选择启用 |

选择器状态：

- 无匹配：提示“未找到值班组，可调整筛选或新建值班组”
- 无权限：提示“你暂无值班组查看权限”
- 仅可保存草稿：当值班组有风险但不阻断草稿时，卡片显示黄色提示
- 阻断启用：排班缺失、无成员、无联系方式时，保存并启用按钮禁用

### 3.4 危险操作确认

| 操作 | 确认方式 | 文案重点 |
| --- | --- | --- |
| 停用启用中的规则 | 二次确认弹窗 | 停用后不再触发新告警，历史事件保留 |
| 批量停用规则 | 二次确认 + 数量提示 | 展示选中规则数、生产规则数、P0/P1 数 |
| 删除草稿规则 | 二次确认 | 删除后不可恢复 |
| 启用配置异常规则 | 阻断 | 不允许启用，需修复数据源、指标或通知对象 |

## 4. 联系人与值班组

### 4.1 联系人列表页

页面标题：联系人  
页面说明：维护告警通知对象基础联系方式，手机号、邮箱和密钥类信息默认脱敏。

```text
标题：联系人                                      [批量导入] [新增联系人]
筛选：姓名/账号、部门、状态、渠道完整性、关键字
表格：姓名、账号、部门、手机号、邮箱、企业微信、钉钉、状态、最近测试、操作
```

| 列 | 展示规则 |
| --- | --- |
| 姓名 | 主文本姓名，副文本登录账号 |
| 手机号 | 默认脱敏；有敏感权限可点击查看并写审计 |
| 邮箱 | 默认脱敏 |
| 企业微信/钉钉 | 已绑定、未绑定、异常 |
| 渠道完整性 | 完整、缺手机号、缺邮箱、缺 IM |
| 状态 | 启用、禁用 |
| 操作 | 编辑、测试通知、禁用、审计 |

联系人抽屉分组：

| 分组 | 字段 |
| --- | --- |
| 基本信息 | 姓名、登录账号、部门、状态 |
| 联系方式 | 手机号、邮箱、企业微信账号、钉钉账号 |
| 通知测试 | 测试渠道、测试接收地址、测试结果 |
| 审计提示 | 最近变更人、最近变更时间、审计提示 |

校验：

- 姓名 2-30 字。
- 登录账号需与统一认证账号唯一匹配。
- 手机号、邮箱格式错误时字段下方提示。
- 禁用联系人若被值班组或规则间接引用，确认弹窗展示影响值班组和规则数。

### 4.2 值班组列表页

页面标题：值班组  
页面说明：维护值班成员和覆盖应用，告警规则按当前排班动态解析通知对象。

```text
标题：值班组                                      [新建值班组]
筛选：值班组名称、业务线、覆盖应用、状态、当前值班人
统计：全部、正常、排班缺失、联系方式缺失、停用
表格：值班组、业务线、覆盖应用、当前值班人、下一值班人、规则数、状态、操作
```

#### 值班组表单抽屉

抽屉宽度：960px  
底部操作：取消、保存、保存并启用

| 分组 | 字段 | 说明 |
| --- | --- | --- |
| 基本信息 | 值班组名称、业务线、组负责人、状态 | 同一业务线下名称唯一 |
| 覆盖范围 | 覆盖应用、环境范围 | 应用选择器只展示有维护权限的应用 |
| 成员配置 | 值班成员、备份联系人 | 至少 2 名成员；备份联系人可选 |
| 排班配置 | 排班方式、当前值班人、下一值班人、轮值周期 | 一期支持固定当前值班人或基础轮值 |
| 通知偏好 | 通知渠道偏好、不可达兜底 | 默认继承规则渠道 |
| 引用与审计 | 被引用规则数、最近变更记录 | 停用前提示影响规则 |

#### 值班组校验

| 场景 | 提示 |
| --- | --- |
| 值班组名称重复 | 同一业务线下已存在同名值班组 |
| 覆盖应用为空 | 请选择至少一个覆盖应用 |
| 成员不足 2 人 | 值班成员至少 2 人，避免单点通知风险 |
| 当前值班人禁用 | 当前值班人已禁用，请重新选择 |
| 当前值班人缺少联系方式 | 当前值班人缺少规则所需联系方式，告警规则不能启用 |
| 排班缺失 | 当前时间无法解析值班人，请补全排班 |

#### 危险操作

- 停用被规则引用的值班组：确认弹窗展示引用规则数量、P0/P1 规则数量、受影响应用。
- 移除值班成员：若成员为当前值班人或唯一有效联系人，必须先切换当前值班人。
- 禁用排班：提示“排班停用后，绑定该值班组的规则将进入配置异常”。

## 5. 通知渠道

### 5.1 通知渠道列表页

页面标题：通知渠道  
页面说明：配置邮件、短信、IM、电话和 Webhook 等告警触达通道。

```text
标题：通知渠道                                   [测试全部] [新增渠道]
筛选：渠道类型、状态、适用级别、关键字
表格：渠道名称、类型、适用级别、状态、最近测试、成功率、失败原因、引用规则、操作
```

| 列 | 展示规则 |
| --- | --- |
| 渠道名称 | 主文本名称，副文本渠道 ID |
| 类型 | 邮件、短信、企业微信、钉钉、电话、Webhook |
| 适用级别 | P0/P1/P2/P3 标签 |
| 状态 | 启用、停用、异常、测试中 |
| 最近测试 | 成功/失败 + 时间 |
| 成功率 | 最近 24 小时或最近 100 次发送成功率 |
| 失败原因 | 最近失败摘要，悬浮展示详情 |
| 引用规则 | 展示规则数，可点击筛选告警规则 |
| 操作 | 编辑、测试、停用、查看通知记录、审计 |

### 5.2 渠道表单抽屉
