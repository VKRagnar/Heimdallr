# 核心排障链路 UI 高保真页面设计说明

## 1. 文档定位

本文基于 `product-prototype/core-troubleshooting/core-troubleshooting-prototype.md`、`architecture/information-architecture.md` 与需求文档，细化企业级统一监控平台一期核心排障链路的高保真页面设计说明。

设计范围：

- 排障视角首页
- 告警详情
- 日志查询
- 应用详情
- 指标趋势

设计重点：

- 研发负责人优先：默认展示“我负责 / 我值班 / 我被授权”的应用、告警、日志和指标。
- Trace ID 贯穿：告警、日志、应用、指标之间传递并回显 Trace ID、Request ID、错误签名和时间窗口。
- 告警跳日志：从告警进入日志时自动带入应用、环境、实例、时间窗口、ERROR 级别、Trace ID 或错误签名。
- 错误聚合：日志查询首屏提供错误签名、异常类型、接口、实例维度聚合。
- 按应用授权：应用授权决定告警、日志、指标、实例、服务器关联信息的可见性。

## 2. 全局设计规范

### 2.1 页面框架

采用“顶部全局栏 + 左侧一级导航 + 页面标题区 + 上下文筛选条 + 主内容区”的后台产品布局。

| 区域 | 高保真要求 |
| --- | --- |
| 顶部全局栏 | 高度 56px，包含平台名称、全局搜索、环境入口、自动刷新状态、通知、用户菜单 |
| 左侧导航 | 宽度 216px，一级导航固定展示；当前页使用品牌主色左侧 3px 选中条 |
| 页面标题区 | 高度 64px，展示面包屑、页面标题、核心状态标签、页面级操作 |
| 上下文筛选条 | 高度 56px，可吸顶；环境、应用、负责人、时间范围、Trace ID 为核心控件 |
| 主内容区 | 背景 `#F5F7FA`，内容最大宽度不限制，适配 1440px 企业办公屏 |

### 2.2 视觉基调

| 项 | 规范 |
| --- | --- |
| 主色 | `#2563EB`，用于主按钮、链接、选中态、可点击 Trace ID |
| 成功 | `#16A34A`，用于正常、已恢复、数据源正常 |
| 警告 | `#D97706`，用于 P2、采集延迟、预警状态 |
| 危险 | `#DC2626`，用于 P0/P1、ERROR、失败、未恢复告警 |
| 中性文本 | 主文本 `#111827`，次文本 `#4B5563`，弱文本 `#6B7280` |
| 分割线 | `#E5E7EB` |
| 卡片 | 白底，1px 边框，圆角 6px，阴影仅用于抽屉、弹窗、浮层 |
| 字体 | 13px 为表格和表单基础字号，14px 为正文，20px 为页面标题，数字指标使用 24px |

页面整体避免装饰性大面积渐变，优先使用密集、清晰、可扫描的信息布局。

### 2.3 通用组件样式

| 组件 | 高保真要求 |
| --- | --- |
| 主按钮 | 蓝底白字，高 32px，用于查询、确认告警、保存、关闭确认等主动作 |
| 次按钮 | 白底灰边，高 32px，用于返回、重置、添加备注、导出图片 |
| 危险按钮 | 红色描边或红底，关闭告警、强制关闭二次确认时使用 |
| 文本按钮 | 蓝色文本，用于表格行内“详情 / 日志 / 指标 / 复制” |
| 状态标签 | 圆角 4px，左右内边距 8px，高 22px，不使用胶囊式大圆角 |
| 表格 | 表头浅灰底，行高 44px，支持固定首列和操作列，异常行左侧有级别色条 |
| 图表 | 白底容器，标题区 40px，图例右上角，支持阈值线、事件点、悬浮提示 |
| 抽屉 | 右侧 560px 或 720px，适合日志上下文、实例详情、备注历史 |
| 弹窗 | 宽度 480px / 640px，适合转派、关闭、权限申请确认 |
| Tooltip | 用于 Trace ID、脱敏字段、图表事件点、禁用按钮原因 |

### 2.4 状态标签体系

| 类型 | 标签 | 颜色 |
| --- | --- | --- |
| 告警级别 | P0 紧急 | 红底浅红背景 |
| 告警级别 | P1 严重 | 红色描边浅红背景 |
| 告警级别 | P2 一般 | 橙色描边浅橙背景 |
| 告警级别 | P3 提示 | 蓝色描边浅蓝背景 |
| 告警状态 | 已触发、已通知、已确认、处理中、已恢复、已关闭、已升级、已静默 | 状态语义色 |
| 日志级别 | DEBUG、INFO、WARN、ERROR、FATAL | ERROR/FATAL 使用红色，WARN 使用橙色 |
| 数据源 | 正常、延迟、异常、未接入、无权限 | 正常绿、延迟橙、异常红、未接入灰、无权限灰锁 |
| 权限 | 已授权、临时授权、只读、无日志权限、无导出权限 | 使用图标 + 文案，避免只靠颜色 |

### 2.5 跳转上下文规范

所有核心跳转都通过统一排障上下文对象传递：

| 字段 | 说明 |
| --- | --- |
| `sourcePage` | 来源页：home、alertDetail、logQuery、appDetail、metricTrend |
| `alertId` | 告警 ID |
| `appId` / `appCode` | 应用标识 |
| `env` | 环境 |
| `instanceIp` | 实例 IP |
| `interfacePath` | 接口路径 |
| `traceId` / `requestId` | 链路和请求标识 |
| `errorSignature` | 错误签名 |
| `metricCodes` | 指标编码集合 |
| `startTime` / `endTime` | 时间窗口 |
| `backUrl` / `backFilter` | 返回来源与筛选条件 |

来源提示条统一展示为：

```text
来源：告警 ALM-20260426-001 / order-api / 生产 / 10:00-10:30    [返回告警] [清除来源]
```

## 3. 页面一：排障视角首页

### 3.1 页面目标

研发负责人进入平台后，首屏 5 秒内确认“我负责的应用是否异常、当前最该处理哪条问题、下一步看日志还是指标”。

首页不是管理驾驶舱，首屏优先给待处理问题队列和排障入口，统计卡片只服务定位。

### 3.2 首屏优先级

1. 顶部筛选与自动刷新状态。
2. 本人责任范围健康摘要。
3. 待处理问题队列。
4. 错误聚合 TOP 与告警趋势。
5. 异常应用、慢接口、数据接入异常。

### 3.3 页面布局

```text
顶部全局栏
左侧导航 | 页面标题：排障视角首页                         自动刷新 30s 最近刷新 10:32:15
         | 筛选：环境 生产 | 范围 我负责+我值班 | 业务线 全部 | 负责人 当前用户 | 时间 最近24h
         | 摘要卡：整体健康 / 我的异常应用 / 待处理告警 / ERROR 增长 / 慢接口 TOP
         | 待处理问题队列，首屏占比约 45%
         | 告警趋势 50%宽 + 错误聚合 TOP5 50%宽
         | TOP 异常应用 / TOP 慢接口 / 数据接入异常
```

### 3.4 组件样式

| 组件 | 样式与交互 |
| --- | --- |
| 范围切换 | 分段控件：我负责、我值班、全部授权；默认选中“我负责 + 我值班” |
| 摘要卡 | 5 等分栅格，高 88px；左上标题，右上状态标签，主数字 24px |
| 待处理问题队列 | 白底表格，高度不少于 320px；P0/P1 行左侧红色强调条 |
| 趋势图 | 24h 折线 + 告警事件点；P0/P1 点使用实心红点 |
| 错误聚合 TOP | 表格 + 迷你趋势线；错误签名单行截断，悬浮展示完整签名 |
| 新告警提示 | 顶部筛选条下方轻提示，不遮挡表格操作 |

### 3.5 表格列

待处理问题队列表格：

| 列名 | 宽度建议 | 说明 |
| --- | --- | --- |
| 级别 | 72px | P0/P1/P2/P3 标签 |
| 状态 | 88px | 已通知、已确认、处理中等 |
| 应用 / 实例 | 180px | 应用名主文本，实例 IP 次文本 |
| 问题摘要 | 260px | 告警标题或异常摘要 |
| 影响接口 / 指标 | 180px | `/api/pay`、错误率、P95 等 |
| Trace ID | 160px | 存在则可复制和跳日志；无则显示 `-` |
| 负责人 | 96px | 负责人或值班组 |
| 持续 | 80px | 8m、22m |
| 操作 | 180px | 详情、日志、指标 / 应用 |

错误聚合 TOP 表格：

| 列名 | 说明 |
| --- | --- |
| 错误签名 | 异常摘要，点击进入日志查询 |
| 异常类型 | NullPointerException、TimeoutException 等 |

| 位置 | 主按钮 | 次按钮 / 文本按钮 |
| --- | --- | --- |
| 筛选条 | 查询 | 重置、保存视图 |
| 问题行 | 详情 | 日志、指标、复制 Trace ID |
| 错误聚合行 | 查日志 | 查看应用 |
| 趋势点 | 查看告警 | 查看指标 |

### 3.7 抽屉 / 弹窗

| 场景 | 形式 | 内容 |
| --- | --- | --- |
| 问题行快速预览 | 右侧抽屉 560px | 告警摘要、触发值、近 5 条 ERROR、快捷跳转 |
| 权限申请 | 弹窗 480px | 应用、权限类型、申请原因、提交按钮 |
| 自动刷新设置 | 弹出层 | 关闭、15s、30s、60s、手动 |

### 3.8 关键页面文案

| 场景 | 文案 |
| --- | --- |
| 空状态 | 当前授权范围内暂无待处理问题 |
| 空状态辅助 | 可查看最近已恢复告警或检查数据接入状态 |
| 无权限 | 暂无可查看的应用监控数据，请申请应用数据权限 |
| 数据源异常 | 告警服务数据延迟，最后成功同步 10:28:12 |
| 新告警提示 | 新增 1 条 P1 告警，已置顶到待处理问题队列 |

### 3.9 验收点

- 默认范围为当前用户负责、值班或被授权应用。
- 首屏必须展示待处理问题队列，不允许被纯统计卡片挤到首屏外。
- 点击“日志”必须带入应用、环境、实例、告警触发窗口和 `level=ERROR`。
- Trace ID 存在时可复制、可点击进入日志查询。
- 自动刷新不清空筛选、排序、展开行和抽屉状态。

## 4. 页面二：告警详情

### 4.1 页面目标

帮助处理人确认告警真实性、影响范围、触发证据、关联日志，并完成确认、处理中、备注、转派、关闭等基础处理闭环。

### 4.2 首屏优先级

1. 告警标题、级别、状态、持续时间、处理按钮。
2. 影响对象：应用、环境、实例、负责人、值班组。
3. 触发条件：当前值、阈值、持续时间、首次触发时间。
4. 触发指标趋势和快速定位卡片。
5. 处理记录与关联日志 Tab。

### 4.3 页面布局

```text
页面标题：告警详情 / ALM-20260426-001    P1 严重 已通知 持续 8m
操作区：[确认告警] [标记处理中] [添加备注] [转派] [关闭] [更多]
摘要条：order-api 生产环境错误率过高
对象信息：应用 / 实例 / 负责人 / 值班组 / 首次触发 / 最近通知
双栏：触发指标趋势 60% + 快速定位 40%
Tab：处理记录 / 关联日志 / 影响对象 / 通知记录 / 规则信息 / 审计
```

### 4.4 组件样式

| 组件 | 样式与交互 |
| --- | --- |
| 告警标题区 | 标题 20px，级别与状态标签紧跟标题；持续时间用红色弱底标签 |
| 摘要信息区 | 白底 2 行密集信息，字段之间使用竖线分隔 |
| 指标趋势图 | 显示触发指标、阈值线、触发点、恢复点；触发点带红色竖线 |
| 快速定位卡片 | Trace ID、Request ID、错误签名、影响接口、关联日志数量 |
| Tab 内容 | Tab 固定在证据区顶部，切换不刷新页面标题和摘要 |
| 处理时间线 | 左侧时间轴，右侧动作、操作人、备注和关联证据 |

### 4.5 表格列

### 4.6 按钮层级

| 状态 | 主按钮 | 次按钮 |
| --- | --- | --- |

| --- | --- | --- |
| 查关联日志 | 日志查询 | `alertId`、`appId`、`env`、`instanceIp`、`triggerTime-10m` 至 `triggerTime+20m`、`level=ERROR`、`traceId?` |

### 4.9 关键页面文案

| 场景 | 文案 |
| --- | --- |
| 无关联日志 | 当前告警窗口内暂无 ERROR 日志 |
| 扩大范围 | 扩大到触发前后 60 分钟 |
| 无日志权限 | 你有告警查看权限，但暂无该应用日志查看权限 |
| 关闭二次确认 | 当前告警尚未恢复，关闭后仍会保留审计记录。确认关闭？ |
| 指标源异常 | 指标源查询失败，告警摘要与处理记录仍可查看 |

### 4.10 验收点

- 必须展示触发值、阈值、持续时间、检测周期和触发指标趋势。
- “查关联日志”必须自动带入告警对象和触发窗口。
- Trace ID、Request ID、错误签名在快速定位卡片中可复制、可跳转。
- 告警处理动作必须写入处理记录和审计。
- 无日志权限时不展示日志内容，不能通过详情泄露敏感字段。

## 5. 页面三：日志查询

### 5.1 页面目标

帮助研发负责人从告警或应用上下文进入后，先看错误模式，再看日志明细，最后通过 Trace ID、错误签名、实例、接口回跳应用和指标。

### 5.2 首屏优先级

1. 来源提示条与回跳入口。
2. 查询条件：应用、环境、实例、时间、级别、Trace ID、关键字。
3. 错误聚合与时间分布。
4. 日志明细。
5. 日志上下文抽屉。

### 5.3 页面布局

```text
页面标题：日志查询                                      [保存查询] [导出]
来源提示：来自告警 ALM-20260426-001 / order-api / 10:00-10:30 [返回告警]
查询条：应用 环境 实例 时间 级别 Trace ID Request ID 关键字 [查询] [重置]
上半区：错误聚合 55% + 时间分布 45%
下半区：日志明细表格
右侧抽屉：日志上下文 / 堆栈 / 关联跳转
```

### 5.4 组件样式

| 组件 | 样式与交互 |
| --- | --- |
| 来源提示条 | 浅蓝底，高 40px，展示来源告警、应用、窗口和返回按钮 |
| 查询条件 | 两行紧凑表单；Trace ID 输入框宽 260px；关键字宽 320px |
| 错误聚合 | 默认展开，优先于明细；点击行写入错误签名条件 |
| 时间分布 | 柱状图 + 告警触发线 + ERROR/WARN 图例 |
| 日志明细 | 等宽字体展示摘要片段；关键字高亮；敏感字段用 `***` |
| 上下文抽屉 | 命中行居中，高亮背景；前后 N 行可调整 |

### 5.5 查询条件

| 断点 | 设计策略 |
| --- | --- |
| >= 1440px | 默认桌面布局，摘要卡 5 等分，图表双列，表格展示完整字段 |
| 1200px-1439px | 左侧导航可收起，摘要卡保持 5 等分，低优先级表格列可隐藏 |
| 1024px-1199px | 图表由双列改为单列，表格操作列固定，Trace ID 截断 |
| 768px-1023px | 左侧导航默认收起，筛选条折叠为两行，抽屉宽度 80vw |
| < 768px | 只保证应急查看与处理，表格转为卡片列表，主操作固定底部 |

移动端优先保留：告警标题、级别、状态、负责人、Trace ID、查日志、确认 / 备注入口。复杂图表在移动端展示单指标趋势和事件列表。

## 9. 权限与安全表现

| 场景 | 页面表现 |
| --- | --- |
| 无应用权限 | 不展示应用名称、指标值、日志内容；显示“无应用数据权限” |
| 有告警权限无日志权限 | 告警详情可见，日志入口锁定，提示申请日志查看权限 |
| 有日志查看无导出权限 | 可查询，导出按钮禁用，Tooltip 展示原因 |
| 敏感字段无明文权限 | 日志字段脱敏，明文查看入口不可见 |
| 值班临时授权 | 只开放告警对象和触发窗口附近的日志、指标 |
| URL 直访未授权对象 | 返回无权限状态页，不泄露对象名称 |

所有日志导出、敏感字段查看、告警处理、权限失败访问必须记录审计。

## 10. 全链路验收总表

| 验收项 | 标准 |
| --- | --- |
| 研发负责人优先 | 首页默认展示当前用户负责、值班或被授权应用的问题 |

| 按应用授权 | 应用、告警、日志、指标和关联服务器均按应用授权过滤 |
| 状态完整 | 每个页面具备空、加载、异常、无权限状态 |

## 11. 一期不做内容

- 完整分布式链路追踪拓扑。
- 自动根因分析和自动修复。
- 复杂告警合并、动态阈值、完整静默和升级策略。
- 故障复盘报表和容量预测。
- 跨租户或集团多公司隔离的复杂配置界面。
