# UI Foundation Rules

本文是企业级统一监控平台一期 UI 高保真绘制与研发测试验收的统一约束源。若其他高保真页面或原型文档出现局部差异，以本文为准；页面文档只引用本文规则，不再散写颜色、状态、权限、导出、审计等口径。

适用范围：

- 首页总览、应用列表、服务器列表、日志查询、指标查询、告警列表、告警详情、应用详情、指标趋势。
- 告警规则、联系人、值班组、通知渠道、用户权限、应用接入、数据源管理、通知记录、操作审计。
- 设计稿标注、组件库命名、研发实现、测试用例拆分和 UI 走查。

### 1.1 全局框架

### 1.2 按钮层级

同一区域最多一个主按钮。主按钮只表达该区域的最高优先级动作。

| 场景 | 主按钮 | 次按钮 | 文本/图标按钮 | 危险按钮 |
| --- | --- | --- | --- | --- |
| 筛选区 | 查询 | 重置、保存查询、刷新 | 无 | 无 |
| 页面标题区 | 新建、保存并启用、查看日志等页面主动作 | 导入、批量启停、导出、收藏 | 返回来源、清除来源 | 无 |
| 表格行 | 无；需要强入口时可用文本主动作 | 无 | 详情、日志、指标、告警、编辑、审计；超过 3 个收起更多 | 停用、删除、关闭 |
| 告警详情 | 按当前状态给出唯一主动作：确认告警、标记处理中、关闭告警 | 添加备注、转派、查日志、看指标 | 复制、查看审计 | 未恢复关闭、强制关闭 |
| 表单抽屉底栏 | 保存并启用或保存 | 取消、保存草稿、测试连接、规则预览 | 查看审计 | 删除、停用 |

危险按钮必须配二次确认；生产、权限、密钥、导出和告警关闭必须展示审计提示。

## 2. 全局状态字典与优先级

### 2.1 状态族

| 状态族 | 枚举 | 是否互斥 | 说明 |
| --- | --- | --- | --- |
| 对象健康状态 | 正常、预警、异常、严重、未知 | 互斥 | 应用、服务器、接口、实例等最终健康聚合结果 |
| 告警级别 | P0、P1、P2、P3 | 互斥 | 影响和处理优先级，不等同于生命周期 |
| 告警生命周期 | 已触发、已通知、已确认、处理中、已恢复、已关闭、已升级、已静默 | 可组合受限 | 已升级、已静默可作为附加标记 |
| 接入状态 | 指标已接入、日志已接入、链路已接入、仅日志、仅指标、未接入、采集异常、验证中 | 互斥或多源并存 | 总体接入状态可聚合，分数据源状态需分开展示 |
| 数据源状态 | 正常、延迟、异常、停用、验证中、未知 | 互斥 | Prometheus/Grafana、SkyWalking、ELK/Loki、Agent |
| 规则状态 | 草稿、启用、停用、配置异常、无指标数据 | 互斥 | 配置异常和无指标数据阻断启用 |
| 权限状态 | 已授权、只读、无权限、脱敏、需审批、临时授权 | 可并存 | 只读和脱敏可同时存在 |
| 任务状态 | 待创建、处理中、成功、失败、已过期、已取消 | 互斥 | 导出任务、测试发送、验证接入 |

### 2.2 健康状态聚合优先级

对象健康状态按以下顺序计算，命中高优先级后不被低优先级覆盖：

1. 无权限：不进入健康状态计算；页面展示无权限或过滤掉对象，统计数不泄露。
2. 严重：存在 P0 未恢复告警，或核心生产业务不可用，或健康检查连续失败达到严重阈值。
3. 异常：存在 P1 未恢复告警，或错误率/延迟/实例不可用超过异常阈值。
4. 预警：存在 P2/P3 未恢复告警，或资源接近阈值，或采集延迟但仍有可用数据。
5. 采集异常：数据源曾接入但当前采集失败。列表中展示为接入/数据质量问题，不误判为业务正常。
6. 未接入：对象尚未配置对应指标、日志或链路源。未接入不计入业务异常统计，但计入接入风险统计。
7. 未知：无返回、最近一次数据超过有效窗口、Agent 状态不可判定。
8. 正常：无未恢复告警，关键数据源可用，最近采集时间在有效窗口内。

当业务健康异常与数据源异常同时存在时，表格主状态展示业务健康最高风险，旁边必须展示数据质量标签，例如 `异常 / 指标采集异常`。详情页必须分开展示业务健康和数据源状态。

### 2.3 颜色与文案映射

色值以 `ui-design/visual-system/visual-system.md` token 为源。设计稿应标注 token 名称和文案，不直接散写新色值。

| 语义 | Token | 主色 | 背景 | 边框 | 标签文案 | 典型场景 |
| --- | --- | --- | --- | --- | --- | --- |
| 正常 | `--status-ok` | `#16A34A` | `#EAF7EE` | `#BFE8CB` | 正常、启用、在线、已恢复 | 对象健康、数据源正常 |
| 预警 | `--status-warning` | `#D97706` | `#FFF7E6` | `#F8D89B` | 预警、延迟、仅日志、仅指标 | P2/P3、容量接近阈值、部分接入 |
| 异常 | `--status-error` | `#EA580C` | `#FFF1E8` | `#FDBA8C` | 异常、P1 严重、健康检查失败 | P1、错误率异常 |
| 严重 | `--status-critical` | `#DC2626` | `#FEECEC` | `#F8B4B4` | 严重、P0 紧急、核心不可用 | P0、生产大面积异常 |
| 未知 | `--status-unknown` | `#64748B` | `#F1F5F9` | `#CBD5E1` | 未知、无返回 | 无数据返回、状态不可判定 |
| 未接入 | `--status-restricted` | `#6B7280` | `#F3F4F6` | `#D1D5DB` | 未接入、暂无监控数据 | 尚未配置监控源 |
| 采集异常 | `--status-critical` | `#DC2626` | `#FEECEC` | `#F8B4B4` | 采集异常、数据源异常 | 曾接入但采集失败 |
| 受限 | `--status-restricted` | `#6B7280` | `#F3F4F6` | `#D1D5DB` | 无权限、只读、已脱敏 | 权限和安全 |
| 信息 | `--status-info` | `#2563EB` | `#EFF6FF` | `#BFDBFE` | 验证中、已通知、处理中 | 来源提示、任务进度 |

### 2.4 P0/P1/P2/P3 映射

| 级别 | 名称 | 健康语义 | Token | 标签文案 | 排序权重 | 默认通知要求 |
| --- | --- | --- | --- | --- | --- | --- |
| P0 | 紧急 | 严重 | `--status-critical` | `P0 紧急` | 400 | 电话或短信必选，可追加 IM |
| P1 | 严重 | 异常 | `--status-error` | `P1 严重` | 300 | 短信或 IM 必选 |
| P2 | 一般 | 预警 | `--status-warning` | `P2 一般` | 200 | IM 或邮件 |
| P3 | 提示 | 预警/信息 | `--status-info` | `P3 提示` | 100 | 邮件或 IM |

不得使用“危险”泛指 P0/P1；P0 必须红色，P1 必须橙红色。

| 场景 | 标题 | 辅助说明 | 主操作 |
| --- | --- | --- | --- |

## 4. 告警状态机

### 4.1 生命周期状态

| 状态 | 含义 | 可见动作 | 主动作 | 退出条件 |
| --- | --- | --- | --- | --- |
| 已触发 | 规则命中，尚未完成通知 | 查看详情、查日志、看指标 | 无 | 通知任务创建 |
| 已通知 | 已发送至少一条通知或通知失败已记录 | 确认、标记处理中、添加备注、转派、关闭、查日志 | 确认告警 | 人工确认或恢复 |
| 已确认 | 处理人已确认接收 | 标记处理中、添加备注、转派、关闭、查日志 | 标记处理中 | 开始处理或恢复 |
| 处理中 | 已进入处理过程 | 添加备注、转派、关闭、查日志、看指标 | 添加备注 | 恢复或关闭 |
| 已恢复 | 指标恢复或人工标记恢复 | 关闭、添加处理结论 | 关闭告警 | 关闭 |
| 已关闭 | 告警闭环结束 | 查看审计、复制链接 | 无 | 终态 |
| 已升级 | 升级到上级负责人或值班组 | 确认、处理中、备注、转派、关闭 | 按基础状态决定 | 作为附加标记保留 |
| 已静默 | 在静默窗口内不重复通知 | 查看详情、取消静默 | 无 | 静默到期或取消 |

### 4.2 状态流转

| 当前状态 | 动作 | 权限 | 成功后状态 | 失败回滚 | 必填输入 | 审计事件 |
| --- | --- | --- | --- | --- | --- | --- |
| 已触发 | 通知成功 | 系统 | 已通知 | 保持已触发并记录通知失败 | 无 | notification_send |
| 已触发 | 通知失败 | 系统 | 已通知 + 通知失败标记 | 不回滚 | 失败原因 | notification_send_failed |
| 已通知 | 确认告警 | 处理告警 | 已确认 | 保持已通知 | 可选备注 | alert_ack |
| 已通知/已确认 | 标记处理中 | 处理告警 | 处理中 | 保持原状态 | 可选处理备注 | alert_start_processing |
| 已通知/已确认/处理中 | 添加备注 | 处理告警 | 原状态 | 原状态 | 备注 | alert_comment |
| 已通知/已确认/处理中 | 转派 | 转派权限 | 原状态 + 负责人变更 | 原状态 | 新处理人或值班组、原因 | alert_transfer |
| 已通知/已确认/处理中 | 自动恢复 | 系统 | 已恢复 | 原状态 | 恢复时间、当前值 | alert_recover |
| 已恢复 | 关闭告警 | 处理告警 | 已关闭 | 已恢复 | 关闭原因或结论 | alert_close |
| 未恢复任意可处理状态 | 强制关闭 | 高风险处理权限 | 已关闭 | 原状态 | 关闭原因、二次确认 | alert_force_close |
| 任意非关闭状态 | 静默 | 静默权限；一期可隐藏 | 已静默附加标记 | 原状态 | 静默截止时间、原因 | alert_silence |
| 任意非关闭状态 | 升级 | 升级权限；一期可隐藏 | 已升级附加标记 | 原状态 | 升级对象、原因 | alert_escalate |

测试必须覆盖权限失败、记录失败、通知失败三类异常：

- 权限失败：状态不变，按钮恢复可用，提示“当前角色不能执行该操作”。
- 记录失败：状态不变或后台回滚，提示“处理记录保存失败，请重试”。
- 通知失败：告警状态可继续流转，但通知记录必须标为失败并提供重试入口。

## 5. 审计事件字段

### 5.1 必审事件

| 分类 | 事件类型 |
| --- | --- |
| 告警处理 | 确认、处理中、备注、转派、升级、静默、恢复、关闭、强制关闭 |
| 规则配置 | 新建、修改、复制、启用、停用、删除草稿 |
| 导出 | 列表导出、日志导出、指标数据导出、图表导出、下载导出文件 |
| 权限 | 用户角色变更、菜单权限变更、操作权限变更、应用授权变更、生产权限变更、敏感权限变更 |

## 8. 应用授权衍生范围

应用授权是一期数据权限核心。任何列表、搜索、下拉、统计、导出和 URL 直访都必须按应用授权过滤。

| 授权应用后可见 | 计算规则 | 边界 |
| --- | --- | --- |
| 应用详情 | 授权应用的基础信息、负责人、业务线、实例、接口摘要 | 无接入时可看基础信息和接入状态 |
| 日志 | `log.appId in authorizedAppIds` 且满足环境权限 | 敏感字段仍需敏感权限；值班临时授权仅触发窗口 |
| 指标 | `metric.appId in authorizedAppIds` 或实例归属授权应用 | 生产指标按环境权限限制 |
| 告警 | 告警对象为授权应用，或规则绑定授权应用 | 转派/关闭需处理权限 |
| 关联服务器 | 部署授权应用的服务器摘要 | 未授权应用名称、进程、端口、配置不展示 |
| 告警规则 | 规则对象在授权应用范围 | 新建/修改需操作权限 |
| 接入状态 | 授权应用的接入状态 | 修改接入需接入配置权限 |
| 导出结果 | 当前可见结果子集 | 不导出未授权字段和对象 |

授权预览必须展示：授权应用数、环境范围、可见日志范围、可见指标范围、可见告警范围、关联服务器数、生产权限数量、敏感权限是否包含。未接入应用可授权查看，但指标、日志、告警配置入口按接入状态禁用或引导接入。

共享查询、保存视图、通知记录跳转、复制链接给他人后，接收人仍按自身授权重新过滤。

## 9. 值班组通知解析规则

### 9.1 解析顺序

告警触发时，通知接收人按以下顺序解析：

1. 读取告警规则通知对象：应用负责人、备份负责人、值班组、指定联系人。
2. 若包含值班组，用告警触发时间而非当前查看时间解析当前值班人。
3. 校验接收人状态：用户启用、联系人启用、渠道联系方式存在且格式有效。
4. 按告警级别校验渠道：P0 电话或短信必选；P1 短信或 IM 必选。
5. 当前值班人不可达时，解析备份联系人；仍不可达则标记通知失败。
6. 去重同一用户同一渠道，保留最高优先级来源。
7. 创建通知记录，并写入解析快照。

### 9.2 阻断条件

| 场景 | 规则配置表现 | 告警触发表现 |
| --- | --- | --- |
| 值班组停用 | 不可选择，已绑定规则进入配置异常 | 不解析该组，记录失败 |
| 排班缺失 | 可查看，不可保存并启用 | 记录通知失败：当前时间无值班人 |
| 当前值班人禁用 | 阻断启用 | 解析备份联系人，若无备份则失败 |
| 联系方式缺失 | 若缺少规则所需渠道则阻断启用 | 记录渠道失败并尝试其他渠道/备份 |
| 成员少于 2 人 | 阻断保存并启用 | 已有规则标记配置风险 |
| 渠道停用/异常 | 阻断启用依赖该渠道的规则 | 记录渠道失败 |

### 9.3 通知解析快照字段

通知记录和告警详情通知 Tab 必须可展示：

| 字段 | 说明 |
| --- | --- |
| notificationId | 通知记录 ID |
| alertId | 告警 ID |
| ruleId | 规则 ID |
| triggerTime | 告警触发时间 |
| resolvedDutyGroupId/name | 解析的值班组 |
| resolvedUserId/name | 解析后的接收人 |
| sourceType | 应用负责人、备份负责人、值班组、指定联系人 |
| channel | 短信、电话、邮件、企业微信、钉钉、Webhook |
| maskedTarget | 脱敏手机号、邮箱或 IM |
| sendStatus | 待发送、成功、失败、重试中、部分失败 |
| failureReason | 失败原因 |
| retryCount | 重试次数 |
| auditId | 审计编号 |

## 10. 通知记录规则

通知记录是告警触达链路的验收证据，不只作为配置页跳转。

| 规则 | 说明 |
| --- | --- |
| 记录粒度 | 每个告警、每个渠道、每个接收人生成一条记录 |
| 状态枚举 | 待发送、发送成功、发送失败、重试中、部分失败、已取消 |
| 必填字段 | 通知 ID、告警 ID、规则 ID、触发时间、发送时间、渠道、接收人、脱敏联系方式、状态、失败原因、重试次数 |
| 重试权限 | 平台管理员、运维/SRE、告警处理人可重试；只读用户不可重试 |
| 重试记录 | 每次重试生成新尝试序号，保留原记录，不覆盖失败原因 |
| 失败展示 | 告警详情通知 Tab、通知记录列表、通知渠道详情均可查看 |
| 审计 | 手动重试、渠道变更、联系方式明文查看必须写审计 |
| 权限过滤 | 仅展示用户有权查看的告警相关通知；接收人联系方式默认脱敏 |

通知记录列表筛选项：时间范围、告警 ID、渠道、发送状态、接收人、值班组、规则、失败原因、重试次数、环境、应用。
