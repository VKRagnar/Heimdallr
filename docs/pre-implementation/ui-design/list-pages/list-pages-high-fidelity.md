# 企业级统一监控平台列表、查询与状态页高保真设计说明

## 1. 文档定位

本文用于关闭 UI 高保真评审中“列表/查询类页面高保真承接”缺口，承接 `product-prototype/list-and-states/list-and-states-prototype.md`，并与视觉系统、组件规范保持一致。

覆盖页面：

- 应用列表
- 服务器列表
- 告警列表
- 指标查询
- 通知记录
- 日志查询补充态
- 通用状态页
- 导出任务状态

统一设计约束：

1. 列表和查询页采用高密度工作台布局：标题操作、筛选区、来源或数据质量提示、汇总条、表格或图表、分页和查询说明。
2. 默认按应用授权过滤，未授权对象不出现在筛选项、统计数、聚合计数、导出任务和跳转上下文中。
3. 状态标签使用正常、预警、异常、严重、未知、受限、信息语义，不只依赖颜色。
4. 导出、告警处理、通知重试、敏感字段明文查看、共享查询均需权限提示和审计记录。
5. 从告警、应用、服务器、日志、指标之间跳转时，必须回显来源、对象、环境、时间窗口和返回入口。

## 2. 全局页面骨架

### 2.1 首屏结构

```text
页面标题区：面包屑 / 标题 / 授权范围 / 刷新时间 / 数据源状态 / 页面操作
筛选区：核心筛选第一行，高级筛选折叠，查询、重置、保存、刷新右对齐
上下文区：来源提示、数据延迟、数据源异常、只读权限提示
汇总区：总数、风险状态、未恢复、失败、已选数量、当前过滤说明
主内容区：表格、趋势图、日志结果、任务列表
底部区：分页、每页条数、查询耗时、最近成功采集时间、导出任务入口
```

### 2.2 通用控件规格

| 项目 | 高保真要求 |
| --- | --- |
| 页面内边距 | 桌面端 24px，小屏 16px |
| 筛选区 | 白底或弱背景，最多两行；高级筛选折叠 |
| 表格 | 表头 40px，行高 40px 到 44px，名称、状态、操作列固定或不可隐藏 |
| 操作按钮 | 页面级主操作 32px；行内超过 3 个操作收起到更多 |
| 来源提示条 | 信息色浅底，展示来源页面、对象、环境、时间窗口和返回入口 |
| 数据异常条 | 模块内提示，展示异常源、影响范围、最近成功时间和重试入口 |
| 空态 | 表格内轻量空态，说明原因并提供一个主操作 |

### 2.3 通用响应式

| 断点 | 表现 |
| --- | --- |
| 1440px 及以上 | 导航展开，筛选、汇总和宽表完整展示 |
| 1024px 到 1439px | 次要筛选进入高级筛选；次要表格列默认折叠 |
| 768px 到 1023px | 左侧导航折叠；保留对象、状态、负责人、时间和主操作 |
| 小于 768px | 列表切换为紧凑行或摘要卡；批量操作进入底部固定操作条；图表图例折叠 |

## 3. 应用列表

### 3.1 页面目标

让研发负责人和运维快速判断授权应用的运行状态、负责人、接入状态、当前告警和下一步排障入口。

### 3.2 首屏优先级

1. 授权应用数、异常和严重应用数、未接入数量、数据延迟提示。
2. 应用名称/编码、环境、状态、负责人、当前告警核心筛选。
3. 风险优先排序的应用表格。
4. 详情、日志、指标、告警跳转入口。

### 3.3 布局

```text
应用监控 / 应用列表                  授权应用 36 个 / 更新于 10:31:20
[刷新] [保存视图] [导出]

应用名称/编码  环境  状态  业务线  负责人  接入状态  当前告警  [查询] [重置]
高级：所属系统、部门、技术栈、标签、是否我负责、仅看生产、最近发布

全部 36 | 正常 28 | 预警 4 | 异常 3 | 严重 1 | 未接入 5 | 数据延迟 2
已选 3 项  [批量查看告警] [批量导出] [添加到关注]

应用表格
分页 / 查询耗时 / 数据延迟说明
```

| --- | --- | --- | --- |

| 最近发布 | 快捷时间 | 全部 | 24 小时、7 天、30 天、自定义 |

| 环境 | 标签 | 支持 | 生产突出 |

### 3.6 批量操作

| 操作 | 出现条件 | 权限表现 | 结果 |
| --- | --- | --- | --- |
| 批量查看告警 | 已选应用 | 告警查看权限 | 跳告警列表，带入应用集合、环境、未恢复 |
| 批量导出 | 已选应用或当前筛选 | 导出权限；无权限置灰 | 导出摘要，超 5000 行进入任务 |
| 添加到关注 | 已选应用 | 查看权限 | 加入个人关注并 toast 提示 |

### 3.7 行内操作

| 操作 | 上下文 |
| --- | --- |
| 详情 | 应用编码、环境、返回列表筛选 |
| 日志 | 应用、环境、最近 1 小时、日志级别默认全部 |
| 指标 | 应用、环境、最近 6 小时、默认核心指标 |
| 告警 | 应用、环境、未恢复优先 |
| 接入指引 | 应用编码、缺失数据源类型 |

### 3.8 状态文案

| 场景 | 文案 | 主操作 |
| --- | --- | --- |
| 无匹配应用 | 未找到符合条件的应用。请调整筛选条件，或确认你是否已获得应用授权。 | 重置筛选 |
| 无授权应用 | 当前账号暂无可查看应用。请联系平台管理员或应用负责人申请应用数据权限。 | 申请权限 |
| 未接入监控 | 该应用尚未完整接入指标或日志，状态可能不完整。 | 查看接入指引 |
| 数据延迟 | 部分应用数据延迟超过 5 分钟，列表状态可能不是最新。 | 查看数据源状态 |

### 3.9 权限表现

未授权应用不出现在搜索、筛选、表格和统计数中。只有菜单权限但无应用数据权限时展示授权空态。只读用户可查看详情、日志、指标和告警，导出和共享视图置灰并说明原因。

### 3.10 数据源异常

应用列表顶部展示数据质量提示条，标明指标源、日志源或链路源异常。表格行内接入状态显示采集异常，更新时间展示最近成功采集时间。

### 3.11 导出受控

导出默认导出当前筛选或已选应用摘要。生产环境、超过 1000 行、包含负责人联系方式时弹出确认；超过 5000 行创建后台任务；导出记录审计编号。

### 3.12 跳转上下文

所有跳转携带应用编码、环境、时间范围、来源列表筛选 ID。目标页显示来源提示条并支持返回应用列表原筛选。

### 3.13 响应式

1024px 以下保留应用名称、状态、负责人、当前告警、更新时间、操作；系统、业务线、P95、最近发布进入展开行。小屏批量操作固定在底部。

### 3.14 验收点

1. 筛选、统计和表格只包含授权应用。
2. 表格可按状态、告警、错误率、P95、发布时间排序。
3. 行内跳转能带入应用、环境和时间上下文。
4. 未接入、数据延迟、数据源异常有明确标签和文案。
5. 导出权限、二次确认、后台任务和审计提示完整。

## 4. 服务器列表

### 4.1 页面目标

帮助运维和 SRE 定位高负载、异常、Agent 离线或与应用故障相关的服务器，并反向追踪部署应用。

### 4.2 首屏优先级

1. 授权关联主机数量、Agent 离线、高负载、严重异常。
2. 主机名/IP、环境、状态、关联应用、Agent、资源阈值筛选。
3. CPU、内存、磁盘、当前告警风险排序。
4. 指标、告警、关联应用入口。

### 4.3 布局

```text
服务器监控 / 服务器列表             授权关联主机 128 台 / 更新于 10:31:20
[刷新] [保存视图] [导出]

主机名/IP  环境  区域  分组  状态  关联应用  Agent  资源阈值  [查询]
高级：负责人、云厂商、机房、实例规格、是否仅看生产、数据延迟

全部 128 | 正常 102 | 预警 16 | 异常 8 | 严重 2 | Agent 离线 4
分组视图：全部 / 按业务线 / 按应用 / 按环境 / 按区域
已选 5 项 [批量查看指标] [批量查看告警] [批量导出]

服务器表格
```

| Agent 状态 | 单选 | 全部 | 在线、离线、版本过低、配置异常 |

| 内存 | 当前使用率 | 支持 | 超阈值高亮 |

| 更新时间 | 最近采集时间 | 支持 | 延迟时提示 |
| 操作 | 详情、指标、告警、关联应用、更多 | 不支持 | 固定右侧 |

### 4.6 批量操作

| 操作 | 权限表现 | 结果 |
| --- | --- | --- |
| 批量查看指标 | 指标查看权限 | 跳指标查询，带入服务器集合、系统指标、最近 6 小时 |

| 批量导出 | 导出权限；无权限置灰 | 导出资源摘要和当前告警摘要 |

### 4.7 行内操作

| 操作 | 上下文 |
| --- | --- |
| 详情 | 主机 ID、环境、返回筛选 |
| 指标 | 主机、环境、CPU/内存/磁盘/网络、最近 6 小时 |
| 告警 | 主机、未恢复、最近 24 小时 |
| 关联应用 | 主机、授权应用范围 |
| 查看 Agent | 主机、Agent 版本、最近心跳 |

### 4.8 状态文案

| 场景 | 文案 | 主操作 |
| --- | --- | --- |
| 无匹配服务器 | 未找到符合条件的服务器。请调整筛选条件或检查应用关联关系。 | 重置筛选 |
| Agent 离线 | Agent 已离线，资源指标可能停止更新。 | 查看 Agent 状态 |
| 部分应用不可见 | 该服务器部署了你无权查看的应用，相关应用名称和日志已隐藏。 | 申请更多权限 |
| 数据源异常 | 服务器指标源当前不可用，列表展示最近一次成功采集数据。 | 重试 |

### 4.9 权限表现

服务器默认显示与授权应用存在部署关系的主机，或用户直接拥有基础设施查看权限的主机。未授权应用名称、端口、日志和指标细节不展示，统计数也不包含未授权对象。

### 4.10 数据源异常

Agent 心跳异常、指标源异常和部分数据延迟使用行内状态标签 + 顶部提示条。可展示最近一次成功采集数据，但必须标注采集时间。

### 4.11 导出受控

导出字段默认排除未授权应用明细和脱敏联系方式。超过 5000 行进入后台任务；包含生产服务器 IP 清单时弹出二次确认并提示审计。

### 4.12 跳转上下文

服务器跳指标带入主机 ID、环境、系统指标分组和时间范围；跳告警带入主机集合和未恢复状态；跳关联应用只展示授权应用。

### 4.13 响应式

1024px 以下保留主机名、IP、状态、CPU、内存、Agent、当前告警、操作；网络、区域、磁盘、部署应用进入展开行。

### 4.14 验收点

1. 服务器可见性遵循应用授权衍生规则。
2. Agent 离线、版本过低、配置异常有明确状态和最近心跳。
3. CPU、内存、磁盘、告警、更新时间可排序。
4. 批量查看指标、告警和导出按权限控制。
5. 未授权应用信息不泄露。

## 5. 告警列表

### 5.1 页面目标

集中承载告警筛选、排序、批量处理和证据跳转，让值班人员优先处理未恢复、未确认、高级别告警。

### 5.2 首屏优先级

1. 未恢复、未确认、P0/P1、已升级和通知失败数量。
2. 级别、状态、对象、负责人、环境、时间核心筛选。
3. 风险排序告警表格。
4. 确认、处理中、转派、日志、指标操作。

### 5.3 布局

```text
告警中心 / 告警列表                  未恢复优先 / 更新于 10:31:20
[刷新] [保存查询] [导出]

级别  状态  对象类型  应用/服务器  负责人  环境  时间  关键字  [查询]
高级：规则名称、通知状态、是否升级、是否静默、值班组、告警来源

未恢复 18 | 未确认 10 | 处理中 4 | 已升级 2 | 已恢复 36 | P0 1 | P1 7 | 通知失败 3
已选 4 项 [批量确认] [批量标记处理中] [批量转派] [批量导出]

告警表格
```

| --- | --- | --- | --- |
| 批量复制脱敏日志 | 选择日志行 | 查看权限 | 复制脱敏内容 |
| 批量导出 | 已选或当前筛选 | 导出权限 | 生产或超量进入受控流程 |
| 批量关联告警 | 选择日志行 | 告警处理权限 | 添加到告警处理备注或证据 |

### 8.7 行内操作

| 操作 | 上下文 |
| --- | --- |
| 上下文 | 同应用、同实例、同日志文件或同 Trace ID，前后 20 行 |
| 复制 | 默认复制脱敏日志 |
| 看指标 | 应用、实例、日志时间前后 15 分钟 |
| 关联告警 | 告警 ID、日志行 ID |
| 明文查看 | 敏感字段权限，记录审计 |

### 8.8 状态文案

| 场景 | 文案 | 主操作 |
| --- | --- | --- |
| 无命中日志 | 当前条件下未命中日志。请扩大时间范围，或检查应用、实例和关键字。 | 调整时间范围 |
| 查询超时 | 日志查询超时，请缩小时间范围或增加应用/实例条件。 | 缩小范围 |
| 日志源异常 | 日志数据源暂不可用，可能影响查询完整性。 | 重试 |
| 字段无权限 | 部分敏感字段已脱敏展示。 | 申请明文权限 |

### 8.9 权限表现

日志结果严格按应用授权过滤。敏感字段默认脱敏，明文查看、明文复制、生产日志导出需要单独权限和审计。共享查询对接收人继续执行授权过滤。

### 8.10 数据源异常

日志源异常在结果区顶部提示，不清空已有结果；可展示最近一次成功查询的结果时必须标注时间。字段分布或错误聚合失败为局部异常，不影响日志主列表。

### 8.11 导出受控

无导出权限时按钮置灰。生产日志导出弹窗展示应用、环境、时间范围、预估条数、脱敏策略和审计提示；超量创建导出任务；失败显示审计编号和重试入口。

### 8.12 跳转上下文

告警跳入日志时自动带入应用、环境、实例、触发时间前后 30 分钟、ERROR 和告警 ID。日志跳指标带入日志时间点前后 15 分钟；日志跳告警带入 Trace ID 或错误签名。

### 8.13 响应式

1024px 以下错误聚合面板折叠为顶部 Tab；日志表格保留时间、级别、Trace ID、内容、操作，应用和实例进入行内副信息。

### 8.14 验收点

1. 告警跳日志能自动回显来源和时间窗口。
2. 错误聚合支持按签名过滤、样例日志、关联告警。
3. 上下文和堆栈展开遵循同应用、同实例、同日志文件或同 Trace ID 限制。
4. 敏感字段脱敏、明文查看和复制受控。
5. 日志导出覆盖无权限、生产二次确认、超量任务和失败重试。

## 9. 通用状态页

### 9.1 页面目标

为列表、查询、详情和配置入口提供一致的空、加载、数据源异常、无权限、未接入和受限状态，避免误判和权限泄露。

### 9.2 首屏优先级

1. 状态原因和影响范围。
2. 一个主操作和最多两个次操作。
3. 最近成功时间、数据源或权限说明。
4. 返回入口或申请路径。

### 9.3 布局

```text
状态图标
状态标题
状态说明
[主操作] [次操作]
辅助信息：数据源 / 最近成功时间 / 审计编号 / 权限范围
```

状态页可作为整页状态，也可嵌入表格、图表、侧栏和抽屉。列表无数据优先嵌入表格区域，不使用大型装饰插画。

### 9.4 筛选器

通用状态页本身不提供独立筛选器。嵌入列表或查询区域时，保留原筛选条件并提供“重置筛选”“扩大时间范围”“申请权限”等操作。

### 9.5 表格列

通用状态页不包含表格列。若用于表格空态，保留表头、列设置和分页位置，避免布局跳动。

### 9.6 批量操作

无数据、无权限、加载、异常状态下批量操作禁用或隐藏。已选择数据后发生局部异常时，保留选择状态但禁用提交，并展示异常原因。

### 9.7 行内操作

通用状态页无行内操作。模块内异常可提供“重试”“查看数据源状态”“申请权限”“查看接入指引”“返回上一页”。

### 9.8 状态文案

| 状态 | 标题 | 说明 | 主操作 |
| --- | --- | --- | --- |
| 列表无匹配 | 未找到符合条件的数据 | 请调整筛选条件，或重置后重新查询。 | 重置筛选 |
| 授权范围为空 | 暂无可查看数据 | 当前账号没有授权应用，因此无法查看关联日志、指标、告警和服务器。 | 申请应用权限 |
| 未接入数据 | 暂无监控数据 | 对象尚未接入对应数据源，状态可能不完整。 | 查看接入指引 |
| 历史数据为空 | 当前时间范围暂无数据 | 可扩大时间范围或切换环境查看。 | 扩大时间范围 |
| 加载中 | 正在加载数据 | 请稍候，复杂查询可能需要几秒。 | 无 |
| 查询超时 | 查询超时 | 请缩小时间范围或增加对象条件后重试。 | 缩小范围 |
| 数据源异常 | 数据源暂不可用 | 已展示最近一次成功数据时，请以采集时间为准。 | 重试 |
| 无菜单权限 | 你暂无访问该页面的权限 | 请申请菜单权限或联系管理员。 | 申请权限 |
| 无操作权限 | 当前角色不能执行该操作 | 你仍可查看已授权范围内的数据。 | 申请权限 |
| 敏感字段受限 | 字段已脱敏展示 | 明文查看需要额外权限并记录审计。 | 申请明文权限 |

### 9.9 权限表现

无权限状态不展示未授权对象名称、数量、日志内容、指标值和聚合结果。直访无权限对象时展示通用无权限页，说明“当前对象不在你的授权范围内”，不回显完整对象详情。

### 9.10 数据源异常

异常状态必须说明具体来源，如指标源、日志源、Agent、通知记录源。可局部重试，不阻塞其他模块；展示历史缓存时必须显示最近成功时间。

### 9.11 导出受控

通用状态页中的导出无权限、导出失败、后台任务创建成功均使用一致文案。导出失败需展示失败原因、重试入口和审计编号。

### 9.12 跳转上下文

状态页返回上级页面时保留原筛选、排序、分页和时间范围。申请权限入口带入来源页面、对象类型和申请原因模板。

### 9.13 响应式

小屏状态页居中但不使用过大图标，标题不超过两行，说明不超过三行；主操作按钮固定在说明下方。

### 9.14 验收点

1. 空、加载、异常、无权限、未接入、导出受控文案一致。
2. 加载状态不显示误导性 0 值。
3. 无权限状态不泄露对象明细和统计数。
4. 数据源异常可局部重试，并展示最近成功时间。
5. 状态页返回和权限申请能带入上下文。

## 10. 导出任务状态

### 10.1 页面目标

承接列表、指标、日志、告警、通知记录等超量或受控导出，展示任务进度、审批/权限、失败原因、下载有效期和审计编号。

### 10.2 首屏优先级

1. 任务状态：排队中、处理中、待确认、成功、失败、已过期、无权限。
2. 导出来源、范围、预估/实际条数、脱敏策略。
3. 下载、重试、取消、查看审计操作。
4. 最近任务列表和通知方式。

### 10.3 布局

```text
系统管理 / 导出任务                 [刷新]

任务名称/审计编号  来源页面  状态  创建人  时间  [查询]
高级：对象范围、环境、数据类型、脱敏策略、失败原因、下载有效期

全部 48 | 排队中 3 | 处理中 5 | 成功 32 | 失败 4 | 已过期 4
已选 2 项 [批量取消] [批量删除过期记录]

导出任务表格
任务详情抽屉
```

### 10.4 筛选器

| 筛选器 | 控件 | 默认值 | 高保真要求 |
| --- | --- | --- | --- |
| 任务名称/审计编号 | 搜索框 | 空 | 支持任务 ID、审计编号 |
| 来源页面 | 多选下拉 | 全部 | 应用列表、服务器列表、告警列表、指标查询、日志查询、通知记录 |
| 状态 | 多选标签 | 全部 | 排队中、处理中、待确认、成功、失败、已取消、已过期、无权限 |
| 创建人 | 下拉 | 我创建 | 管理员可看授权范围内任务 |
| 时间范围 | 快捷时间 | 最近 7 天 | 创建时间或完成时间 |
| 环境 | 多选 | 全部 | 生产突出 |
| 数据类型 | 高级筛选 | 全部 | 列表、指标、日志、告警、通知 |
| 脱敏策略 | 高级筛选 | 全部 | 默认脱敏、明文审批、字段排除 |
| 失败原因 | 高级筛选 | 全部 | 数据源异常、超时、无权限、任务过期 |

### 10.5 表格列

| 列 | 展示 | 排序 | 备注 |
| --- | --- | --- | --- |
| 任务名称 | 名称 + 任务 ID | 支持 | 点击详情抽屉 |
| 来源页面 | 页面标签 | 支持 | |
| 导出范围 | 对象、环境、时间摘要 | 不支持 | 长文本折叠 |
| 数据量 | 行数或点数 | 支持 | |
| 脱敏策略 | 策略标签 | 支持 | |
| 状态 | 状态标签 + 进度 | 默认 | |
| 创建人 | 用户 | 支持 | |
| 创建时间 | 时间 | 支持 | |
| 完成时间 | 时间 | 支持 | |
| 下载有效期 | 截止时间 | 支持 | 过期突出 |
| 审计编号 | 编号 | 支持 | 可复制 |
| 操作 | 下载、重试、取消、详情、查看审计 | 不支持 | 固定右侧 |

### 10.6 批量操作

| 操作 | 出现条件 | 权限表现 | 校验 |
| --- | --- | --- | --- |
| 批量取消 | 排队中或处理中任务 | 创建人或管理员 | 取消后不可恢复 |
| 删除过期记录 | 已过期任务 | 管理员或创建人 | 只删除下载入口，不删除审计 |
| 批量重试 | 失败任务 | 导出权限仍有效 | 重新校验授权和数据范围 |

### 10.7 行内操作

| 操作 | 上下文 |
| --- | --- |
| 下载 | 任务 ID、下载有效期、权限复核 |
| 重试 | 原筛选条件、当前权限、失败原因 |
| 取消 | 任务 ID、取消原因 |
| 详情 | 任务范围、字段、脱敏策略、审计信息 |
| 查看审计 | 审计编号、操作人、时间、条件和结果范围 |

### 10.8 状态文案

| 状态 | 文案 | 主操作 |
| --- | --- | --- |
| 排队中 | 导出任务已创建，正在排队处理。 | 取消任务 |
| 处理中 | 正在生成导出文件，请稍候。 | 刷新 |
| 待确认 | 该导出涉及生产或敏感数据，请确认导出范围和脱敏策略。 | 确认导出 |
| 成功 | 导出文件已生成，请在有效期内下载。 | 下载 |
| 失败 | 导出失败，请查看失败原因后重试。 | 重试 |
| 已过期 | 下载链接已过期，可重新创建导出任务。 | 重新导出 |
| 无权限 | 当前角色暂无该导出任务的下载权限。 | 申请权限 |

### 10.9 权限表现

用户默认只看自己创建的导出任务；管理员可看授权范围内任务。下载时再次校验当前权限，权限变化后不允许下载历史明文或越权数据。

### 10.10 数据源异常

任务失败原因需标明具体数据源。若数据源异常导致失败，保留原任务条件，支持重试；重试前重新校验权限、数据源状态和脱敏策略。

### 10.11 导出受控

所有后台任务都记录来源页面、筛选条件、对象范围、字段范围、脱敏策略、创建人、下载人、下载时间和审计编号。下载链接有效期默认可配置，过期后不可下载。

### 10.12 跳转上下文

从任一页面创建后台导出后，toast 提供“查看导出任务”。任务详情提供“返回来源页面”，带入原筛选条件但重新按当前权限查询。

### 10.13 响应式

小屏保留任务名称、来源、状态、创建时间、操作；范围、数据量、脱敏策略、审计编号进入详情抽屉。

### 10.14 验收点

1. 超量导出能创建后台任务并展示进度。
2. 任务状态、失败原因、下载有效期和审计编号清晰可见。
3. 下载前重新校验权限。
4. 生产、日志、敏感字段导出有确认和脱敏策略。
5. 可从来源页面进入任务，并从任务返回原筛选上下文。

## 12. 总体验收清单

1. 应用列表、服务器列表、告警列表、指标查询、通知记录、日志查询补充态均具备页面目标、首屏优先级、布局、筛选器、表格列、批量操作、行内操作、状态文案、权限表现、数据源异常、导出受控、跳转上下文、响应式和验收点。
2. 通用状态页覆盖空、加载、无权限、数据源异常、未接入、查询超时、敏感字段受限。
3. 导出任务状态覆盖可导出、二次确认、后台任务、失败、过期、无权限和审计编号。
4. 所有列表和查询页均按应用授权过滤，未授权对象不在下拉、搜索、统计数、聚合和导出任务中泄露。
5. 所有跨页面跳转均带入对象、环境、时间范围、来源页面和返回入口。
