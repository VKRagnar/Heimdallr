# 企业级统一监控平台 UI 高保真视觉规范

## 1. 文档定位

本文用于指导企业级统一监控平台一期页面的高保真设计稿和前端实现，覆盖首页总览、应用监控、服务器监控、日志中心、指标中心、告警中心、通知与值班、接入管理、系统管理等核心页面。

设计依据：

- `demand/monitoring-platform-requirements.md`
- `architecture/information-architecture.md`
- `prototype/low-fidelity-prototype.md`
- `product-prototype/README.md`
- `product-prototype` 下核心排障链路、配置管理链路、列表查询与状态页、验收清单

平台视觉定位：专业、克制、高密度、清晰可判读。它是研发负责人、运维/SRE、值班人员在故障中使用的排障工作台，不是营销官网、展示大屏或装饰性驾驶舱。

## 2. 设计原则

### 2.1 排障优先

首屏优先回答四个问题：哪里异常、影响什么、谁负责、下一步去哪处理。首页、详情页和告警页的信息排序应优先呈现 P0/P1、待处理问题、触发值、阈值、持续时间、负责人、日志和指标入口。

### 2.2 信息可信

所有状态、指标和趋势都必须能说明数据来源和更新时间。未接入、数据延迟、数据源异常、Agent 离线不得被包装成正常状态。

### 2.3 高密度但不拥挤

监控平台需要同时呈现筛选、表格、图表、日志和处理记录。视觉上采用紧凑行高、清晰分组、弱分割线、稳定列宽和克制留白，避免大面积空白、超大卡片、营销式 hero。

### 2.4 上下文连续

从首页、告警详情、日志查询、应用详情、指标趋势跳转时，应通过来源提示条、面包屑、筛选回显、时间窗口标记保持上下文。

### 2.5 权限不泄露

无权限状态不能泄露未授权应用、日志内容、敏感字段和统计数量。视觉上用锁定态、脱敏文本和申请入口表达受控，而不是显示被遮挡的真实内容。

## 3. 信息密度

### 3.1 密度等级

| 场景 | 密度 | 适用页面 | 视觉要求 |
| --- | --- | --- | --- |
| 紧凑 | 高 | 告警列表、日志查询、应用/服务器列表 | 表格行高 40px，筛选区双行以内，操作按钮图标化 |
| 标准 | 中高 | 首页总览、应用详情、告警详情、指标查询 | 卡片/模块间距 16px，表格行高 44px，图表高度稳定 |
| 宽松 | 中 | 权限空态、无数据、异常状态、表单分步配置 | 说明清晰，操作入口明确，不使用大插画占位 |

### 3.2 首屏信息优先级

1. 页面标题、关键状态、环境、刷新时间。
2. 核心筛选：环境、应用/对象、负责人、状态、时间范围。
3. 风险摘要：P0/P1、异常对象、未恢复告警、数据源异常。
4. 主工作区：待处理队列、表格、日志结果、指标趋势。
5. 次级信息：历史记录、审计、配置说明、帮助入口。

## 4. 页面布局与栅格

### 4.1 全局框架

| 区域 | 尺寸 | 说明 |
| --- | --- | --- |
| 顶部栏 | 56px 高 | 平台名称、全局搜索、环境、刷新状态、通知、用户菜单 |
| 左侧导航 | 216px 宽；可折叠为 64px | 一级导航固定，图标 + 文案；当前导航高亮 |
| 内容区 | 最小宽度 1200px 适配，最大不强制居中 | 面向工作台，优先横向信息容量 |
| 页面内边距 | 24px；窄屏 16px | 列表页和查询页保持一致 |
| 模块间距 | 16px | 同级模块统一间距 |

### 4.2 栅格

- 内容区采用 12 列栅格，列间距 16px。
- 首页摘要卡建议 5 列等分，低于 1440px 时变为 3 + 2。
- 详情页采用 `8 + 4` 或 `7 + 5` 结构：左侧证据区，右侧快速定位/处理区。
- 配置表单采用 2 列布局，复杂规则配置可用分段表单；字段说明在输入控件下方，不挤占主标签。
- 表格、日志、趋势图必须有稳定高度和最小宽度，避免数据加载后布局跳动。

### 4.3 页面模式

| 页面类型 | 布局模式 | 关键规范 |
| --- | --- | --- |
| 首页总览 | 筛选条 + 摘要卡 + 待处理队列 + 趋势/排行 | 待处理队列优先，不做纯统计大屏 |
| 列表页 | 标题操作 + 筛选区 + 汇总条 + 表格 | 表格是主视觉，卡片只用于状态汇总 |
| 详情页 | 摘要头 + 指标/证据区 + Tab 明细 | 摘要头必须显示状态、环境、负责人、时间 |
| 查询页 | 查询条件 + 来源提示 + 结果区 | 日志和指标支持来源回跳 |
| 配置页 | 列表 + 抽屉/分步表单 | 高风险变更使用确认弹窗和审计提示 |

## 5. 色彩系统

### 5.1 基础色

整体采用冷静中性色 + 有限强调色。背景不使用大面积渐变、装饰光斑或高饱和色块。

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--color-bg-page` | `#F5F7FA` | 页面背景 |
| `--color-bg-surface` | `#FFFFFF` | 面板、表格、抽屉 |
| `--color-bg-subtle` | `#F8FAFC` | 表头、筛选区、弱背景 |
| `--color-bg-hover` | `#F1F5F9` | 行悬停、菜单悬停 |
| `--color-border` | `#DDE3EA` | 默认边框 |
| `--color-border-subtle` | `#E8EDF3` | 表格分割线 |
| `--color-text-primary` | `#1F2937` | 主文本 |
| `--color-text-secondary` | `#52616F` | 次级文本 |
| `--color-text-tertiary` | `#7A8794` | 辅助说明、占位 |
| `--color-text-disabled` | `#A6B0BA` | 禁用文本 |
| `--color-primary` | `#2563EB` | 主操作、链接、选中态 |
| `--color-primary-hover` | `#1D4ED8` | 主操作 hover |
| `--color-focus` | `#60A5FA` | 焦点描边 |

### 5.2 状态色

状态色必须语义一致，用色面积受控。严重状态不应只依赖颜色，必须配合文字、图标或级别标签。

| 状态 | Token | 色值 | 背景 | 边框 | 使用 |
| --- | --- | --- | --- | --- | --- |
| 正常 | `--status-ok` | `#16A34A` | `#EAF7EE` | `#BFE8CB` | 正常、启用、在线 |
| 预警 | `--status-warning` | `#D97706` | `#FFF7E6` | `#F8D89B` | P2/P3、容量接近阈值 |
| 异常 | `--status-error` | `#EA580C` | `#FFF1E8` | `#FDBA8C` | P1、错误率异常、健康检查失败 |
| 严重 | `--status-critical` | `#DC2626` | `#FEECEC` | `#F8B4B4` | P0、核心业务不可用 |
| 未知 | `--status-unknown` | `#64748B` | `#F1F5F9` | `#CBD5E1` | 未接入、无返回、未知 |
| 受限 | `--status-restricted` | `#6B7280` | `#F3F4F6` | `#D1D5DB` | 无权限、脱敏、只读 |
| 信息 | `--status-info` | `#2563EB` | `#EFF6FF` | `#BFDBFE` | 验证中、提示、来源说明 |

### 5.3 告警级别色

| 级别 | 名称 | 主色 | 背景 | 视觉重量 |
| --- | --- | --- | --- | --- |
| P0 | 紧急 | `#DC2626` | `#FEECEC` | 最高；标签实底或强描边，列表置顶 |
| P1 | 严重 | `#EA580C` | `#FFF1E8` | 高；标签描边 + 浅底 |
| P2 | 一般 | `#D97706` | `#FFF7E6` | 中；浅底标签 |
| P3 | 提示 | `#2563EB` | `#EFF6FF` | 低；浅底标签 |

告警趋势图中 P0/P1 线条可更醒目，P2/P3 降低透明度。P0 与 P1 不应使用相近红色，避免无法区分。

## 6. 字体与文本层级

### 6.1 字体

- 中文优先：`PingFang SC`, `Microsoft YaHei`, `Noto Sans CJK SC`, sans-serif。
- 数字、指标、日志等值：`Inter`, `Roboto`, `Arial`, sans-serif。
- 代码、Trace ID、日志内容：`JetBrains Mono`, `Consolas`, `Menlo`, monospace。

### 6.2 字号层级

| 层级 | 字号/行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| 页面标题 | 20px / 28px | 600 | 页面主标题 |
| 模块标题 | 16px / 24px | 600 | 卡片、表格、图表标题 |
| 卡片主数值 | 28px / 36px | 600 | 首页摘要指标 |
| 强调数值 | 22px / 30px | 600 | 详情页核心指标 |
| 正文 | 14px / 22px | 400 | 表格、表单、说明 |
| 表格紧凑正文 | 13px / 20px | 400 | 高密度表格、日志摘要 |
| 辅助文本 | 12px / 18px | 400 | 单位、更新时间、字段提示 |
| 日志文本 | 12px / 20px | 400 | 日志内容、堆栈 |

数值与单位之间保留 2-4px 间距，单位使用辅助文本色。百分比、毫秒、QPS 等指标值采用等宽数字特性。

## 7. 间距、圆角与阴影

### 7.1 间距

使用 4px 基础步进：

| Token | 值 | 用途 |
| --- | --- | --- |
| `--space-1` | 4px | 图标与文本、紧凑标签内距 |
| `--space-2` | 8px | 表单控件内部、按钮内距 |
| `--space-3` | 12px | 筛选项间距、表格单元格左右 |
| `--space-4` | 16px | 模块间距、卡片内距 |
| `--space-6` | 24px | 页面内边距、分区间距 |
| `--space-8` | 32px | 大区块间距 |

### 7.2 圆角

| Token | 值 | 用途 |
| --- | --- | --- |
| `--radius-sm` | 4px | 标签、输入框、表格选中态 |
| `--radius-md` | 6px | 按钮、下拉、提示条 |
| `--radius-lg` | 8px | 面板、卡片、抽屉内容块 |

不使用超过 8px 的大圆角，避免监控平台显得消费化或营销化。

### 7.3 阴影

阴影只用于浮层、下拉、抽屉、弹窗和悬浮操作条，不用于普通页面区块堆叠。

| Token | 值 | 用途 |
| --- | --- | --- |
| `--shadow-sm` | `0 1px 2px rgba(15, 23, 42, 0.06)` | 悬浮工具条 |
| `--shadow-md` | `0 8px 24px rgba(15, 23, 42, 0.12)` | 下拉、Popover |
| `--shadow-lg` | `0 16px 40px rgba(15, 23, 42, 0.16)` | 抽屉、弹窗 |

## 8. 图标系统

### 8.1 图标风格

- 使用线性图标，线宽 1.75px 或 2px。
- 尺寸：导航 18px，按钮 16px，状态 14px，空态 48px。
- 图标必须服务识别和操作，不做装饰性堆砌。

### 8.2 推荐图标语义

| 场景 | 图标语义 |
| --- | --- |
| 首页总览 | 仪表盘、活动脉冲 |
| 应用监控 | 方块/应用窗口 |
| 服务器监控 | 服务器 |
| 日志中心 | 文档/终端 |
| 指标中心 | 折线图 |
| 告警中心 | 警示三角/铃铛 |
| 通知与值班 | 用户组/电话 |
| 接入管理 | 插头/数据源 |
| 系统管理 | 设置/盾牌 |
| 无权限 | 锁 |
| 数据源异常 | 断链/告警圆点 |

状态图标必须与颜色和文字同时出现，例如 `P1 严重` 不只显示橙色圆点。

## 9. 通用组件视觉规范

### 9.1 顶部栏

- 高度 56px，白底，底部分割线 `#E8EDF3`。
- 左侧显示平台名称，字重 600。
- 全局搜索宽度 280-360px，支持搜索应用、服务器、告警 ID、Trace ID。
- 环境切换使用下拉或分段控件，生产环境标签使用轻微强调。
- 刷新状态显示最近刷新时间；自动刷新中使用小型旋转/脉冲图标，不打断用户。

### 9.2 左侧导航

- 宽 216px，背景 `#0F172A` 或 `#111827`，文字 `#CBD5E1`。
- 当前项使用左侧 3px 主色条 + 深色高亮背景。
- 一级导航顺序与信息架构一致：首页总览、应用监控、服务器监控、日志中心、指标中心、告警中心、通知与值班、接入管理、系统管理。
- 二期不可用入口默认隐藏，不展示空白菜单。

### 9.3 页面标题区

包含面包屑、页面标题、关键状态标签、页面级操作。详情页标题区必须显示对象状态、环境和更新时间，例如：`order-api / 生产 / 异常 / 更新于 10:31:20`。

### 9.4 按钮

| 类型 | 高度 | 视觉 |
| --- | --- | --- |
| 主按钮 | 32px | 主色实底，白字 |
| 次按钮 | 32px | 白底描边 |
| 文本按钮 | 32px | 主色文字，无边框 |
| 危险按钮 | 32px | 红色描边或红色实底，谨慎使用 |
| 图标按钮 | 28/32px | 方形，hover 浅底，必须有 tooltip |

列表行内操作优先使用文本按钮，超过 3 个操作时收起到“更多”菜单。高风险操作如关闭告警、停用渠道、生产导出必须二次确认。

### 9.5 标签与状态徽标

- 标签高度 22px，左右内距 8px，圆角 4px。
- 状态标签格式：`圆点 + 文案` 或 `级别 + 名称`。
- 同一行多标签不超过 4 个，超出折叠为 `+N`。
- 生产环境标签可使用深色描边，避免与告警级别混淆。

## 10. 表格规范

### 10.1 基础样式

| 项目 | 规范 |
| --- | --- |
| 表头高度 | 40px |
| 表格行高 | 紧凑 40px；标准 44px |
| 单元格内距 | 左右 12px |
| 表头背景 | `#F8FAFC` |
| 分割线 | `#E8EDF3` |
| hover | 行背景 `#F8FAFC` |
| 选中 | 左侧复选框 + 浅蓝背景 `#EFF6FF` |

关键列如名称、状态、操作建议固定。宽表支持横向滚动，操作列固定右侧。

### 10.2 风险表达

- 告警列表默认按级别、未恢复、未确认、持续时长排序。
- P0 行左侧可加 3px 红色风险条；P1 使用橙色风险条。
- 数值异常只高亮数值和状态，不整行大面积染色。
- 触发值/当前值采用并列展示，例如 `6.2% / 5.8%`，阈值在 tooltip 或副文本中显示。

### 10.3 表格空态与加载

加载时保留表头，展示 5-8 行骨架。无数据时在表格区域内显示轻量空态，不跳转到独立大页面。

## 11. 表单规范

### 11.1 表单布局

- 简单筛选表单使用横向排列。
- 复杂配置表单使用分区：基础信息、监控对象、触发条件、告警策略、通知配置、处理建议。
- 必填标记使用红色星号；校验错误在字段下方显示，不使用弹窗替代字段错误。
- 表单底部操作固定：取消、保存草稿、保存并启用。

### 11.2 控件规格

| 控件 | 高度 | 说明 |
| --- | --- | --- |
| 输入框/下拉 | 32px | 默认列表和配置页 |
| 多行输入 | 80-120px | 规则描述、处理建议、备注 |
| 数字输入 | 32px | 阈值、持续时间、检测周期 |
| 开关 | 20px 高 | 启用/停用 |
| 复选框/单选 | 16px | 权限、通知渠道、多选项 |

### 11.3 校验视觉

- 错误：红色边框 + 错误文案。
- 警告：黄色提示条，允许保存草稿但阻止启用。
- 成功：字段级不常驻绿色，只在测试连接、验证接入成功时显示。
- 只读：浅灰背景，保留文本可复制。

## 12. 筛选区规范

### 12.1 布局

- 核心筛选默认一行展示，最多两行。
- 高级筛选折叠，不默认占据首屏。
- 筛选项顺序统一：关键字/对象、环境、状态/级别、负责人、时间范围、更多条件、查询。
- 查询、重置、保存查询、刷新放在筛选区右侧。

### 12.2 视觉

筛选区使用白底或 `#F8FAFC` 弱背景，边框 `#E8EDF3`，圆角 8px，内距 16px。不要把每个筛选项做成独立卡片。

### 12.3 来源提示条

从告警、日志、应用、指标跳转时，在筛选区下方显示来源提示条：

```text
来源：告警 ALM-20260426-001 / order-api / 生产 / 触发窗口 10:00-10:30  [返回告警] [清除来源]
```

来源提示条使用信息色浅底，不抢告警级别视觉。

## 13. 图表视觉规范

### 13.1 通用规则

- 图表背景白色，网格线使用 `#E8EDF3`，坐标轴文字 `#7A8794`。
- 图表线宽 2px，重点线 2.5px。
- 不使用 3D 图、强渐变面积、装饰性环图。
- 所有图表必须显示单位、时间范围、采样粒度和数据延迟。
- 缺失数据用断线表示，不用 0 填充误导。

### 13.2 指标趋势

| 元素 | 视觉 |
| --- | --- |
| 主指标线 | 主色或状态相关色，线宽 2.5px |
| 对比指标线 | 使用区分度高的蓝、青、紫、灰，不超过 6 条 |
| 阈值线 | 红/橙虚线，标注阈值 |
| 告警触发点 | P0/P1 使用红/橙实心点 + tooltip |
| 日志命中点 | 蓝色竖线或小标记 |
| 发布事件 | 灰色竖线，标注版本或发布人 |

### 13.3 首页趋势与分布

首页趋势以折线、堆叠柱、排行表为主。告警级别分布可用条形图替代环图，提高精确读数能力。

### 13.4 日志时间分布

ERROR、WARN 分布使用不同状态色柱状图。点击时间桶后刷新日志明细，并在图上显示当前选中时间范围。

## 14. 告警级别视觉

### 14.1 告警标签

| 级别 | 标签样式 | 示例 |
| --- | --- | --- |
| P0 | 红色实底或强描边，白字/红字 | `P0 紧急` |
| P1 | 橙色浅底 + 橙色文字 | `P1 严重` |
| P2 | 黄色浅底 + 棕黄色文字 | `P2 一般` |
| P3 | 蓝色浅底 + 蓝色文字 | `P3 提示` |

### 14.2 告警生命周期

| 状态 | 视觉建议 |
| --- | --- |
| 已触发 | 红/橙标签，显示触发时间 |
| 已通知 | 信息色标签，显示通知渠道 |
| 已确认 | 蓝色标签，显示确认人 |
| 处理中 | 蓝色或黄色标签，显示处理人 |
| 已恢复 | 绿色标签，显示恢复时间 |
| 已关闭 | 灰色标签，显示关闭人 |
| 已升级 | 红色描边标签，显示升级对象 |
| 已静默 | 灰色/紫灰标签，显示静默截止时间 |

### 14.3 告警详情头部

告警详情头部应使用紧凑摘要条，不做巨大红色块。P0 可在标题左侧加风险条，摘要中高亮级别、状态、持续时长、触发值和阈值。

## 15. 日志视觉规范

### 15.1 日志列表

- 日志正文使用等宽字体 12px，行高 20px。
- 时间、级别、应用、实例、Trace ID 固定列展示。
- ERROR/FATAL 使用红/橙级别标签，WARN 使用黄色标签，INFO/DEBUG 使用灰蓝标签。
- 关键字高亮使用浅黄色背景 `#FEF3C7`，不改变文字颜色。

### 15.2 堆栈与上下文

- 堆栈默认折叠，展开后使用浅灰背景代码块。
- 异常类、业务包名、`Caused by` 使用轻微高亮。
- 上下文抽屉右侧打开，宽度 560-720px。
- 敏感字段以 `138****0000`、`token=******` 等脱敏格式显示。

### 15.3 Trace ID

Trace ID 使用等宽字体、可复制图标和 hover 提示。长 ID 中间截断，例如 `trace-a1b2...f89c`，复制时保留完整值。

## 16. 空、加载、异常、无权限状态

### 16.1 空状态

空状态必须说明原因，并给出一个主操作。

| 场景 | 标题 | 主操作 |
| --- | --- | --- |
| 无匹配结果 | 未找到符合条件的数据 | 重置筛选 |
| 无待处理问题 | 当前授权范围内暂无待处理问题 | 查看历史告警 |
| 未接入数据 | 暂无监控数据 | 查看接入指引 |
| 无授权应用 | 当前账号暂无可查看应用 | 申请应用权限 |
| 无关联日志 | 当前窗口无 ERROR 日志 | 扩大时间范围 |

空态图标使用线性图标，不使用大型插画。

### 16.2 加载状态

- 首页：摘要卡、队列、趋势分区骨架加载。
- 列表：保留表头和筛选条件，展示骨架行。
- 图表：显示图表骨架和“正在查询指标趋势...”。
- 日志：显示查询进度文案，复杂查询提示可能需要几秒。
- 告警详情：摘要优先加载，日志、通知、处理记录可局部加载。

加载状态不能显示 0 值，避免用户误判。

### 16.3 异常状态

异常提示使用模块内提示条，能局部重试，不阻塞整个页面。

| 类型 | 表现 |
| --- | --- |
| 指标源异常 | 标明 Prometheus/Grafana 异常，展示最近成功采集时间 |
| 日志源异常 | 标明日志源异常，提示结果可能不完整 |
| Agent 异常 | 标明心跳异常、最近心跳时间 |
| 查询超时 | 提示缩小时间范围或增加筛选条件 |
| 通知失败 | 标明渠道、接收人、失败原因、重试入口 |

### 16.4 无权限状态

| 场景 | 视觉 |
| --- | --- |
| 无菜单权限 | 独立状态页，锁图标 + 申请入口 |
| 无应用数据权限 | 不展示对象详情，不泄露敏感信息 |
| 无操作权限 | 按钮隐藏或置灰，tooltip 说明原因 |
| 无导出权限 | 导出按钮置灰，提示申请权限 |
| 敏感字段无权限 | 脱敏展示，明文入口隐藏或置灰 |

## 17. 权限与安全视觉

- 手机号、邮箱、Webhook Secret、Token、生产敏感日志默认脱敏。
- 生产日志导出、敏感字段明文查看、规则修改、权限变更必须展示审计提示。
- 只读用户不显示误导性可点击主按钮；必要时显示只读标签。
- 值班临时授权只展示告警对象和触发窗口附近的数据，不提供全量应用历史入口。

## 18. 接入与数据源状态视觉

| 接入状态 | 标签 |
| --- | --- |
| 指标已接入 | 绿色 `指标已接入` |
| 日志已接入 | 绿色 `日志已接入` |
| 链路已接入 | 蓝色 `链路已接入` |
| 仅日志 | 黄色 `仅日志` |
| 仅指标 | 黄色 `仅指标` |
| 未接入 | 红色或灰红 `未接入` |
| 采集异常 | 红色 `采集异常` |
| 验证中 | 蓝色 `验证中` |
| Agent 离线 | 橙色/红色 `Agent 离线` |

应用详情必须把指标源、日志源、Trace 源分开展示，避免单一“已接入”造成误判。

## 20. 页面落地检查清单

高保真设计稿和前端实现交付前，应逐项检查：

1. 首页首屏是否优先展示待处理问题、P0/P1、异常对象、负责人和处理入口。
2. 列表页是否统一筛选顺序、表格行高、状态标签和导出受控态。
3. 告警详情是否突出触发值、阈值、持续时间、指标趋势、关联日志和处理动作。
4. 日志查询是否支持错误聚合、Trace ID、上下文、堆栈折叠和敏感字段脱敏。
5. 指标图表是否包含阈值线、告警点、日志命中点、采样粒度和数据延迟。
6. 应用详情是否分开展示指标源、日志源、Trace 源接入状态。
7. 所有无数据、加载、异常、无权限状态是否有一致文案和主操作。
8. P0/P1/P2/P3 与正常/预警/异常/严重/未知是否全平台语义一致。
9. 高风险操作是否有二次确认和审计提示。
10. 页面是否避免营销化大图、装饰渐变、过大圆角、低信息密度卡片和无意义插画。
